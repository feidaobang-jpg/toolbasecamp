# 回调企稳与模拟跟踪

仅保留回调企稳 pullback-v1。原月K、强势弹性、妖股推荐接口和界面已移除，旧 stock_pick_records 不删除、不再结算，单独归档且不纳入新统计。没有连接券商或真实下单。

## 初始规则

主板普通股，遵守 ACCOUNT_ALLOWED_EXCHANGES 与 ACCOUNT_RESTRICTED_SYMBOLS；成交额至少1亿元。全市场有效行情至少2500只、至少80%时间戳新鲜；上涨家数占比至少40%，上证指数涨幅高于-1.5%。所属行业至少5只样本、平均涨幅非负、上涨占比至少50%。

昨日及更早的未复权日K：20/60日均线向上、MA20高于MA60。近7日高点后回调2～5日、深度2%～8%、回调成交量不超过高点前5日均量的85%。实时价格站回昨日最高价、日内低点不明显破位，涨幅0.3%～4.5%，按已交易时长估算量比1～3。最多扫描成交额最大的100只候选、推荐3只，不保证每天出票。须成功核验公告接口，过滤近30日严重负面标题；这不等于全面尽调。

这些是待验证初始参数，没有宣称历史回测完成、胜率最高或预期收益。调整条件、费用或资金规则须建立新版本，不能改写旧记录。

行情适配使用东方财富网页公开客户端标识和各来源对应的请求来源地址；全市场行情有两个入口，每次连接最多重试3次。进程内仅复用30秒内完整快照，保留原始报价时间，过期缓存不替代失败的实时请求。备用入口也必须通过既有行情覆盖率、行业和时间戳核验，不能把延迟行情当作有效实时信号。新浪报价仍使用新浪来源地址，公告使用东方财富数据页来源地址。

东方财富行情分页失败时，改用东方财富数据中心的完整股票/行业名册与新浪批量实时行情组合；数据中心的价格字段不作实时行情使用。名册须完整翻页、去重后不少于3000只沪深股票，新浪报价覆盖至少98%，行业与行情新鲜度继续遵守原条件。每个价格、涨幅、成交额、时间戳都来自实际新浪报价，不以抓取时间替代报价时间；筛选快照记录使用的行情来源。换手率缺失保留为空，既有策略不以该字段筛选。

## 执行与统计

服务器按北京时间工作日每5分钟唤起；应用用交易所日历跳过休市。14:40预览、14:50正式信号、14:55模拟买入、盘中每5分钟检查持仓、15:10保存估值。14:57后不模拟连续竞价成交；错过窗口不补单。2026日历来源：[上交所公告](https://www.sse.com.cn/disclosure/announcement/general/c/c_20251222_10802507.shtml)。未核验年份暂停执行，AI复盘提醒更新日历。

信号按版本/股票/日期去重，快照不覆盖。预览和只读GET不写成交。买入取比信号更新的实时卖一价与足够数量，较信号偏离超过2%放弃。模型本金3万元，每仓预算1万元、最多3仓、不借款、100股整手。单边滑点0.1%、佣金万三且最低5元、卖出印花税0.05%、双边过户费0.001%，仅为模拟假设，佣金应按本人账户另行校准。

跌4%止损、涨8%止盈；观察到的价格峰值盈利达到5%后回落3%退出。普通趋势退出从第3个交易日开始，最迟第10个交易日14:55尝试退出；应急止损/止盈从下一交易日开始。T+1禁止当天卖出。卖出取当次买一价扣滑点，盘口不足、停牌、报价过期时保留持仓；不用日内最高价设置事后峰值，不假定按止损价成交。

除权除息或价格基础不一致标为待复核，不把跳变当收益；当前版本不自动调整股数或计入分红。胜率只计已平仓且扣费净利润大于0的记录，预览/过期/待复核不算。同时展示平均净收益、平均盈亏金额之比、账户权益和按观察点计算的最大回撤。5分钟观察无法代表连续盘中最大回撤或保证触发价成交；估值过期会提示。保留未平仓记录，防止只看已盈利平仓的偏差。

费用依据：[印花税减半公告](https://shanghai.chinatax.gov.cn/zcfw/zcfgk/yhs/202308/t468451.html)、[中国结算过户费表](https://www.chinaclear.cn/zdjs/editor_file/20220701154723234.pdf)。佣金和滑点是公开展示的模型假设。
