# 裂隙防线 3D（Breachline 3D）· overview

- 入口：`public/html/game/breachline/index.html`（站点路径 `/html/game/breachline/`）
- 引擎：Three.js 0.170.0（站内 vendored），全部美术为程序化几何体 + canvas 纹理，音效为 WebAudio 程序化合成，零外部素材
- 版本：0.1.0（2026-10-01）

## 一句话玩法

虫群从远方 6 个发光裂隙洞口源源涌出，玩家与友军小队（2 步枪兵 + 1 坦克）用三件武器、翻滚闪避和战功建造的自动机枪塔，守住城门 10 波进攻；第 10 波迎战「洞窟母巢」Boss。

## 背景与原创声明

灵感来自同作者的单机 Godot 游戏《裂隙防线 Breachline》（第一人称基地攻防打虫群）。网页版只取其核心玩法方向（波次虫群 + 基地防守 + 可建造防御），**世界观、命名、美术、音效、数值与代码全部为本次原创**，未搬运原作任何素材、贴图或音频。

## 操作

电脑（全程键盘可玩，不依赖鼠标，不使用 Pointer Lock）：

| 按键 | 功能 |
| --- | --- |
| W A S D | 移动（相对镜头水平轴） |
| ← / →（按住） | 连续旋转视角 |
| ↑ / ↓（按住） | 有限俯仰（0.12–1.25 rad） |
| J（按住） | 射击 |
| K | 跳跃 |
| L | 翻滚闪避（翻滚期间无敌） |
| 1 / 2 / 3 | 切换武器：突击步枪 / 狙击枪（对飞行虫 ×2 伤害）/ 火箭筒（范围伤害） |
| U | 在准星地面落点建造自动机枪塔（100 战功，场上 ≤4 座，有 HP 可被虫攻击） |
| Q / E | 单次切换镜头预设：Q=越肩，E=高位战术 |
| C | 回默认视角 |
| Enter | 开始 / 波间继续 / 结算后重玩（页内重玩，不刷新页面） |
| Esc | 暂停（不 preventDefault，不会拦截浏览器退出全屏） |

辅助瞄准：准星锥形范围内自动软锁定最近敌人（金色圆环标记 + 准星高亮），hitscan 自动吸附目标中心，键盘瞄准负担低。

手机：左下虚拟摇杆（模拟量）；右下动作按钮 J 射击 / L 翻滚 / U 建塔 / 1-3 武器（字母 + 功能标签，58–84px）；右侧镜头区 ↺/↻ 按住连续旋转 + Q/E/C 预设。Pointer Events 按 pointerId 跟踪，pointercancel / 失焦 / 暂停即清空全部输入。竖屏开始后整个容器旋转 90° 成横屏（触控坐标逆变换），无阻断提示；开始不自动全屏，「全屏」按钮对整个容器（含触控层）请求全屏，失败给 toast 回退提示。

## 目标与规则

- 城门完整度 = 防线 HP（1000 + 周目加成不适用，固定 1000 起步）。漏过防线的虫会啃城门，门归零即失败。
- 击杀得战功点（同时计入分数）：甲刃虫 10 / 疾行虫 12 / 酸囊虫 18 / 飞镰虫 15 / 重甲精英 40 / 洞窟母巢 400。
- 敌人 6 类：普通甲刃虫（近战）、疾行虫（快速）、酸囊虫（远程吐酸，落点红圈预警可躲）、飞镰虫（飞行）、重甲精英（高血）；第 10 波 Boss「洞窟母巢」（高血、酸液扇射 5 连红圈预警、周期召唤甲刃虫）。同屏敌人 ≤24，全部头顶简化血条。
- 玩家 HP 归零 → 在复活点原地无限复活（3 秒无敌不连续扣血）；「演示无敌」开关在面板内，默认关。
- 友军阵亡后当波结束自动补员。
- 波与波之间 Enter（或点击战场）继续；10 波全清 → 胜利结算 → Enter 进入下一周目（周目 +1：虫群 +35% 血 / +10% 速 / +20% 伤，无限周目）。
- 最高波次与最高分数存 `localStorage`，命名空间 `tb-game-breachline-*`（`tb-game-breachline-best`，读写均 try/catch）。

## 胜 / 负 / 重玩

- 胜：第 10 波清空 → 结算面板（分类型击杀数 + 总战功）→ Enter 进入周目 2。
- 负：城门完整度归零 → 失败面板（坚持到第 N 波）→ Enter 从第 1 波重开（页内重玩，不刷新）。
- 暂停：Esc 或工具条「暂停」；工具条另有「全屏」；面板含操作说明、声音开关、触屏开关、中/EN 切换、演示无敌开关。

## 特色

- 夜色战场全程序化：发光裂隙（光环 + 光柱 + 脉冲）、石墙城门（城门随完整度变换发光预警）、散落岩块掩体、两侧翼高地、星空。
- 军团防守氛围：友军步枪兵与坦克自动索敌开火（坦克炮为范围伤害）。
- 战功经济 + 自建炮塔布防位置选择。
- 受击方向弧提示（HUD 圆弧指向伤害来源相对镜头的方位）、飘分、波次横幅、Boss 警报。
- i18n：全部可见文案 `data-i18n="breachline.*"`；站点 locale 不含游戏 key，页面内嵌 `window.GAME_I18N` 中英兜底字典，main.js 的 t() 先查站点词典再查兜底（共 62 个 key，见 `i18n-keys.md`）。

## 已知局限

- 岩块掩体目前只有视觉阻挡意义，未做角色-岩块碰撞（虫群与玩家可从岩块上穿过边缘）。
- 敌人 AI 为直线追击 + 简单分离，不会绕后或利用掩体。
- 狙击/步枪为 hitscan 曳光表现，无弹道下坠；火箭为抛射投射物。
- 血条/飘分等 UI 元素在低端机上数量上限较低（飘分 ≤14 条）。
- 手机竖屏旋转布局在极端长屏（如 21:9）下按钮可能与镜头区重叠。
- 页面 URL 带 `?qa=1` 时会挂载 `window.breachQa` 自动化验证钩子（跳波次、清场、加战功、读状态），与站内 tank-3d 的 QA 范式一致；普通游玩不暴露任何入口。
- 未做手柄/振动；未做存档续玩（每局从头开始）。

## 真实问题与修复（开发验证中发现）

1. `scene.js` 的 `createScene` 返回对象漏导出 `update` → 主循环首帧即崩（`view.update is not a function`）。已补导出。
2. 敌人对象池网格创建后未 `scene.add` → 模拟正常但敌人完全不可见。已补。
3. 渲染层多处误写 `w.time`（应为 `world.time`）→ 每帧抛错。已统一修正。
4. `main.js` 重写后遗漏 `pressed()` 输入助手 → 移动/射击全失效。已补。
5. 初始灯光过暗、虫体几乎不可见 → 提高半球光/平行光强度与曝光，提亮地面纹理。
6. 城门逻辑坐标（z=49）与视觉门体（z≈53）错位、敌人啃门位置悬空 → 调整 GATE 坐标与攻击距离。
7. 敌人头顶血条未抵消父节点朝向，旋转不面向相机 → 用 yaw 逆四元数修正 billboard。
8. 【验收阶段发现】`game.js` 三处读 `inp.my`，而 `main.js` 返回的移动分量是 `mz` → `Math.hypot(mx, undefined)=NaN`，WASD/摇杆移动与翻滚方向全部失效。已统一改为 `inp.mz`（2026-10-01），并用 Node 纯模拟回归验证：按住前进 1 秒位移 8 格、坐标有限（见仓库 `/tmp/breachline-mv-test.mjs` 同款脚本：startRun 后以 `{mx:0,mz:1}` 输入 stepWorld 60 帧，z 36→44）。该 bug 与公路打僵尸开发中发现的同类笔误同源，交叉核对后补修。
