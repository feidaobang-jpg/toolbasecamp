# 恐龙快打 · 第一、二关 3D 重制版 — 游戏总览（v0.6.0）

## 一句话

把 Capcom 1993 年街机《恐龙快打》第一关「海上都市」重新制作成 3D：选一位英雄，从楼顶一路打到第 47 街，揍趴牵着岩跳龙的 Boss 维斯·T——还能切到主角身后和第一人称重新体验这一关。

## 背景与流程（已实现）

2513 年的东海岸，黑市偷猎团伙在半沉入海里的旧曼哈顿作乱。第一关分三段，与原作顺序一致：

1. **大楼楼顶 TOP OF THE BUILDING**：开场维斯带着四个手下放话「你们老是来碍事」，朝天开一枪后跳楼离开；手下费里斯、尼斯围上来。楼顶两只油桶（一只藏炸药）、尽头楼梯间的通风管道可打碎；清完三波后一脚踹开楼梯间的门进楼。
2. **大楼内部 IN THE BUILDING**：壁纸、大理石柱、红地毯和四座金色骑士像（打碎得分、掉金砂袋 / 霰弹枪 / 冲锋枪 / 烤肉）。敌人从两侧和双开门里出来：朋克、拿刀的布雷德（掉左轮）、三个胖子锤子·T、扳手·T、黑埃尔默（掉食物）。最后撞破窗户跳到街上。
3. **第 47 街 47TH STREET**：黑埃尔默破门而出、费里斯和尼斯从残墙上跳下；路边油桶藏火箭筒。尽头倒塌的铁丝网前，维斯牵着锁链拴住的绿色岩跳龙——「喂，混蛋！离那只恐龙远点！」「滚开，不然打掉你的牙！」。维斯抽了岩跳龙一鞭，它变成橙色暴走、谁都咬。维斯会飞身踢、三连拳接长臂直拳、贴身连打、拔左轮瞄准，血量降到七成、四成时朝天开枪叫手下。打倒维斯后结算体力奖励（剩余体力 × 100），维斯留下下一关的线索：「屠夫在北边的森林里打猎……那家伙是个疯子！」

## 操作

- 电脑：WASD 移动（W 走向纵深）、J 攻击 / 捡东西 / 用武器、K 跳跃（空中 J 跳踢）、U 必杀（或 J+K）、I 冲刺（L / 双击方向也行）、冲刺中 J 冲刺攻击、走进敌人自动抓住（J 膝撞，第四下或反方向+J 投摔）、贴着油桶 J 举起再 J 扔出、C 切换视角、Q/E 转视角、Esc 暂停。
- 手机：左摇杆；右侧小霸王式 2×2 方阵（下排 J 攻击 / K 跳跃，上排 U 必杀 / I 冲刺，v0.1.3 起）；右上角 C 切换视角与暂停；按住画面拖动转视角（2026-10-05 起不设 Q/E 按钮）；竖屏开局后自动旋转为横屏布局。

v0.2.0：第一人称向右划即向右转头；侧视保持拖场景。手机点 I 后持续推摇杆保持奔跑，回中停止，可以松 I 接 J。下→上→J（键盘 S→W→J）为空手角色特殊技：杰克上踢、汉娜滚肘、穆斯塔法翻身踢、梅斯跳跃坐压；不扣体力。K 起跳后方向＋J 为斜下踢（梅斯坐压）。冲锋枪按住 J 连射，火箭筒发射范围爆炸弹；阵亡复活时降下五枚支援火箭并配四发火箭筒。

## 规则

- 每个区域倒计时 2:00，Boss 战 3:00；时间到当作阵亡并重置计时。
- 卷轴锁屏：每波敌人出现时画面锁定，清完出现「GO ▶」。原作不能往回卷，这里也一样。
- 得分：拳 100、踢 200、武器 400、投 400、冲刺攻击 500、举桶砸中 1000；敌人分值、食物（不满血回血 / 满血加分）、宝物分值按原作物品表；50 万、100 万分各奖一条命（经典命数时）。
- 失败：经典命数用完后出现原作式续关画面——维斯拿左轮指着你倒数 9 秒，按键续关；不续就 GAME OVER。

## 特色

- 四位英雄造型配色、能力值、口号与原作一致；敌人名字、头像、多层血条仿原作 HUD。
- 3D 场景四周都有布景：Q/E 转到任何角度都看得到海上沉城与远处的楼；室内外墙按镜头位置剖切成玩偶屋视图。
- 镜头不穿墙、不出画（v0.1.1）：第 47 街后墙与楼体立面同样剖切，镜头贴近时渐隐；墙后瓦砾挡住视线时正视先抬高再拉近；第一人称贴身的敌人和岩跳龙按距离淡化成虚影；锁屏时敌人、Boss 和被打飞的角色都留在画面里。
- 正视 / 第一人称可以从主角身后、主角眼睛里重新打这一关。

## v0.5.0 画风统一 + 第二关「沼泽森林」（2026-10-06）

### 画风：与赤色要塞 3D 统一

用户问「恐龙快打的画风和赤色要塞一样吗」。改前不一样：恐龙快打是卡通色阶着色（MeshToonMaterial 三段灰阶）+ 黑色法线外扩描边 + 写实感的砖纹 / 壁纸 / 地毯 / 裂缝 / 青苔噪点贴图、强光；赤色要塞是哑光顶点色低模（Phong，低高光）、无描边、只有大色块、偏冷天光 + 暖色太阳的柔和光照、浅色天空和雾。v0.5.0 改为同一套：

- 材质：全部角色 / 道具 / 布景改为与赤色要塞 `MAT.toy` 相同参数的哑光 Phong（shininess 28、specular #2a2a2a），删除描边网格。
- 角色比例：头约为写实比例的 1.5 倍、四肢略粗、手脚更圆，Q 版椭圆黑眼 + 腮红（同赤色要塞小兵的脸）；保留格斗动作需要的手臂和腿长度，总身高与判定不变。配色在原作辨识色上略降饱和。
- 场景：程序化贴图改为大色块 + 低对比接缝 + 柔和色斑（模拟赤色要塞地面的顶点色起伏），去掉噪点、裂缝、青苔、墙皮破损和蛛网；天光 / 太阳 / 雾改为赤色要塞同款色温（three r170 物理光照强度约为 r152 的 π 倍）。
- 接地阴影改为赤色要塞的径向渐变软贴片；选人卡片和结算面板文字改为奶油底深绿字（原来白字在奶油底上看不清）。
- 对照：本机 `releases/v0.5.0/captures/style-compare.png`（改前 / 改后 / 赤色要塞 / 第二关）。

### 第二关流程（已实现）

1. **2-1 偷猎者森林 IN THE POACHERS' FOREST**（原版 BGM「In the Poachers' Forest」）：凯迪拉克开进林子停下，主角跳下车。两头发怒的三角龙哈克（HACK）先后从两侧出现：退到与玩家同一纵深、隔 4～5 米，刨地预警后沿直线冲锋（撞到谁都挑飞，换纵深或跳开能躲），贴身会用角挑；被打败后晕乎乎跑开（不打死恐龙，与岩跳龙相同）。木桶里有太阳镜、汉堡、牛排。偷猎者 J（POACHER J）和斯金纳（SKINNER）端步枪：远处同一纵深时举枪瞄准，枪口白光闪一下后开枪（跳起来或换纵深能躲），近身用枪托砸，掉步枪 / 冲锋枪。尽头熟睡的霸王龙希瓦特（SHIVAT）趴在路边打呼；第三波的胖子锤子·T、扳手·T 会走过去捶它，**捶三下就醒**——玩家先把胖子打倒，它就一直睡着，可以直接走过去；被吵醒（或被玩家打到、被爆炸波及）后锁屏，咬人、跺脚震倒身边所有人，谁都打；打倒后倒地又睡着。走到山崖边跳下去。
2. **2-2 泥沼 MUD SWAMP**（原版 BGM「Ancient Earth」）：泥水齐腰深，走、跑、冲刺都慢约三成，走动溅水花；格特（GUTTER）从水里冒出来，黑埃尔默、斯金纳、偷猎者 J 也在水里。上岸后链锤兵拉什·T（LASH T.，三条血）：链锤过顶抡两圈后甩出约 3.6 米再收回，近身膝撞 / 抡锤；木桶里有手雷和烤肉。走出林子时天色转暗。
3. **2-3 恐龙尸骸地**（字幕「看看这些恐龙尸体！LOOK AT ALL THE DEAD BODIES!」，原版 BGM「Trap of Silence」与 1-2 同曲）：木栅栏、一路死恐龙、轮胎、火堆；一排五个油桶都有东西。Boss 屠夫（BUTCHER，五条多一点血）背对玩家在肢解一头死剑龙，回头一句话不说就动手（原版 BGM「Boss 2」）：双刀两连斩、冲刺斩（没刀时改冲撞）、满屏乱跳、跳起追着玩家的屁股坐（会连坐两三下，被打断才停）；七成、四成血时怒吼叫两个手下，场上杂兵少于两个时每 12 秒再补一个（格特、雷泽、打手、尼斯、布雷德、黑埃尔默轮流）。**被打倒时两把砍刀脱手掉在地上**，玩家可以捡来用（12 次），他也会回去捡。打倒后体力奖励，第二关结算。

- 第一关打完：维斯的线索台词后直接淡入第二关（体力回满、武器清空），全部打完才进结算；结算标题「第一关、第二关全部通关！」或「第二关完成！」。
- 主菜单「起始关卡」可选第一关 / 第二关（保存在本地，再玩一次回到所选关卡）。

## v0.6.0 打击感：出招到位、命中有分量（2026-10-07）
