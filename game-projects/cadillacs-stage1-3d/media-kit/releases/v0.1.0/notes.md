# v0.1.0 开发笔记（2026-10-05）

## 目标

用户要求用 game-maker 做「街机恐龙快打的第一关 3D 重置版」：属于第一类「完整第一关 Demo」+ 复刻经典——忠实还原原作第一关，只把画面做成 3D，并按用户统一要求加上正视与第一人称、Q/E 转视角、标准选项组、电脑键盘与手机触屏。

## 做了什么

1. **查原作资料**：WebFetch 抓 NamuWiki / StrategyWiki / GameFAQs 全部 403，改用内置浏览器读 NamuWiki 的关卡、敌人、物品、角色词条；用 yt-dlp 下了一段穆斯塔法一命通关录像，每 2～3.5 秒截一张拼成联系表，逐段对出第一关的流程（楼顶 → 大楼内部 → 第 47 街 → Boss）、每段的敌人、区域标题、对白；另外截了汉娜、杰克、梅斯的录像前 90 秒，读出四位主角的选人能力值和口号（杰克 4/3/3 GOOD ABILITY、汉娜 2/4/5、穆斯塔法 3/5/3 FLYING KICKS、梅斯 5/2/4 HIGH POWERED）以及游戏里的配色（汉娜是白裤子、梅斯是橙背心 + 薄荷绿裤子、布雷德其实是金发蓝衣）。
2. **音乐的取舍**：想按 MIDI 重新合成原作第一关的曲子，但 vgmusic 只有 4-2、8-1 两首，musical-artifacts 的音色包要过人机验证——按规则不绕过。最后按原作摇滚风格重新写了关卡曲和 Boss 曲，交接里如实标「未还原」。
3. **一次写完核心再逐项验证**：程序化人形骨架（按骨骼合并顶点色网格 + 卡通着色 + 描边）、关键姿势动画、三段场景、连招 / 抓投 / 冲刺 / 必杀 / 武器 / 举桶、敌人 AI（两个攻击名额，其余在外围游走）、维斯与岩跳龙、锁屏波次、计时、过场对白、续关画面、结算。
4. **用 bot 当试玩员**：写了页面内 bot，派发真实键盘事件、配合手动时钟，0.7 秒跑完一整关；四位英雄都能通关（220～255 秒游戏时间，倒下 1～3 次，汉娜最吃力，和原作一样）。

## 测试结果（v0.1.0 最终构建）

- 桌面纯键盘 88/88、手机触控 32/32（设备模拟）、四位英雄与经典 / 宽松耐久 bot 全部通关（见 qa/）。
- 测帧（Edge + RTX 4060 Ti，1280×720）：侧视 / 正视 / 第一人称 / 转视角 / Boss 战都是约 170 FPS（刷新率封顶），P95 6 ms，无超过 50 ms 的帧；绘制次数最多约 173。手机视口 + CPU 降速 4 倍约 104 FPS（模拟，不代表真机）。

## 有意思的反差 / 可拍的点

- 侧视是原作画面，按 C 切到正视和第一人称：同一个楼顶，从穆斯塔法身后看过去是一条通往楼梯间水塔的长屋顶，四周是沉在海里的高楼。
- 维斯抽了岩跳龙一鞭，绿色的恐龙变成橙色暴走，回头连维斯也咬。
- 梅斯能把油桶举起来砸人；穆斯塔法的跳踢全是飞踢。
- 续关画面：维斯拿左轮指着你倒数 9 秒。

## 待办 / 限制

- 背景音乐不是原作曲（缺乐谱），音效为合成。
- 没有真机测帧，手机只做了视口模拟；桌面实测约 170 FPS。
- 没有 Toy、没有 B 站视频；按授权规则不擅自新建 Toy。
