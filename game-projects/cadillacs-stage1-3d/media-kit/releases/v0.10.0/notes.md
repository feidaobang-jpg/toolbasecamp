# v0.10.0 第三关地狱公路
用户确认做下一个关卡后，选择已完成两关的恐龙快打，第三关用驾驶追逐改变原有步行打斗节奏。
开场清敌取得无线电呼叫凯迪拉克；荒漠公路上撞开敌人、躲油桶和投雷，追击摩托霍格。车毁或房主按U下车后保留人物体力继续步行战斗。2–4人共乘，各玩家保留角色与独立座位，共同转向和加速。
角色比例、色阶、描边与写实贴图延续前两关。荒漠、沥青、摩托和无线电为程序化制作；音乐采用第三关三首完整原版录音。具体路程、波次、车辆耐久、Boss血量为本作调校，不声称原版逐帧复刻。
最初动态提示的键位重建出现文字重复，改为重建完整按键提示；车内人物脚下旧地面影子被隐藏。新旧联机协议隔离，旧页面需要重新载入对应游戏；其他游戏协议保持。
QA通过旧关卡回归与新关卡、车毁、超时复活、二到三关衔接、三种操作模式、横竖布局及2/3/4人真实本地中继。四镜头以真实实时模拟和键盘转镜头采集；开场与Boss距离使用明确夹具。媒体保留在本机captures，不提交二进制。声音未人工听审、无完整关卡一轮录像，因此视频交接标partial；不影响已经验证的游戏发布。
网站、Toy、TapTap与B站简介分别核验和记账；未上线的审核状态不推进公开基线。不制作或发布新视频。
