## 做了什么

1. **查原作**：下载一币通关（穆斯塔法）与梅斯无伤两条录像的第三关片段，每秒 1～3 帧抽帧拼成联系表逐张看。两条录像正好是两种结局：车被炸毁后徒步打完、在车上直接把霍格撞死。
2. **3-1 死亡沙漠**：黑屏上霍格放话 → 四个蹲着的手下 → 打完才出字幕 DESERT OF DEATH → 木桶弹药箱、锤子·T 一群 → 石堆仙人掌旁的沃尔瑟 → 机修工开着凯迪拉克赶到、主角空翻上车。新敌人：车手 DRIVER、沃尔瑟 WALTHER；新角色：机修工。
3. **3-2 地狱公路**：只有一屏宽的“跑步机”——车在一屏里自由移动，地面贴图、土路车辙、近处地块、远景台地按开过的距离向后卷，贴地的东西（落地的人、掉落物、路障）跟着挪。路上按原作顺序出人和路障，撞到就飞。新敌人：飞车党（骑粉色摩托）。
4. **霍格**：车上阶段在车的前后里外换位置扔手雷（落点红圈），用车撞；车挨够手雷爆炸后转徒步阶段，猛冲与停车投弹交替，手下上场、掉冲锋枪；两种结局都做了。
5. **其他**：侧视在这一关压平了一点（多露天空和台地）；第三关不加镜头震动（按 2026-10-09 的镜头舒适度约定，前两关原样没动）；开车时武器栏显示凯迪拉克还能挨几颗；演示模式下车也不掉耐久；一路撞的那段不计时。
6. **音乐**：原声带 3-A / 3-B / Boss 3 三首原版录音，转成与前两关相同的规格（单声道 32kHz 96kbps，完整时长），响度压到和旧曲子一档（平均约 -16.5 dB）。

## 过程中遇到的真实问题

- **撞霍格可以把他撞到不能还手**：第一版自动试玩的“追着撞”打法 18 秒撞了 14 下，霍格一颗手雷都没扔出来——每撞一下他硬直 0.8 秒、投弹冷却被顶回去，车又比他快。改成：撞到后 1.5 秒撞不到并弹开；平时车要追一阵才贴得上，他抬手投弹的前后一秒会慢下来；必须是车朝他压过去才算（他自己蹭上停着的车不掉血——之前“完全不碰方向”的打法也白捡了 3 下）。改后同一打法约 31 秒、14 下撞死，期间他扔了 13～14 颗手雷，和原作录像里熟练玩家半分钟左右的节奏接近。
- **徒步阶段太拖**：霍格 640 血时，车早早被炸、一下没撞到的最差情况，自动试玩 215 秒都打不完（只有他路过时能蹭几下）。对照前两关 Boss 的 400～520 血（全程可打），把霍格改成 420 血、撞一下 30（仍是 14 下），徒步伤害 ×1.5，猛冲和慢速经过改成一趟一趟交替，慢速经过时停两秒只扔两颗（一颗逼你挪位、一颗送客），手下出场放慢。改后最差情况约 109 秒打完。
- **慢速经过时一直扔手雷没法打**：最初停下来每 0.7 秒扔一颗，全落在主角脚下，贴上去打的人只能不停躲。改成两颗定时。
- **新曲子比旧的响 3～4 dB 且顶到 0 dB**：重新转码压了音量。
- **第二关验收脚本里有“没有第三关”的断言**（两关回退时加的）：改成“打倒屠夫后接着进第三关”。
- `qa/camera.js` 里第一关 Boss 战“角色不出画”一项三次里有一次没过（维斯贴边出招时越界 4.7%）。这是原有的随机 40 秒对打测试，第一关的镜头参数这次没动，重跑两次都过；没有去改它。

## 给视频的线索

- 反差点：横版清版打到一半，机修工把车开来，“开这辆车走，会安全些”——然后就是开车把刚才围殴你的那帮人一路撞飞。
- 两种结局可以各拍一遍：车上撞死（主角空翻下车、车自己开走）与车被炸飞后徒步打完。
- 正视 / 第一人称坐在驾驶座上开，前面是一条车辙土路和迎面扑上来的人，是原作没有的角度。
- 调平衡的真实经过（“追着撞他连手雷都扔不出来”）可以讲。
