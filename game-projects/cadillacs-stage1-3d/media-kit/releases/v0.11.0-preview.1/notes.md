## 试玩

本机入口：http://127.0.0.1:8793/html/game/cadillacs-stage1-3d/index.html?stage=3

打开即选中第三关，点击开始、选角色即可。服务停止时，在本任务工作区的 game-projects/cadillacs-stage1-3d 运行 `npm run preview`；更改源码后先 `npm run build`。`?stage=3` 只预选菜单，不开启测试接口。

推荐检查：荒漠清完两波敌人 → 靠近末端电台按 J → 叫车过场 → 公路躲油桶、撞匪徒 → 640 米后追击霍格 → 击败首领结算。也可故意撞毁车辆，检查弃车步战。

- 步战沿用 J 攻击/拾取，K 跳跃，U 必杀，I 冲刺；WASD/摇杆移动。
- 驾车自动前进，WASD/摇杆调整车位，J 加速撞击，按住 K 刹车；隐藏无作用的 U/I。
- C 切换四种视角；Q/E 或拖动画面观察；暂停中切换电脑/触屏/自动，立即生效。
- 开局可直接选三关，也可从第一、二关顺序打入。重玩回到本局选择的起始关卡。

## 已知取舍

这是基于第三关核心流程的3D重制，不宣称逐帧或数值完全复刻。640米路程、车体100耐久、霍格460体力、J加速/K刹车为本版调校。开场需要电台叫车，未制作从开场起完全徒步走完整条公路的分支。

多人车辆由房主驾驶，其他乘员同车，毁车后各自独立步战。当前验证为2/3/4人状态与客机快照重建，没有接入线上大厅做网络时延、掉线重连实测。手机只做浏览器触控与横竖屏模拟，没有真实手机性能及真实多指验收。
