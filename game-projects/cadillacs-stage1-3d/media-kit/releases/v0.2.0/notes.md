# v0.2.0 玩家反馈版本
本次为正式玩法版本，网站完成验证后同步既有 Toy 和 BV18XHW66E55 简介；不制作新成片、不新增评论。

- 第一人称转头随手指方向；侧视/斜视仍可拖动场景，移动键不换位。
- 触屏点冲刺后持续推摇杆保持，回中/松杆/暂停/切换操作模式清除；四键去掉白色装饰点。
- 下上攻击是真正的四角色特殊技，有判定与动画且不扣血。键盘 S→W→J；手机下→上→J。
- 空中方向＋J 发斜下踢；梅斯坐压，和同时 J+K/U 必杀分开。
- 既有抓人、膝撞、投掷、手枪和霰弹枪保留；加入可拾取冲锋枪（走廊第三座像）与火箭筒（街道首个桶）。复活五枚支援火箭、不伤玩家，携带四发火箭筒。
- 走廊补原作参考中的拱券、低护墙线、破损墙面，并调整柱头高度；属于程序化重绘，尚非逐像素/逐尺寸完整复刻。

## 验证范围
33 项玩家反馈回归、35 项横竖屏触控回归、11 项防穿墙/黑屏/出画回归已通过。桌面全流程另附结果。多指使用 Chromium CDP 模拟，不宣称手机真机性能验收。
桌面旧连招用例会继承前序抓取/受击状态：改为独立起点及固定时钟，保留实际键盘输入与血量/击倒断言；第一人称 E 的断言更新为正确转头方向。CDP 手指释放按“本次抬起的触点”传递，并等一帧让 pointermove 派发，避免测试本身漏事件。
