# v0.5.0 画风与赤色要塞统一 + 第二关「沼泽森林」（2026-10-06）

正式版本。用户原话：「恐龙快打的画风现在和赤色要塞的一样吗？如果不一样则调成和它的一样。然后开发第二关。」

## 画风：改前不一样，现已统一

| | 改前（v0.4.1） | 赤色要塞 3D | 改后（v0.5.0） |
| --- | --- | --- | --- |
| 材质 | MeshToonMaterial 三段色阶 | 哑光 Phong 顶点色（shininess 28） | 同赤色要塞参数 |
| 轮廓 | 黑色法线外扩描边 | 无 | 删除描边 |
| 贴图 | 砖纹、壁纸花、地毯纹、裂缝、青苔噪点 | 大色块 + 顶点色起伏 | 大色块 + 低对比接缝 + 柔和色斑 |
| 角色 | 写实比例 | Q 版小兵 | 头约 1.5 倍、四肢略粗、椭圆黑眼 + 腮红（保留格斗动作可读的手脚） |
| 光照 | 白光强光 | 偏冷天光 + 暖色太阳、浅色雾 | 同色温（r170 强度按 π 倍换算） |
| 接地阴影 | 实心黑圆 | 径向渐变软贴片 | 软贴片 |

顺带修复：选人卡片和结算面板在奶油色底上用白字 / 浅紫字，几乎看不清（统一 UI 时遗留），改为深绿字、金色重点。侧视镜头取景边距加大 0.2 米，修复主角贴右缘最前排出拳时手臂出画约 4%（旧构建 11.8%）的既有问题。

## 第二关（三段 + Boss）

- 2-1 偷猎者森林：凯迪拉克开场；三角龙哈克刨地冲锋 / 角挑，被打败后跑开；偷猎者 J、斯金纳步枪瞄准（枪口闪光）后开枪，跳起来或换纵深能躲；熟睡的霸王龙希瓦特——胖子捶三下就醒，先打倒胖子就能悄悄走过；醒了以后锁屏、咬人、跺脚震倒所有人、谁都打。
- 2-2 泥沼：齐腰深、移动慢约三成、溅水花；格特从水里冒出；上岸后链锤兵拉什·T 甩锤约 3.6 米。
- 2-3 恐龙尸骸地：黄昏、木栅栏、死恐龙、一排五个都藏东西的油桶；屠夫背对玩家肢解死剑龙，回头就打：双刀连斩、冲刺斩 / 冲撞、乱跳、连续屁股坐、七成 / 四成血叫人 + 每 12 秒补小弟；被打倒时两把砍刀脱手，玩家能捡来用，他也会回去捡。
- 原版音乐：2-1 In the Poachers' Forest、2-2 Ancient Earth、2-3 Trap of Silence（原作与 1-2 同曲）、Boss 2。
- 流程：第一关打完直接接第二关（体力回满）；主菜单「起始关卡」可直接选第二关并保存；结算按通关关卡显示。
- 网站卡片：副标题改「海上都市 · 沼泽森林两关」，标签「开发中」，封面按新画风重拍（同一构图）。

## 验证（2026-10-06，本机 Edge + RTX 4060 Ti）

- `qa/stage2.js` 55/55；`qa/desktop.js` 90/90；`qa/mobile.js` 35/35；`qa/camera.js` 11/11。
- 两条既有测试断言过期（不是本次引入）：手机全屏按钮已按 10-06 规则改为按能力显示；右拖与 E 同向（10-05 拖动方向统一后符号相反）。已用旧构建复跑确认这两项与镜头右缘出画在改前就失败，测试已按现行规则更新。
- bot 自动通关：从第二关开局 457 游戏秒通关（7 次倒下、无限命）；从第一关开局一路打到第二关结算 699 秒（第一关 4 次、第二关 6 次倒下）。
- 测帧：第二关三个区域四个视角，每帧 CPU 1.1–1.5 ms、绘制 12–92 次、约 9–12 万三角形，帧率被显示器刷新率封顶（126 / 170 FPS），无 >50 ms 长帧；844×390 DPR2 + CPU 降速 4 倍的模拟中位 5.9 ms。不是真机测试。
- 360° 取景：`qa/rotate-stage2.js` 三个区域侧视转 ±90° / 180°、正视、正视转身、第一人称截图；背景树环挡视线时整片淡化。
