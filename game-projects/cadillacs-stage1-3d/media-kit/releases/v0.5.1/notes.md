# v0.5.1 画风改回旧版（硬派写实），第二关同款（2026-10-06 晚）

用户看了旧版 v0.4.1 / Q 版 v0.5.0 / 折中版（写实比例 + 哑光）三版同站位对比后决定：「旧版好，更暗更写实。改回旧版，第二关也是。以后做游戏要根据游戏自身特点去做画风。」折中版没有上线。

- 第一关：角色比例、脸、配色、卡通色阶着色（MeshToonMaterial）、黑色描边、写实贴图（壁纸菱格、裂缝、蛛网、墙皮破损、砖纹）、灯光与雾回到 v0.4.1；`captures/revert-check.png` 为同站位对照，除选人卡片文字外一致。
- 第二关同一路线：角色、恐龙、凯迪拉克、死恐龙与道具卡通色阶 + 描边；写实泥土 / 烂泥地面（碎石、草屑、裂纹），树与草丛用斑驳纹理（一开始带纵纹，树冠像西瓜，改成纯斑块），木栅栏用木纹；三段灯光改暗，泥沼水更浑。
- 保留：选人卡片 / 结算文字深色（旧版白字看不清，属于可读性修复，卡片紫色头像底和紫边恢复旧样）；侧视取景边距 0.75 米。
- 网站卡片封面恢复旧图（?v=3）。B 站简介里「画风改成和赤色要塞一样」一句已不准确，同步删掉。
- 画风规则改为「每款游戏按自身特点决定」：AGENTS.md 与本机 game-maker 技能（见 `game-projects/site-games/releases/style-principle-20261006/`）。
