# v0.5.4 暂停后重开有声音、第二关下半屏能走（2026-10-06 夜）

用户反馈：「暂停游戏后点击重新开始，bgm没有播放？」「第二关为什么只有上半屏幕可以人物走动进入，下半屏无法进入？」基于 v0.5.3（另一任务的虚拟按键内移）。

- 暂停重开无声：暂停会挂起整个音频，「重新开始」直接开新局没有解除，新的一局 BGM 和音效全无。`startGame()` 先 `A.musicDuck(false)`。同样问题在赤色要塞、虫潮也有，一并修复（见 `game-projects/site-games/releases/restart-audio-20261006/`）。
- 第二关可走范围：第二关三段原来与第一关同一纵深（z −2.3～2.5），第一关前排下面有楼顶边缘 / 路沿等明显边界，第二关地面一直铺到画面底部，可走范围只到画面约 60% 高。现在第二关可走到 z 4.0（前排脚下约在画面 83% 高）；取景仍按 z 2.5 那一排（`camZ1`），观察点抬高 1 米（`camTy`）让地面整体下移；前排更靠近镜头时锁屏左右边界按透视收窄（`nearInset`）；外沿一排灌丛 / 芦苇 / 碎石骨头标出边界，原来压在前排的倒木、轮胎、骨头挪到外沿。第一关不变。
- Toy 标题按用户要求改为「恐龙快打 3D：第一、二关」（已过审）。
