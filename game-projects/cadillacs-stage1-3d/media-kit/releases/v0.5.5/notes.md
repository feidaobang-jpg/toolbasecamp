# v0.5.5 开枪看得见子弹、火花在枪口（2026-10-07）

用户反馈：「恐龙快打枪发射没看到子弹飞出来？火花的位置好像也不在枪管出口？」

## 原因

- 玩家的手枪 / 冲锋枪 / 霰弹枪 / 步枪是即时判定：扣扳机就直接算命中，画面上只有枪口火花和敌人身上的命中火花，中间没有任何东西飞过去。
- 枪口火花放在「站位前方 0.9 米、离地 1.35 米」的固定估计点，而开枪姿势要约 0.15 秒才从持枪姿势举到位，火花出现时手还没抬起来：手枪的火花飘在枪前三四十厘米，冲锋枪在枪管前面一截。偷猎者步枪、维斯左轮同样是估计点；维斯手里根本没有枪模型。

## 修改

- 火花、子弹、步枪兵瞄准闪光都从武器模型的枪管前端算出：开枪那一帧手臂直接举到位，等站位和朝向更新后取枪口世界坐标。
- 新增子弹拖光（亮芯 + 橙色光晕）：手枪 / 冲锋枪约 75 米/秒，步枪约 95 米/秒且更长，霰弹枪五颗弹丸扇形散开；没打中就飞到射程尽头，偷猎者打空的子弹落在主角身后的地上扬尘。
- 子弹飞到才命中：谁中弹、伤害在扣扳机时算好，掉血、受击闪白、命中火花推迟到子弹到达（几帧以内）；换区域时还在飞的子弹作废，目标已倒地则不结算。
- 维斯拔枪、召唤小弟、开场鸣枪时手里显示左轮，朝天开枪也有子弹飞上去。
- 火箭筒的火花也改在炮管前端。

## 验证

- `qa/guns.js` 41/41：每种枪朝右 / 朝左，火花到枪模型前端距离 0、在朝向上不落后于枪口 0.1 米以内；开枪后有拖光，扣扳机那帧敌人不掉血、子弹飞到后掉血，拖光随后消失；火箭筒、偷猎者、维斯同样检查。
- `qa/gun-shots.js` 逐帧截图对照：`captures/before-guns.png`（修复前）、`captures/after-guns.png`（修复后）。
