# v0.6.0 打击感：出招到位、命中有分量（2026-10-07）

用户反馈：「感觉恐龙快打的动作不够标准和爽快，能继续优化吗。包括打击感和音效等。」

## 原因（逐帧截图查出来的）

- **拳头总伸不到位**：出招片段之外又套了一层平滑（时间常数约 30 毫秒），刺拳第 0.05 秒就判定命中，这时画面上的手臂才伸出一半；命中停顿又把角色冻在原地，所以停顿那几帧定格的是「半截拳」。
- **出招没有蓄力和爆发**：每招都是「架势 → 出拳姿势」平滑过渡（smoothstep 起步慢），没有往回拉的蓄力，也没有打出去那一下的加速和过头。
- **被打的人反应弱**：受击姿势随机二选一，停顿期间也保持被打前的姿势，后退只有 1.2 米/秒；倒地的落地声 −46 dB，几乎听不见。
- **轻重不分**：所有命中只分「普通 / 大」两档，停顿 0.05 / 0.08 秒，只有大招震屏；连招最后一下和第一下刺拳的感觉差不多。
- **声音单薄**：拳、踢都是一层滤波噪声 + 一个降调正弦，每一下音高完全相同；挥空声在按键瞬间就响（比拳头打出早 0.05～0.15 秒），音量也小。
- **连打吞键**：没打中时在出招中途再按 J，收招后这一下就丢了。

## 修改

- **动作**：刺拳、勾拳、上勾拳、中踢、高踢、侧踢、膝撞、武器挥击、屠夫砍刀等改成「蓄力拉回 → 极快打出并略微过头 → 停住 → 收招」，打出那段用先快后慢的缓动；出招时平滑大幅减弱。命中停顿里攻守双方直接摆到「打到位 / 被打歪」的那一帧。
- **受击**：打头左右手各有方向（左拳打得头往一边歪、右拳往另一边），踢到身体是弯腰；先被打得猛一歪再缓回来；后退 2.1 米/秒；被击倒飞得更利落（水平 3.3 米/秒）。
- **三档打击分量**（轻 / 重 / 终结）：命中停顿 0.065 / 0.10 / 0.14 秒（被打方比出手方多一帧），被打的人沿受力方向抖动；震屏 0.035 / 0.09 / 0.17；连招最后一下和挑飞算终结。远处飞来的子弹、爆炸不让开枪的人跟着定格。
- **特效**：命中火花加白热闪光和朝受力方向飞的火星，终结技多一圈冲击波；重招出手带一道月牙形挥击残影（正对 / 背对镜头时不画）。
- **音效**（WebAudio 合成，未找到可用的原版音效采样）：拳 / 踢分三层——高频「啪」的瞬态、中频皮肉拍击、失真的降调闷响，重击再叠低频冲击；新增重踢、重挥空、倒地砸地声；打击声送进 0.32 秒的短混响；每一下音高随机浮动 ±8%。挥空声改在拳脚打出时响，重招用更沉的挥空声。
- **手感**：挥空中途按的攻击不丢，收招后立刻再出一拳；一波最后一个敌人被主角打倒时 0.42 秒慢动作（0.3 倍速），自动恢复；Boss 倒下仍用原来的慢动作。

## 实测数据

- 离线渲染单个音效测响度（同一条总线链）：倒地 −45.9 → −24.9 dB（旧版用的是轻落地声）；重拳 −26.8 → −24.1 dB；重踢（新）−23.2 dB；挥空 −41.5 → −35.4 dB，重挥空（新）−31.0 dB；所有峰值 ≤ 0.57，没有削波。
- 逐帧截图（`captures/impact-before-after.png`，左旧右新）：旧版停顿帧手臂伸出约一半、敌人站直；新版拳头伸到位、敌人头被打歪、火花在拳头上。
