# v0.8.1 原版音效对号入座（2026-10-07）

用户反馈：v0.7.0 接入的原版音效里，「打人 4 连击的声音和扣血必杀的声音不对」，并问 GO 满不满意。

## 原因

原版拆包（The Sounds Resource：效果 36 个、人声 30 个）文件名只有编号。v0.7.0 按编号顺序猜：005C～005F 当拳 / 重拳 / 踢 / 重踢，V01～V04 当四人必杀，V33 连放三遍当 GO。实测：

- 005C～005F 在实机录像里几乎不出现，不是打击声。
- V01～V04 分别是杰克「Take that」、汉娜「Gotcha」、穆斯塔法「Gotcha」、梅斯「Blammo」——捡东西 / 嘲讽台词，不是必杀喊声；真正的必杀喊声（V14～V17）拆包里缺失。
- GO 原作连喊三遍、间隔 0.59 秒，旧版间隔约 0.75 秒，用的录音也和实机不太一样。

## 怎么核对的

不再按编号猜：把每个样本和四段原作实机录像（杰克无武器、汉娜、梅斯、穆斯塔法）的音轨逐点比对，扫描 0.7～1.3 倍播放速度，命中时刻再截帧看画面；人声用一段无背景音乐、逐句标注的原作人声视频对上名字（30 个人声相关度 0.94～1.00）。详见 `audio-sources.json`。
