# 跳跳狐 3D：第一关（Hop Fox 3D: Stage 1）

## 一句话玩法
3D 立体布景里的经典横版闯关：小狐狸沿河岸小路跑跳，顶木箱拿橡果、踩甲虫、踢蜗牛壳，最后跳上终点旗杆敲响铃铛。

## 背景
用户想要一个「FC 超级玛丽第一关 3D 版」与现有 mario-3d 对比效果。该系列角色与关卡受版权保护，这里做的是同类型的原创作品：原创主角、敌人、道具与关卡，保留横版闯关的手感与节奏，用 3D 立体布景展示画面效果。

## 操作
- 电脑：A/D 移动；K（或空格）跳跃，按住跳得更高；J 奔跑，拿到萤火灯笼后按 J 发射会弹跳的火花；Q/E 旋转视角（限制在 ±55°，左右方向始终和屏幕一致），R/F 俯仰，C 回正；Enter 开始/继续/重玩，Esc 暂停。
- 手机（横屏）：左下摇杆左右移动，右下大号 K 跳跃、J 奔跑，右侧视角键；开始时请求全屏与横屏锁定，失败仍可在视口内玩；竖屏显示提示并自动暂停。

## 目标与规则
- 从草原起点跑到终点旗杆，时间 300（每秒减 2.5），3 条命，第 96 格有中途灯笼（检查点）。
- 顶木箱：橡果箱出 1 颗橡果（200 分），多次箱在 4 秒内可连顶 8 次；能量箱出「发光莓」（戴上矿工帽，可顶碎陶砖、多挨一下），已有装备时出「萤火灯笼」（可发射火花）；隐藏箱出「金叶」（+1 命）。100 颗橡果 +1 命。
- 敌人：甲虫（踩扁 / 从下方顶翻 / 火花击倒）；蜗牛（踩一下缩进壳里，再碰壳会踢飞，飞行的壳沿路撞翻其他敌人，壳 7 秒后会醒来）。连续踩踏分数递增（100→200→400…）。
- 危险：从侧面碰到敌人（有装备则掉装备并短暂无敌）、掉进河里、时间耗尽。
- 地形：可穿越的树枝平台（从下方跳上）、树桩、石阶、会来回移动的浮木、弹跳叶片（弹得很高）。
- 终点：抓旗杆的高度越高分越多（100–5000），滑下后走进磨坊小屋，剩余时间每单位 50 分，放烟花后结算。

## 失败 / 成功 / 重玩
- 失败：3 条命用完 → GAME OVER 字样升起 → 结算面板。
- 成功：旗杆 → 小屋 → 时间结算 → 三发烟花 → STAGE 1 CLEAR 面板（橡果、铃铛高度奖励、总分）。
- 重玩：Enter 或按钮原地重开；最高分存本机（tb-game-hopfox3d-hi）。

## 特色
- 3D 立体布景：小路在河岸上方，前景是流动的河水和石头，后面是草地、低多边形树、远山与云；Q/E 旋转能看到整条路线在河边蜿蜒。
- 角色动画：跑步摆腿、尾巴甩动、围巾飘动、起跳拉伸/落地压扁、急转身刹车倾斜，戴帽子和提灯笼时外观变化，灯笼会照亮周围。
- 开场：黑底关卡卡片后，镜头从全景拉近到主角。
- 原创配乐（F 大调轻快小曲）与振荡器音效，时间不足时加速。

## 主要功能（implemented）
- F-move：加速/奔跑/急停、可变跳跃高度、土狼时间与跳跃缓冲、顶角修正
- F-blocks：木箱（橡果/多次/能量/隐藏金叶）、陶砖（装备后可顶碎）、石块、树桩、单向树枝平台
- F-enemies：甲虫、蜗牛（缩壳、踢壳、壳撞翻敌人、醒来）、从下方顶翻、连续踩踏计分
- F-powerups：发光莓（矿工帽）、萤火灯笼（火花投射物）、金叶 +1 命
- F-terrain：高低台地、坑与河、移动浮木、弹跳叶片、检查点
- F-goal：旗杆高度计分、滑杆、进屋、时间结算、烟花
- F-camera：侧视跟随 + 前瞻、Q/E/R/F/C、开场拉近、标题待机摆动
- F-controls：键盘全程、手机摇杆 + 跳跃/奔跑键、多点触控、全屏回退、竖屏暂停
- F-hud：分数、橡果、生命、时间（不足 100 闪红）、进度条、结算面板
- F-audio：原创配乐与音效、静音
