# 赤色要塞 · 前线营救 3D

用原创低模三维模型重新演绎 FC《赤色要塞》第一关的吉普救援循环。完整第一关 Demo，单人、纯键盘与触屏均可玩。关卡按林地营房、左侧河桥、战俘营、接应点、四辆重型坦克组织；是可玩的三维改编，不是逐格复制原版地图或 ROM 模拟器。

## 运行与构建

源码：`src/`，Three.js r152 同源本地依赖，许可证位于 `src/vendor/LICENSE.txt`。

```powershell
node game-projects/jackal-3d/build.mjs
python -m http.server 8876 --directory public
```

入口：`http://127.0.0.1:8876/html/game/jackal-3d/index.html`。
静态产物：`public/html/game/jackal-3d/`。所有运行依赖均在本目录内，游戏本身无需 CDN 或账号。

## 操作与规则

- Enter 开始 / 继续 / 重玩；WASD 或方向键驾驶；J 连发机枪；K 榴弹或导弹；L 加速；C 在斜俯视与正俯视之间切换；Esc 暂停；M 静音。
- 武器跟随驾驶朝向，有小角度辅助瞄准。可以停下持续射击，不依赖鼠标。
- 炸开四座营房后靠近队员接人；共 9 人，车载上限 8 人，全部救援需要往返接应点。军官升级为导弹，再次升级扩大爆炸范围。
- 停机坪每 0.5 秒撤离一人，回复一格装甲并加分。撤离后直升机起飞。
- 初始 5 格装甲；正常受伤有短保护。死亡后从最近检查点无限复活，3.2 秒保护；重武器降一级，乘员回到检查点附近等待接回。
- 击毁关底依次出现的 4 辆重型坦克即通关；后两辆有预警范围炮击。救援数量、得分、用时和增援次数参与结算。最高分独立保存在 `jackal3d.v1.best`。开启过演示无敌的局不写最高分。
- 手机左摇杆、右侧 J/K/L 按钮，C 单按钮切镜头。竖屏开始后自动旋转游戏并逆变换触控；开始不请求全屏，全屏须单独点按钮。

## 验证与媒体

`qa/` 为可重复浏览器验收脚本，使用 Playwright 和本机 Edge。`inspect.cjs` 通过浏览器测试拦截注入只在测试时可用的诊断入口，发布代码没有作弊全局。`playthrough.cjs` 使用正常键盘输入完成整关；`functional.cjs` 明确标识定点状态设置与模拟触屏；`performance.cjs` 在不录屏时测帧时间。

媒体交接唯一入口：`media-kit/`。原始录屏留本机，视频文件不提交到仓库。网站部署与 Toy 提交是独立状态；本版本未提交 Toy。
