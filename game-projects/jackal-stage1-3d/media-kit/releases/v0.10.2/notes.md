# v0.10.2 — 联机队友车头不转向与加入者卡顿修复

- 分类：严重修复（联机玩法）+ 普通补丁（内部性能）。
- 修复内容：
  1. **队友车头钉死**：加入者（纯渲染端）从不模拟自己的车，`P.ang` 停在出生角 180°，而上送的输入里 `look` 取的正是这个静止值；主机按它把队友车头按住，于是"车会走、车头不转"。现在加入者上送**世界方向 + 本机视角朝向**（第三人称只在真的拖过视角时才带朝向），主机直接按本人镜头开车并转车头；电脑接管的换算路径保持不变。
  2. **加入者卡顿**：加入者按约 15Hz 快照摆放车位，画面逐帧跳格。现在所有车位姿（含自己的车，跟得更紧）按帧向权威值插值；房主端不受影响（本机本来就连续）。
  3. **包体瘦身**：上千个地物（营房、大门、油桶、树）过去每次快照整份上送，占包体 57%；改为只送与上次不同的条目，并每约 2.6 秒与本关初始状态比对一次以便中途加入者对齐。快照数值统一保留 4 位小数。实测联机单包 68.6KB → 26.3KB，双端真实联机会话 29.6KB。
  4. 补回被上一次共用大厅改造丢掉的 `demoBlock` 事件（演示模式挡下敌弹时记录），桌面 QA 恢复 94/94。
- 验证（本机无头 Chromium + 本地联机转发服务，两个真实浏览器页面）：
  - 新增 `qa/coop-heading-perf.cjs` 10 项全通过：双人进入同一局、主机看到好友车头随移动方向转向、好友本机车头与主机一致、好友按自己的镜头方向转车头且实走方向与车头一致（along=1.0）、加入者插值按帧收敛（瞬移 4 格后逐步 0.83→0.33，5 帧收敛到 2.75）、房主本机未受影响、快照体积与收包数、无页面错误。
  - 既有回归：`qa/desktop.js` 94/94、`qa/stage2.js` 31/31、`combo-fire.cjs`、`barrel-direction.cjs`、`hud-visibility.cjs` 全通过。`qa/mobile.js` 横屏 3 项失败（Toy 外壳顶栏下菜单超出视口、右上角暂停按钮、暂停菜单全屏项）——已用改动前源码 A/B 复现同样的 3 项失败，属既有问题，不在本任务范围。
