# v0.11.0 开发记录：第三关「港口」+ 开局保护

**一句话目标**：赤色要塞是几款复刻里访客最多的一款，但第二关之后没再加过内容，新玩家几乎不回来——加上第三关（港口、战舰 Boss），并查清新玩家为什么留不住。

基于 v0.10.3-menu-text1-privacy1（线上现行版本）。开发日期 2026-10-12，Claude Code 会话，独立工作区 `D:/project/worktrees/jackal-stage3-20261012`。

## 真实经过

1. **新玩家开局实测**（Toy 公开入口，手机竖屏 390×844，无存档）：约 1.5 秒出菜单，点「开始游戏」能进，摇杆方向正确，无报错。
2. **发现：出生点不动会很快被打死。** 手动时钟、6 个随机种子，进场后完全不操作：
   - 第一关：2.8–3.9 秒挨第一枪，7.7–9.0 秒第一次阵亡，60 秒内阵亡 5 次。
   - 第二关：2.5–3.3 秒挨第一枪，5.6–7.9 秒第一次阵亡。
   - 线上实时录像（改动前）：22 秒内受击 4 次、阵亡 2 次。媒体 `M-BEFORE-IDLE`。
   - 这个问题从首版就有，不是 10-07 之后才出现的，所以它解释不了留存为什么在那天之后变低，但对还在找按键的手机新玩家确实不友好。
3. **开局保护**：每关进场后，玩家第一次推摇杆 / 开火之前敌人都不开火，最多等 10 秒；第一次操作后再留 1.2 秒，并把在场敌人的开火时间错开。进场 2.5 秒还没动，就提示怎么开车和开火。Boss 开战时保护立即结束。
4. **查原作第三关**：地图用 VGMaps 的 Jackal-Stage3（512×2932，sonyball 2007 年绘制），分 8 段在无头浏览器里截图看的，没有下载到本机；Boss 资料来自 Arcade History（横停的战舰，NES 版 6 座炮塔）和 Hardcore Gaming 101（six spread-shot cannons）。
5. **引擎里早就留好了港口部件**：橙色仓库（port 样式）、集装箱、橙色闸门、标线、吊机都是之前做第二关时预留的，这次直接用；新做的只有码头货箱堆、停着的吉普、战舰和舰炮。
6. **第一版一次就跑起来了**（无报错、全程可通行），但有这些真实问题：
   - 地面箭头画成了「Y」：预留的箭头代码从没被用过，两笔箭翼的转角符号反了。媒体 `M-FIRST-BASIN`（改前）/ `M-FIX-LANE`（改后）。
   - 水色是很亮的青色，像游泳池；改成深蓝。
   - 战舰的舰桥顶盖是深灰色，俯视看过去一片黑；改成白色舰桥加红色腰线。媒体 `M-FIRST-BOSS` / `M-FIX-BOSS`。
   - **机器人卡了 280 秒**：俘虏棚货场那辆巡逻坦克的路线正好穿过一只红色集装箱，坦克过不去，机器人隔着箱子朝它打了 1998 发火箭，谁也打不着谁。把巡逻路线改到货场北边的空地后，机器人 155 秒打通全关。
   - 结算表：第三关击毁种类多（13–14 行），844×390 横屏下超出屏幕 6 像素；紧凑横屏里行数多时收紧行距。
7. **跑旧回归时发现两处线上就有的问题**：
   - Toy 手机横屏（游戏区 844×346）主菜单底部被截掉 29 像素：后来加的「联机大厅」入口让菜单从 7 行变成 8 行。把它和三键操作模式行并排，回到 7 行。媒体 `M-BEFORE-MENU`（线上）/ `M-AFTER-MENU`。
   - 两条验收断言还在检查 10-10 已经按规则移除的「返回游戏列表」链接，手机回归因此中途崩溃，后面的检查一直没跑到；改成确认没有这类链接。
8. **联机第三关开出来是第二关**：服务端把联机房间的关卡号限制在 1–2。放宽到 1–9（各游戏客户端按自己的关卡数再夹一次），补了一条服务端测试。顺带修了加入者在 Boss 战里一直听关卡曲的旧问题。
9. **音乐没能核实**：见下面「待确认」。

## 待确认

- **第三关 BGM 是否原作第三关的曲子**：Zophar 这套录音的曲名标注不可靠——「2 - Stage 1」只有 19 秒；「3 - Stage 2」和「4 - Stage 3」是同一首曲子（频谱相似度 0.95，只错开 7.2 秒），所以现有第一、二关其实一直在放同一首；标成「6 - Stage Clear」「7 - Game Over」的都是 180 秒的循环曲。第三关暂用「6 - Stage Clear」（33.55 秒一循环，和现有关卡曲、Boss 曲都不同）。要核实得拿一段原作实机录音来比对，下载需要用户同意。
- **手机真机**：所有手机结论都是桌面浏览器模拟。

- **「新玩家站着不动 8 秒就被打死」**：`M-BEFORE-IDLE`（线上改动前实时录像 22 秒）→ 改动后同样不动（验收脚本数据；上线后可补录同机位对照）。
- **「预留了一年没用过的箭头，一用就是反的」**：`M-FIRST-BASIN` → `M-FIX-LANE`。
- **「坦克和机器人隔着集装箱对射了 280 秒」**：只有日志数字（1998 发火箭），没有画面；要画面得用旧路线重演并标注。
