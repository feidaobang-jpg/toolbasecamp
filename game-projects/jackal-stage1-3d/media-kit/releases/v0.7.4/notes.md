# v0.7.4 去雾与恢复Boss固定机位

用户反馈Boss画面出现迷雾、战场显得变小，并要求取消自动拉远，先用旧固定预设试玩。实际场地和模型尺寸没有被上一版缩小；斜俯视Boss镜头距焦点由34拉至约61.232，触发既有距离雾，导致目标变小、颜色变淡。

本版删除全场景距离雾及各预设雾参数，完整恢复v0.7.1 camera.js。HUD、模型统一与战斗判定保留。近景与自由转头沿用原观察范围，未经用户同意不再次自动缩放。

134项功能检查通过；动态录像和独立帧时间测量另记。手机为桌面视口模拟，未做实体手机验证。普通补丁沿用封面、B站简介累计。

部署：v0.7.4网站134项验收通过。后续原作模型任务已合入去雾与固定镜头，以v0.7.5部署并提交Toy；本任务不重发旧包。最新网站、v0.7.5提交预览与Toy公开新版v22991各134项检查通过。射程、固定距离和无雾均保持。
