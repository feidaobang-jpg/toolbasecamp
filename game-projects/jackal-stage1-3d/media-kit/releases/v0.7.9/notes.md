# v0.7.9 手机横屏菜单完整显示、全屏按浏览器能力显示（2026-10-07 凌晨）

处理 v0.7.8 回归时发现、线上旧版同样存在的两个问题：`qa/mobile.js` 的「横屏菜单完整落在视口内」（844×390 下菜单底部超出 11px）和「手机全屏入口均隐藏」（与 2026-10-06 全屏按实际能力检测的规则矛盾，且之后脚本会 TimeoutError 中断）。

- 紧凑横屏（高度 < 520）：操作模式三键行去掉外边距、与其他选项同为 40px，面板内边距收紧；暂停改为左列标题/得分/提示、右列两列选项；结算改为左列计分表、右列总结与按钮。844×390、932×430 下三种菜单完整显示；更矮的 667×375、740×360 暂停与结算完整，主菜单整层滚动。
- 窄横屏（宽度 < 640，如 568×320）：主菜单上下排列，选项保持两列不再横向溢出；主菜单与暂停整层手指滑动或键盘 ↑/↓ 都能到达首尾。旋转布局下（竖屏手机开局后）也已实测拖动可滚动。
- 全屏：`fsCapable()` 检测元素全屏方法与 `fullscreenEnabled`，不支持时隐藏菜单与右上角的全屏按钮（键盘导航跳过），支持时显示；请求被拒绝时保留原提示并继续游玩。删除了按手机隐藏的旧 CSS。
- 顺带修复：`hidden` 被 `.items > button`、`#stage #hud` 的 display 盖掉——失败结算和最后一关结算会显示「进入下一关」，标题页 HUD 会从菜单后露出。
- QA：mobile.js 57/57（新增窄横屏可达、暂停适配、全屏实测与不支持全屏场景，修复 `#hud .hud-score` 超时）；desktop.js 94/94；stage2.js 31/31；touch-view.js、hud-visibility.cjs 全部通过。设备模拟，非真机。
