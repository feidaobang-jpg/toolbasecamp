# 最终口播

一台小吉普，十九个人要救，前面还堵着四辆坦克。赤色要塞，开打！

先用手雷炸开营房，再靠过去接人上车。车后座越来越挤，这趟救援可不能白跑。

闪光俘虏就是关键补给。接上车，手雷直接升级成火箭，火力终于跟上了。

营地大门也能炸开。冲进去继续救人，武器还能升到双向，再到四向火箭。

过桥先处理守桥坦克，接走闪光俘虏。看左上角，四向火箭到手，救人和变强是一条线。

找到直升机坪，停稳交接。车上的人数往下减，已送达往上加，十九个人，一个不少。

最后是四辆蓝色坦克。先对准再开火，贴太近就往侧面拉。挨炮后护甲确实会掉，无限命可不是无敌。

最后一辆也解决了。第一关救援完成，接下来进废墟城。

第二关换成废墟城，石柱、窄路和敌人的交叉火力，路线一下变得紧张了。

这一下没躲开，吉普被打爆了。复活能继续，但武器回到手雷，还是得重新救人，把火力补起来。

绕进营地再炸营房，接回闪光俘虏，武器重新升级。后面还有修理补给，掉血也有机会救回来。

废墟城这一趟，十五个人也全部送到了。穿过石桥，继续往北打。

第二关的关底换成四座石像。对准石像开火，还要留意追过来的导弹和坦克。最后一座打掉，两关通了！

方向键移动，机枪跟着车头转，手雷也朝车头扔。按一下 C，还能切换俯视和近景。
