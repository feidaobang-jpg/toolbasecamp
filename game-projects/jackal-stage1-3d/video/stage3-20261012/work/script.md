# 解说稿（v0.11.0 第三关更新）

**01-hook**　赤色要塞第三关，码头尽头停着一艘战舰。六座炮塔，得一座一座打掉。

**02-sink**　最后一座炸掉，整艘船起火下沉。喜欢这种打法，顺手点个赞。

**03-why**　这款是我几个复刻里玩的人最多的，可它一直只有两关。这次照着原版第三关的地图，把整个港口搭了出来。

**04-first**　第一版刚跑起来就闹了笑话：地上的箭头全画成了字母 Y，海水亮得像游泳池，战舰的舰桥黑成一团。

**05-fixed**　改完之后，才像个正经港口。

**06-before**　还顺手查出一个老问题：新玩家进场站着不动，八秒就会被打死。

**07-after**　现在你不动，敌人就先不开火，屏幕上还会提示怎么开车。

**08-pier**　回到关卡里。两条栈桥并排伸进海里，两边的炮艇夹着你打，另一条桥上还有坦克堵路。

**09-star**　停车场里停着的吉普别放过。炸开这一辆，里面藏着一颗星。

**10-corridor**　最难的是仓库之间的之字通道，炮台贴着墙排成一排，这一趟就在这儿被打翻了一次。

**11-pad**　把十二个人全部送上直升机，再炸开最后一道闸门，就到码头了。

**12-front**　按 C 换成低位视角，整个港口就立在你眼前。

**13-end-bili**　第三关已经上线，点视频下方的 Toy 入口就能玩，电脑手机都行。原作一共六关，下一关想先看哪个，评论里告诉我。

**13-end-generic**　第三关已经上线，网页版电脑手机都能玩，入口在简介里。原作一共六关，下一关想先看哪个，评论里告诉我。

说明：
- 结尾有两版：`13-end-bili` 讲「点视频下方的 Toy 入口」，只用于 B 站；`13-end-generic` 讲「入口在简介里」，用于抖音和 YouTube。
- 「玩的人最多」依据 2026-10-12 的 `toy stats`：近 4 天日均访客赤色要塞 593，高于恐龙快打 147、超级玛丽 231、坦克大战 225。
- 「八秒就会被打死」依据改动前的实测：6 个随机种子，进场后不操作 7.7–9.0 秒第一次阵亡。
- 「这一趟就在这儿被打翻了一次」是这次录像里的真实结果（原片 91.9 秒阵亡），录像由自动试玩机器人按正常规则游玩，没有开无敌。
- 「十二个人」是这次录像实际送达的人数（第三关一共 12 名）。
