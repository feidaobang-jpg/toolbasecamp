# 第一关开发记录

按用户确认的第一类开发：完整第一关Demo，统一3D、网站手机双端和C单键视角。保留原版自动攻击、武器与技能概念，独立制作山寺场景和27敌的完整挑战。

静态环境首次约350次绘制，按材质合批后初始约78次。实测活动场景约111次绘制，RTX4060Ti浏览器采样约168–170fps，不是手机性能承诺。

真实问题：已死敌人hit计时不递减导致尸身残留。保留修复前截图与录像，改为移除死亡敌人，逻辑检查和完整正常通关复测通过。另补充检查点复活时敌人类型变化的模型替换与重新开始的模式标签刷新。

最终实机通过默认正常数值的键盘自动操作通关，未使用无敌、传送或时间压缩。死亡专项测试仅在QA响应注入低生命，以验证三次复活和演示模式；未暴露测试全局给发布版。

原片保存在captures，不自动上传；后续视频素材状态partial，须听审独立音轨并补同步游戏音轨。旧2D文件保留，游戏中心改指向3D第一关。
