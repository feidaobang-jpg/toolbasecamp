# 亮剑：攻打平安县城（重做版）

一句话：你是李云龙，带独立团扫清城外，把意大利炮拉上来，喊一声“开炮”轰开城楼，再打进县城和山本一木拼刀。

这是用户 2026-10-13 要求的本地重做版：对照《枪火集结》抗战战役里的平安县城一章，**没有阅读也没有沿用原实现代码**，玩法、画面、数值、关卡全部重新设计。只在本地运行，未接入网站列表、未发布。

当前版本 v0.2.0（2026-10-13）：按用户选定的枪战类操作规范，从“四视角自动锁定的街机动作”改成“越肩第三人称 / 第一人称、自己瞄准的枪战”，并加了跳跃。v0.1.0 的做法见 `releases/v0.1.0/notes.md`。

## 已实现（implemented）

### 一关五个阶段（尚未有人试玩；手动瞄准的自动脚本三档耐久约 3 分到 4 分半打完，真人用时没有数据）

1. **扫清城外**：端掉城外两处机枪阵地。阵地正面沙袋打不穿，要绕到腰高的侧面（可以跳进去）、踩弹药箱上土坎顶从高处打、扔手榴弹或叫骑兵连；路上的铁丝网走不过去，要跳。拔掉第一处后城门口有一波反扑。
2. **拉炮上阵**：“二营长！你他娘的意大利炮呢？”——护送炮组把炮推到炮位。鬼子靠近 17 米内炮就推不动，侧翼有几波冲击，城墙上的掷弹筒用地面红圈预警。炮被打坏＝本阶段重来（核心失败条件）。
3. **开炮！**：走到炮旁按 F（手机点“操炮”）上炮。转视角或 A/D 转炮口、W/S 或 Y/H 调仰角，画面上有弹道线和落点圈，对准目标后变绿；开火键开炮。先敲掉城墙上两个机枪堡、轰开城门，最后瞄准城楼——“开炮！！！”城楼塌掉。炮弹 8 发，打光后和尚会扛来。再按 F 离开。
4. **打进县城**：冲锋号响，沿主街打街垒（沙袋只有胸口高：能隔着沙袋对射、打守军露出来的上半身，也能直接跳上去或踩箱子翻过去）、十字街口机枪阵地（旁边的箱子台阶能上矮棚顶，从侧面打）、小巷里钻出来的援兵和山本特工队。路口东边的院子是军火库，进去就“发财了”：换歪把子机枪并补满。
5. **决战山本一木**：守备队部院子里的 Boss 战。三连点射、扔手雷（红圈预警）、拔刀突进（地上红条预警）；血量 62% 和 32% 时各叫两名特工队，最后阶段会连续突进两次。突进有三种应对：侧移躲开、**跳起来躲开**、或者按亮剑撞上去＝**拼刀**，山本被震开露出破绽。

### 射击（固定一档辅助）

- 自己把准星对到敌人身上，按住开火键才打。准星离敌人身体很近、而且中间没有掩体时子弹会被吸过去，这时准星变红；用触屏或 Q/E/Y/H 转视角时，准星经过敌人会变慢、开火时轻轻拉向目标；用鼠标时只有子弹吸附。
- 子弹是有飞行时间的实体，从枪口飞向准星指的地方，会被沙袋、土坎、房子挡住。打中头部伤害 ×2，有单独的提示。
- 驳壳枪弹匣 20 发、歪把子 40 发：打空自动换弹，也可以按 R 提前换；换弹时不能开火。
- 开镜：视野收窄、散布变小、走得慢，第三人称镜头拉近。

### 动作

- **跳跃**：约 1.3 米，空中能调整方向，没有二段跳。能落在弹药箱、土坎顶、棚顶、阵地侧墙上；房顶、城墙、树站不上去。
- **手榴弹**：3 颗，约 12 秒回 1 颗，朝准星指的落点抛（6～20 米），抛物线越过掩体。
- **亮剑**：抽大刀沿镜头前方突进约 10 米，沿途伤敌并短暂无敌，冷却 7 秒。
- **骑兵连**：“骑兵连，进攻！”五骑从身后两侧冲过去，冷却 45 秒；城里沿主街冲，Boss 院子里进不来。

### 梗（都是玩法触发，不是只有文案）

开炮（每一炮都有大字、弹幕和喊话）、“二营长，你他娘的意大利炮呢”、“给我拉上来”、“你他娘的还真是个天才”（一炮三杀或首次直接命中机枪堡）、“骑兵连，进攻”、“什么他娘的精锐，老子打的就是精锐”（第一次干掉特工队）、“这辈子没打过这么富裕的仗”（缴获军火库）、“狭路相逢勇者胜”（拼刀成功）、亮剑、“晋西北乱成了一锅粥”（胜利），以及楚云飞、丁伟、孔捷、旅长的弹幕吐槽。弹幕可在选项里关掉。

### 视角与操作模式

- 两个视角（C 切换，切换时瞄准方向不变）：越肩第三人称（默认，主角在画面中间偏左、准星在正中）和第一人称；操炮时对应炮后视角与炮手视角。
- 向右拖向右看；第三人称可以上下看约 −50°～+42°，第一人称 ±60°。镜头被墙、箱子挡住会拉近，贴镜头太近的战友隐藏，挡住主角的城楼、门洞、房子变透明。跳的时候镜头不跟着上下晃。
- 自动识别 / 电脑键鼠 / 手机触屏三种操作模式，随时切换不丢进度。手机竖着拿时从标题菜单起就旋转成横屏。

### 选项

起始阶段（1～5 直达）、命数（无限命 / 经典 3 命）、耐久（标准 5 格 / 宽松 8 格 / 一发 1 格）、演示模式（无敌，每次载入为关，演示局不计最高分）、视角、画质（自动 / 高 / 流畅）、音量、弹幕、触屏按键、帧率显示、瞄准灵敏度（低 / 中 / 高）、鼠标瞄准（按住拖动 / 鼠标锁定）、左手开火键、操作模式、全屏。暂停菜单另有：继续、从本阶段重来、重新开始、返回主菜单。

### 生命与补给

默认无限命：阵亡约 2 秒后在最近的安全点满血复活，带 2.6 秒保护。受击后短暂无敌、角色闪红、屏幕红边；只剩 1 格时血格闪烁并有红边提示。急救包位置固定（每拔掉一处阵地、清掉一段街道各出一个，Boss 院子两个），一个 +3 格，满血时留在原地；一发模式下折成战功。每进入新阶段补满。

### 声音

全部由 WebAudio 程序合成（原创）：枪声、机枪、爆炸、炮声、军号、拼刀、马蹄、跳跃、鼓点与铜管背景乐。十句喊话用本机 IndexTTS 合成（不是演员原声，没有截取电视剧音轨）。暂停、切后台时声音冻结，继续、重开、回主菜单再开局都会恢复。镜头不震动。

## 省略与替换（按题材）

- 视角只有两个，没有俯视、高位等预设：按用户 2026-10-13 定的枪战类规范（game-maker 的 `references/shooter-controls.md`）。
- 手机动作键不是 2×2 方阵，而是枪战布局；同一规范。
- 没有“返回游戏列表”等跳出链接，也没有任何网站账号入口；主菜单只有一个玩家主动点才打开的“作者B站主页”。
- 复刻类的“原作生命规则”不适用（原创设计），用“一发 1 格”作为硬核选项。
- 不做联机（用户此前决定暂缓）。

## 已知限制

- 手动瞄准的手感、吸附强弱、难度和跳跃手感都没有真人试过；数值是按自动脚本调的。
- 手机只做过浏览器触控模拟，没有真机验收；性能只在本机（RTX 4060 Ti）测过。
- 鼠标锁定只在无头浏览器里验证过；在 Toy 这类内嵌环境里可能拿不到锁定，所以默认是按住拖动。
- 喊话语音是机器合成，我没法试听，音色和语气需要用户听一下。
- 敌人和战友没有真正的寻路，只会贴着障碍绕；步兵被掩体挡住射界时会斜着往前绕出来，但不会找掩体躲。城里靠街道宽度兜住。战友不会跳，铁丝网只挡主角。
- 机枪阵地正面的沙袋（1.6 米）是故意打不穿的，要绕侧、上高处或用手榴弹；街垒是胸口高，可以对射。
