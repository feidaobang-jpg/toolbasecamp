# v0.4.0 开发记录（2026-10-14，亮剑、骑兵连、拼刀加回）

## 本次目标

用户原话：「亮剑、骑兵连，连带和山本“拼刀”也去掉了，山本突进靠侧移或跳起来躲。这些我又想加回来了。那快捷键你怎么安排？」

## 键位怎么排的

v0.2.0 时这两个技能在 U / I；v0.3.0 去掉技能后，U 给了手榴弹、I 给了互动（和《枪火集结》其余模式一致），这两个位置不想再动。于是：

| 技能 | 纯键盘 | 鼠标手（左手在 WASD） | 手机 |
| --- | --- | --- | --- |
| 亮剑 | L | V | 亮剑键 |
| 骑兵连 | N | X | 骑兵连键 |

- L 紧挨着 K，在 J K L 这一排上，右手不用离开位置；N 在 J 的下方。右手六个键：J 开火、K 跳、L 亮剑 / U 手榴弹、I 互动、O 开镜，外加下排的 N。
- N 在《枪火集结》战地模式里是“兵种支援”，叫骑兵连也是叫支援，同一个键一个意思。
- V / X 就是 v0.2.0 里鼠标手用的那两个键，没变。
- 代价：L 在 v0.3.0 里是换弹的别名（R / L），现在让给亮剑，换弹只剩 R。

这是我定的，用户还没看过；不顺手的话改一行映射就行。

## 改了什么（相对 v0.3.0）

- 亮剑突进、骑兵连冲锋、亮剑撞上山本突进的“拼刀”三样都加回来，代码是从 v0.2.0 的提交里原样取回的；两句语音（“骑兵连，进攻”“亮剑”）也放回来。
- 和 v0.3.0 新东西的衔接：在阵地机枪上不能亮剑（人是固定的），可以叫骑兵连；操炮时同理。
- 右下状态条回到四项（J 开火、U 手榴弹、L 亮剑、N 骑兵连）；手机上两个键放回 v0.2.0 的位置。
- 底部按键提示改成按项换行（原来一行放不下时会把“切换人称”拆开），状态条里已有的 U / L / N 不再在提示里重复。
- 战报恢复“拼刀成功”“骑兵连出击”两行；胜利时不再另外打一次“狭路相逢勇者胜”（拼刀成功时会打）。
