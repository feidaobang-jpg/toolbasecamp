# v0.6.0 开发记录（2026-10-14，亮剑战役：苍云岭重做）

## 本次目标

用户原话：「亮剑的其他两个模式现在要做吗？如果做的话我需求不太明确，你来制定后让我选择或输入吧。舍弃原来的玩法，画面，控制，按钮等，完全重新做，参考第三章。」

经过三轮问答（grilling）定下来的做法：

- 现在就做，一章一章来；每章做完就发网站和 Toy，用户试玩后再做下一章。两章是**苍云岭**和**李家坡**（不做骑兵连那章），菜单按原作时间排成第一章苍云岭、第二章李家坡、第三章平安县城，先做苍云岭。
- 三章放在同一个「亮剑战役」页面，共用引擎，在它自己的菜单里选章；枪火集结的章节卡片直接进对应章节；平安县城并进来，旧地址跳转、进度保留。
- 每章和平安县城一样大：五个阶段、有 Boss、真人约 8～12 分钟；操作、界面和平安县城一致（只加本章必需的键），亮剑 L / 骑兵连 N 每章都有。
- 用《亮剑》原声：下载前列出片段（BV、时长、大小、用途）给用户确认——用户同意了 BV1Ef421B7CK（第 1 集 01）、BV1BS411w7AU（第 1 集 02）。原声没有授权，用户已知 Toy 可能退回。
- 新章节上线时删掉对应的旧实现，旧存档跳转。章节发布后先把 B站视频简介的改法拿给用户看，同意再改；三章都做完再做新视频。
- 苍云岭：①坚守山头（掩护师部和野战医院转移，进度条约两分多钟走满）②抓舌头（把带臂章的军曹打倒，走过去按 I 抓活的；打死了就换一个）→ 过场“坂田联队……老子打的就是精锐！全体上刺刀” ③送炮前出五百米（望远镜看见山坡上的帐篷，柱子说够不着；护送炮组，炮组被打散回检查点；旅部突围命令、楚云飞一个镜头）④两发炮弹（亲手瞄，没有落点预览，柱子报第一发偏了多少；第一发落地看得见）⑤打中任何一发＝原作：坂田被炸死、“打中了”、全团冲进指挥部再突围；两发都偏＝坂田 Boss（躲在掩体后指挥，叫掷弹筒和机枪、派卫兵冲锋，血少了拔刀突进），再突围。结算写走的是哪条线。场景：1940 年 2 月晋中山区，冬天、黄土压雪、枯树、阴天，帐篷在山坡下，和平安县城同一种低模画风。

## 改了什么（相对 v0.5.0）

### 引擎与页面

- `public/html/game/gunfire-assembly/pingan/` 改名为 `liangjian/`（亮剑战役），引擎 `js/game.js` 与章节 `js/chapters/*.js` 拆开：章节继承引擎、覆盖“章节钩子”（场景、火炮配置、阶段流程、目标、标签、Boss、结算等）。平安县城的代码搬进 `chapters/pingan*.js`，行为不变。
- 菜单多一排选章按钮（李家坡显示“重做中”）；换章重新载入页面。存档前缀改为 `lj_campaign_v1_`：设置共用，进度 / 最高分 / 结局按章节分开（`cp_<章>`、`best_<章>`、`ending_<章>`），第一次打开时把旧的 `lj_pingan_v1_` 搬过来。
- 旧地址 `pingan/index.html` 只剩跳转页，带原参数跳到 `liangjian/index.html?ch=pingan`。
- 引擎补的通用能力：操炮镜头可由章节覆盖（迫击炮的瞄准镜）、操炮时可显示准星、单位外观 / 血量可单独指定、“打残不打死”（抓舌头）、章节每帧更新、进度条名称可换且只有“炮组”会标红、望远镜遮罩、语音清单按章节分组（每章只下载自己的）、过场里清掉互动提示。

### 苍云岭（新）

- 场景：`chapters/cangyunling-world.js`。南边我方山头阵地（胸口高的沙袋线、两挺可接管的机枪、山后转移小路），中间开阔地（土坎、弹坑、枯树、铁丝网），北边鬼子前沿与第二道线、两个掷弹筒坑，五百米外的炮位，山坡下坂田的指挥部（三顶帐篷、电台天线、太阳旗、门口沙袋和机枪阵地），东边山口是突围口，东边山梁上是 358 团的观察所。场外按距离抬成积雪的山坡，阴天、小雪。
- 新人物与道具：军曹（臂章）、虎子、柱子、坂田（眼镜、披风）、楚云飞与参谋、担架队；迫击炮、担架。
- 五个阶段（`chapters/cangyunling.js`、出兵与 Boss 在 `cangyunling-ai.js`）：
  1. **坚守山头**：转移进度约 140 秒走满；阵地前沿有三个以上鬼子时进度停下。七波进攻（步兵、举刀冲锋的军官、两侧绕上来的、端冲锋枪的精锐），一门掷弹筒打阵地。走满后原声“张大彪，师部和野战医院转移了没有——已经全部撤离”。
  2. **抓舌头**：军曹挨子弹只倒地不死（倒地后再挨枪也不死），手榴弹、炮弹、亮剑、骑兵连会把他弄死——记一次“下手太重”，换一个军曹。走到跟前按 I（手机点“抓俘虏”）进过场：原声“日军第四旅团的坂田联队——怎么听着这么耳熟”“团长，他们可是号称鬼子的精锐——什么他娘的精锐……老子打的就是精锐！全体上刺刀，准备进攻！”。
  3. **送炮前出**：望远镜过场（双圆遮罩）里坂田站在帐篷前——“老天爷帮忙啊”“你的炮够得着吗——超出射程了”“向前推进五百米，准行——只有两发炮弹了”“你个败家子儿”。之后护送柱子的炮组沿路线前出，16 米内有鬼子就停下；炮组被打散回本阶段起点（不重放过场）。途中原声“前方五百米，为炮兵赢得时间”、旅部突围命令和李云龙的回绝。到炮位后切到 358 团观察所：楚云飞“得想办法支援他们一下”“此事恐怕我们无能为力”。
  4. **两发炮弹**：“快，就放这”“半斤地瓜烧……打不中我还得枪毙你”。上炮后 A/D 转炮口、W/S 调仰角（越低越远），屏幕中间准星对方位，界面显示仰角和**表尺（平地射程）**，没有落点预览。炮弹会被西风往右吹约五米，柱子会提醒“往左带一点”。出膛后镜头侧面跟着炮弹飞、落地凑近看；没中时柱子报“远了 / 近了 / 偏左 / 偏右多少米”（远了时李云龙原声“打歪了！指挥部在下边”），并提示怎么修正。会打中的那一发落地前一秒放“联队长，危险！——柱子，打得好！打中了”，帐篷变废墟，再一句“你他娘的还真是个天才”。
  5. **突围**：
     - 打中（原作）：“柱子！弟兄们，冲啊”，冲进指挥部，“大彪，看看这一网捞了多少大鱼”，两侧鬼子压上来，顶住一阵后“团长，突围吧——继续攻击，打出去”，从东边山口突出去。
     - 两发都偏（改写）：坂田“我倒要拭目以待……很有意思”、李云龙“坂田这个兔崽子，我非砸碎了它不可”，再“狭路相逢，勇者胜”。坂田（200 血）躲在门口两段沙袋后打手枪、轮流下令（掷弹筒齐射 / 两名军官冲锋 / 补机枪手），66% 时叫第五大队增援，33% 时“不是他疯了，就是个阴谋”拔刀突进（红线预警，可侧移、跳起或亮剑拼刀）。打死后同样突围。
     - 进第五阶段换歪把子。突围成功后切到楚云飞：“干得漂亮，这是八路军哪支部队——团长叫李云龙”。结算写结局线（第几发打中 / 手刃坂田）、抓舌头打死了几个等。
- 局内原声排队：上一句没放完不叠下一句；换阶段时掐掉上一阶段没说完的；跳过过场时一起停。
- 25 句原声截自两个片源（时间点见 `media-kit/assets/voice.json`、截取脚本 `tools/cyl_voice_*.py`），加上平安县城的亮剑、骑兵连、天才三句，共 28 条，约 1.4MB。

## 开发中修的问题

1. 过场开始时“按 I 抓活的”之类的互动提示还留在画面上（引擎在过场里提前返回，没清提示）——过场里统一清掉，平安县城同样受益。
2. 迫击炮最初沿用了意大利炮的镜头（炮手视角按仰角往天上看，第一人称看不到指挥部）——改成贴着炮身往前看的瞄准镜（拉近）和炮后高位视角。
3. 楚云飞观察所的沙袋参数传错，立起来成了一块斜板；镜头钻进山坡——重摆沙袋、加土台，镜头按地形抬高。
4. 抓舌头的分组名和第一阶段进攻分组前缀撞了（`P1x`），改成 `T`。
5. 炮组路线走完后再进一帧会越界读取路线点（测试摆位时报错）——先判断再走。
6. 自动通关里第一阶段阵亡 6 次，全是两门掷弹筒的爆炸（步枪子弹全被沙袋挡住）——第一阶段只留一门，打主角的比例降到四成，阵亡降到 2 次。
7. 局内两句原声会叠着放（旅部命令触发时“前方五百米”还没说完）——加了局内原声排队，换阶段时掐掉上一阶段没说完的。

## 需要用户知道的

- 原声没有授权（用户已知 Toy 可能退回）。苍云岭这 25 句没有合成版，被退回时只能先去掉声音（只剩字幕）或用本机 IndexTTS 重新合成。
