## 改了什么（相对 v0.6.0）

### 引擎（三章共用）

- 地形：`world.hgt(x, z)` 有就按地形走（平地章节没有，行为不变）。主角、敌我单位、子弹落地、手榴弹 / 炮弹 / 掷弹筒落点、机枪、拾取物、尸体、镜头防钻地都按地形算；搭在坡上的碰撞盒记 `base`，按离地高度判断能不能站、挡不挡镜头和视线。
- `setLight()` 按阶段换光（雾、天光、太阳）；`heroCover()` / `allyCover()` 让章节决定一部分子弹打在掩体上（交通壕）。
- 坡上的预警圈、冲击环、焦痕贴着坡面倾斜，突进预警条沿坡度抬起 / 压低；远处烟柱从地面起；骑兵在坡上也认得沙袋、碉堡（按离地高度判断能不能跃过）。
- 战友不打本章标了 `noAlly` 的目标（山崎：“谁也不许开枪，给我留着”）。
- 战友给主角让路：两人挤在一起时只推开战友，主角不会被自己人挤开（之前各让一半，手机测试里主角松手后还会被跑过的战友挤动一点）。

### 李家坡（新）

- 场景 `chapters/lijiapo-world.js`：南边山脚的出发阵地（独立团、七七二团两道沙袋线），中间一面朝南、下缓上陡的黄土坡（高 14 米，坡顶看得到整面坡），坡上弹坑、铁丝网（挡在两个外围火力点正面）、枯树、石头；山脚两个外围火力点在挖平的小台地上；坡顶是环形工事——南面三个混凝土碉堡（炸塌后变碎块、成了缺口）、外墙内墙两道沙袋夹着的环形战壕、中间山崎的指挥所（四个射击孔、正门、太阳旗）、北面帐篷。坡上的之字形交通壕约 75 米，按挖掘进度一段段出现（实例化的壕底、两侧土埂；土埂只拦主角，跳得过去）。
- 新人物：山崎（黄呢军服、白手套、军刀、仁丹胡）、孔捷（过场）；挖壕的铁锹。
- 五个阶段（`chapters/lijiapo.js`，出兵与山崎在 `lijiapo-ai.js`）：
  1. **强攻受挫**（黄昏）：开场孔捷“坐冷板凳”。七七二团每二十多秒冲一次坡，冲到半坡被坡顶机枪扫倒或压回来（演出）；主角进到坡中间的封锁区，碉堡机枪先在脚下亮红圈再扫。先拔左边火力点（原声“七七二团又撤下来了——第八次了”，坡上下来一股增援），再拔右边（路上程瞎子电话“捞现成的”）。火力点正面沙袋打不穿，正面有铁丝网，要从侧面绕。拔完进过场：李云龙讲“缩短攻击的距离”、参谋问“土工的方式进行掘进”，天慢慢黑下来。
  2. **挖交通壕**（夜里，飘小雪）：原声“告诉你们程瞎子……站在山坡下学着点儿”“部队全部运动到山坡的下边……剩下的三十米，就是个娘们儿都能把手榴弹扔进环型工事去”。走到壕头的铁锹那里按 I（手机点“挖壕”）开挖，走动、开枪或再按一次就停；主角每秒挖 0.9 米，两个战友各 0.22 米（附近有鬼子或照明弹亮着时战友不挖）。壕里八成五的子弹打在土埂上，壕头只挡四成五，壕外不挡。夜里坡顶机枪朝壕头瞎扫；每十七到二十四秒一发照明弹（点光源把一片坡照亮），亮着时机枪照着露头的人和壕头点射。挖到一成半、四成半、四分之三时鬼子从两侧摸下来；挖到三成半坡顶掷弹筒开始砸壕头（摸黑时四成不打）；挖到六成多山崎“立刻开炮，把炮弹通通给我打光”，沿交通壕落九发炮。中间放“每个人十颗——三千六百颗”和日军“新上来的八路在掘土”。
  3. **手榴弹雨**（拂晓）：过场里张大彪“拿不下李家坡您也甭枪毙我……没人会活着退出战斗”、李云龙“手榴弹一响，全团人人上刺刀”、孔捷“快憋疯了”，天亮起来。原声“我这里信号弹一响……两分钟之内必须全都扔出去”后升起红色信号弹，开始两分钟倒计时。准星抬到坡顶，落点圈（12～46 米）罩住目标按 U（手机“全营投弹”）：每轮三百六十颗，十六颗手榴弹从壕里飞出去落在圈里，约 3.2 秒一轮；碉堡挨八下塌。两分钟到了或扔完还剩碉堡，张大彪抱着集束手榴弹补上（少算分）。
  4. **突击队**（白天）：过场“准备白刃战……见着山崎那小子，谁也不许开枪，老子要活劈了他”。冲锋号，张大彪“拿出野狼的劲头来”，孙德胜“咱们是骑兵，没有马也该比步兵快”。南面战壕的鬼子端着刺刀冲出来，东西两段守着；南面拿下后和尚和战士“俺包圆了——平分”，北面再反扑一股。工事里有一箱歪把子。
  5. **决战山崎**：喊话员的决斗挑战（39 秒原声）。指挥所四个射击孔各管 62° 扇面，主角进扇面就点射；从侧面把手榴弹扔到孔边（一颗只炸哑最近的一个）。四个都哑了山崎带两个卫兵冲出来：“什么乱七八糟的，还都以为自己是中世纪的骑士……混蛋，攻击！”。山崎（150 血）架着刀时子弹全被格开（火星、金属声）；连砍三刀（红圈预警，二阶段四刀）或突刺（红线预警）后收刀喘气，这时子弹 ×1.5；突刺时亮剑撞上去拼刀，震住 2.8 秒（伤害 ×2）；手榴弹只伤一半；战友不朝他开枪；血少过半叫卫兵。倒下后“快，尽快解决残敌”，太阳旗拔掉。
- 19 句原声截自两个片源（时间点与字幕见 `media-kit/assets/voice.json` 的 `lijiapo`，截取脚本 `tools/ljp_voice_*.py`），加上亮剑、骑兵连、精锐、发财四句共 23 条。局内原声排队；过场开始时掐掉局内还没说完和排着队的。
