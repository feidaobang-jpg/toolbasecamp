## 做了什么

拔刀近战（取“简化版天国拯救”：不分方向，只有轻 / 重 / 格挡 / 弹开）
- Q 拔刀 / 收刀（触屏“拔刀”键）。刀在手时不能开枪、开镜，蹲 / 趴会先收刀；上炮、上机枪自动收刀。第一次拔刀喊一声原声“亮剑”。
- 左键轻砍，挥刀途中再按接下一刀，三刀一套（右上斜劈、左上斜劈、正劈）；按住左键超过 0.32 秒松手或蓄满 0.75 秒出重砍，往前带一步、贴着敌人就停。
- 伤害：轻砍 2（鬼子步兵一刀倒）、重砍 5；对 Boss 轻 4、重 12。重砍让非 Boss 踉跄、破军官和 Boss 的格挡。
- 敌人格挡：拿刀的军官正对着时格开约三成轻砍并马上反砍；Boss 在游走时格开约七成（山崎沿用原来的“架刀”状态）。
- 右键（触屏按住“格挡”）格挡：挡住刀不掉血、被震退；刀砍到前 0.25 秒内按下＝弹开：军官踉跄 1.4 秒，山本 / 山崎 / 坂田的突进被弹开就是拼刀（硬直 2.8 秒、掉血），山崎连砍被弹开这一套就断了。挡不住子弹。
- 模型：拔刀时背上的刀藏起来、右手的驳壳枪换成空手，刀挂在新加的“手腕”上能立起来；第一人称的大刀按手的位置和刀身朝向摆（架刀、格挡横刀、对角劈下）。

蹲下 / 趴下
- C 蹲（再按站起），Z 趴（再按站起）；跳、Shift 往前都会站起来。触屏“姿势”键站→蹲→趴轮换。
- 子弹按姿势身高判定（站 2.05、蹲 1.4、趴 0.62 米；趴下身体沿朝向摊开，分三段判定）；敌人瞄胸口高度（站 1.1、蹲 0.75、趴 0.3 米），射界也按这个高度算，所以蹲在沙袋后它们会去绕位。
- 趴下躲大半手榴弹破片（只有很近才伤到）；速度蹲 0.55、趴 0.25 倍；镜头蹲低 0.5、趴低 1.2 米，第一人称趴下时眼睛往前到头的位置。
- 模型：蹲是单膝跪，趴是整个人向前放倒，举枪时双臂朝前、枪口贴地。

其他
- 骑兵连技能去掉（按钮、状态条、E / N 键、结算里的“骑兵连出击”）；剧情里孙德胜的台词和原声保留，`buildRider` 与 `qibinglian` 语音没删。结算多一行“弹开”。
- 山本扔手榴弹只在 25 米以内。
- 开炮卡顿：实测第一次开炮时会新编译一个着色器（这台电脑上编得快不卡，但 Windows 上有的浏览器一次要几十到几百毫秒）。现在载入和换画质时把平时藏着的爆炸、圈、炮弹等先显示一次统一编好（`warmShaders`），第一次开炮不再新编译。用户那台电脑上是否就是这个原因没法直接确认，如果还卡请再说。
