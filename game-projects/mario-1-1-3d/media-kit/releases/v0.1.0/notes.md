# v0.1.0 — 2026-09-29

首个版本。FC 1-1 完整 3D 化：?砖块（金币/蘑菇）、砖块（大马力奥可碎）、4 根水管、
两段深坑、上下阶梯 + 8 级终盘阶梯、旗杆（高度奖励 + 滑旗动画）与城堡、16 只板栗仔
+ 1 只乌龟、漂浮金币弧线、100 金币 1-UP、中途检查点（x=102）、240 秒限时。

- 平台：桌面键盘 + 手机横屏触控（虚拟摇杆/动作键/相机盘），竖屏自动旋转布局
- 音频：原创 8 小节 chiptune 循环 + 14 种振荡器音效
- 已知取舍：乌龟无龟壳踢击机制（踩踏即消灭）；`?-`砖顶出蘑菇走直线不折返；
  顶砖不震落砖上敌人
