# 超级玛丽 3D：1-1、1-2 与 1-3

FC《超级马力欧兄弟》的原作地图搬进 3D：顶砖、拿道具、踩敌人和跳平台，采用自然色哑光低模画面，可以自由转动镜头。

当前正式版本 `v2.5.0` 增加 WORLD 1-3 树冠关，保留最新 v2.4.7 的 1-2 钻管过场。用户已确认第三关效果并授权发布，各渠道实际状态见版本 handoff。

试玩入口：https://www.zhengxiaohui.cn/html/game/mario-3d/index.html?level=1-3

## 一句话玩法

从左跑到右，顶砖拿道具、踩敌人、跳过断崖，最后拔旗进城堡；1-1 进入地下 1-2，再接树冠 1-3。第三关在高低树冠与往返浮台之间跳跃，飞行乌龟第一次踩掉翅膀，第二次踩成龟壳。三关可直接选择起始关卡；传送区仍单独结算。

## 操作

- 电脑：WASD / 方向键按水平镜头轴移动，K 跳（按住跳更高），I 冲刺，U 下蹲 / 钻水管（L 兼容），J 火球与旧跑键兼容，Q/E 转镜头，C 切换五种视角，Esc 暂停；菜单 ↑↓ 选择、←→ 调整、Enter 确认。
- 手机：左下摇杆，右下 U金 / I蓝在上、J红 / K绿在下的等大 2×2 动作键；右上视角、暂停、全屏。竖着拿时标题菜单就按横屏布局旋转；全屏按浏览器能力显示。
- I 点按或按下开启冲刺，松开 I 仍跑，方向归零后停止；可先按 I 再移动。第三关远跳先跑起来再起跳。J 未吃火焰花时仍显示实心红色按钮和“需火焰花”，点击给提示。
- 自动识别 / 电脑键鼠 / 手机触屏可在菜单点击或用键盘切换，保留本局进度。画面空白处上下左右拖动观察。

## 规则

- 小玛丽顶问号砖出蘑菇，大玛丽出火焰花；吃花后 J 放火球。大玛丽能顶碎普通砖块。
- 无敌星 10 秒内碰谁都赢；金币满 100 奖命；踩敌连踩分数递增，到顶奖命。
- 1-1、1-2 时间 400，1-3 时间 300，耗尽就输一次。掉坑、被敌人碰到会输一次（标准耐久下小玛丽有 3 格护心）。
- 过中途点后从中途点继续；输掉时变回小玛丽。

## 已实现（implemented）

- `level-1-1`：原作 1-1 地图、地下奖励房间（第 4 根水管进，19 枚金币）、隐藏 1UP、10 连金币砖、无敌星砖、终点台阶旗杆城堡与烟花。
- `level-1-2`：原作 1-2 地下关、天花板 1UP、奖励房间、三根食人花水管、升降台、横管出口、地面出口区。
- `level-1-3`：按原作地图与坐标交叉核对的 17 组高低树冠、4 个往返浮台、23 枚逻辑金币、1 个道具问号砖、飞行绿乌龟、巡逻红乌龟与栗宝宝，终点台阶、旗杆和大城堡。树冠可从下方跳上，浮台会带着角色移动；检查点位于中段安全树冠。
- `warp-zone`：天花板上方通往传送区，三根传送水管 4/3/2（钻入后结算，原作后续世界未做）。
- `lane-3d`：所有地形沿纵深铺满跑道，水管纵向 3 根一排，不能绕过；台阶边缘不会掉下。
- `powerups`、`pipe-travel`、`crouch`、`enemies`（栗宝宝、绿/红乌龟、食人花）。
- `options`：起始关卡、命数（无限命 / 经典 3 命）、耐久（标准 3 格护心 / 原作）、演示模式（无敌）、视角、画质（自动 / 高 / 流畅）、音量、触屏按键、帧率显示、全屏、返回游戏列表。
- `cameras`：侧视（默认）/ 斜视 / 正视（身后肩上看向前进方向）/ 第一人称（玛丽的眼睛）/ 俯视，Q/E 无极旋转，遮挡淡化，镜头避让，地下关天花板与两端墙剖面。
- `mobile`：触控摇杆与按键、竖屏自动旋转、Toy 宿主 0×0 启动自恢复。
- `flow`：WORLD 卡片、复活、通关 / 传送 / GAME OVER 结算、最高分（演示局不计）。

## 限制

- 本版包含 1-1、1-2、1-3；没有 1-4 或完整八个世界，传送区不会真的去 2-1 / 3-1 / 4-1。
- 模型与贴图程序化制作；音乐与常用音效沿用已发布版本的原作录音，缺项或加载失败使用合成回退。奖励房间和 1-2 出口区布局有推测成分；1-3 浮台与飞行时序是本工程手感下的近似，不声称逐帧复刻（见 sources.json）。
- 第三关地形输入路线已从正常起点连续重放到拔旗结算，路线检查关闭敌人以隔离跳跃和浮台时序；敌人、道具、复活与关卡衔接另做针对性检查，未把这些测试称为普通带敌人全程通关。
- 没有真机测试；手机全屏与横屏锁定取决于浏览器。
