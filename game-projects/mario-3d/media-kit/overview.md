# 超级玛丽 3D：第一关

这是一个把经典横向平台关卡放进可前后移动 3D 空间的网页 Demo。玩家从起点出发，沿草地、砖块、水管、断崖和阶梯前进，跳跃顶砖、收集金币、踩过敌人，最后到达旗杆和城堡。

## 当前已实现

- `movement`: WASD 移动，J 加速，K 跳跃；手机左侧虚拟摇杆。
- `camera`: Q/E 旋转、R/F 俯仰、C 回正；手机右侧视角键。
- `platforming`: 地面、断崖、砖块、问号砖、阶梯和水管碰撞。
- `items`: 金币和蘑菇；蘑菇会让角色变大，变大后可顶碎砖块。
- `enemies`: 栗宝宝式程序化敌人，可巡逻、转向、被踩或撞击玩家。
- `finish`: 中途检查点、倒计时、旗杆、城堡、胜利/失败/重玩。
- `display`: 统一横屏；电脑键盘、手机虚拟摇杆和动作键；全屏请求失败时仍保留可玩视口。

## 本版限制

这是第一版可玩路线。没有任天堂原始素材、原曲、联网、存档或关卡编辑器；3D 角色和场景均为程序化原创表现。手机全屏与横屏锁定受浏览器权限和用户操作限制，实机验收结果以 handoff 中的 QA 记录为准。
