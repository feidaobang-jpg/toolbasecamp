# 自动横屏布局补丁

用户要求：手机竖屏点击开始后，直接旋转游戏为横屏布局，不显示横屏遮罩。初始菜单仍正常竖屏显示。全屏仅由按钮触发。

实现：开始后根据触屏设备及视口宽高切换90度容器旋转，交换逻辑宽高；摇杆屏幕坐标通过逆旋转映射；控件按容器尺寸布局。横竖切换时清空输入，重新计算相机尺寸。全屏作用于文档根元素以包含旋转容器。

验证：Edge headless触屏模拟390×844，开始后逻辑尺寸844×390、没有全屏、没有横屏遮罩；通过CDP真实触控事件验证摇杆右移，角色x从3移动到5.06；切换844×390恢复正常布局，切回后暂停按钮显示继续。已检查两张实机截图；录像无音轨，未完整审片，不标记视频素材就绪。未测试真实手机系统浏览器。
