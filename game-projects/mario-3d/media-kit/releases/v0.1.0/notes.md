# v0.1.0 开发记录

## 目标

把熟悉的第一关路线改造成一个不依赖鼠标、电脑和手机横屏都能玩的 3D 短循环，先保证“进入—移动—跳跃—碰撞—收集—到达终点—重玩”成立。

## 取舍

使用 Three.js 与程序化几何，避免引入外部素材和版权不明资源；使用 Canvas 纹理表现问号砖和砖块，让关卡识别度集中在路线与反馈上。相机默认跟随，Q/E/R/F 只承担视角调整，减少首次操作负担。

## 当前结果

已实现一条从起点到旗杆的连续路线、敌人、金币、蘑菇、检查点、胜负状态和桌面/触屏操作。媒体交接记录以真实浏览器截图和录像为准；如果本次环境无法获得真机触控或浏览器全屏授权，明确标记为模拟或部分验证。

## Bug 记录

本版没有为制造笑料主动引入 Bug。若实际试玩发现可复现异常，先把原片放入 captures，再填写 handoff.json 的 bugs；当前没有已确认的开发 Bug。
