# v0.1.1：修复电脑横屏被旋转提示遮挡

用户通过线上电脑浏览器报告遮罩，实际画面是横屏。此前关于窗口比例的解释不准确。

根因：原代码把 `rotate.hidden` 设为 `vertical || !running`。开始后 running=true 且 vertical=false 时，hidden 变成 false，反而显示提示。多次调整设备识别不能修复这个布尔逻辑错误。

修复：遮罩只在以粗指针且无悬停能力为主要输入的设备上，视口为竖向时显示；电脑窄窗口不显示。旋转仅阻止游戏推进并暂停，不把 running 清零，保留横屏后的继续入口。同时清空按键状态和摇杆位置，触屏控件在触屏设备上默认显示。入口提升 main.js 的版本参数。

验证：Edge 自动化浏览器中验证 1600×1317 与 700×1000 电脑视口，开始、全屏和调整尺寸均无遮罩；844×390 模拟触屏显示操作控件，切到 390×844 显示旋转提示且倒计时不变，回横屏点击继续后倒计时继续。无运行时错误。截图保存在 captures/，这是模拟设备验证，不是真机验证。

修复前证据来自用户本次聊天附件；没有另存为本版实机，也没有伪造复现录像。四张修复后截图可用于后续版本介绍，完整介绍仍需补拍较长的核心玩法录像。
