# v0.1.2：地面闪烁与绘制开销

## 真实原因与修复

原泥土中心 y=-1.05、高 2.1，顶面 y=0；草地中心 y=-0.07、高 0.14，顶面也为 y=0。两层完全共面，运行录像中地面在黄色泥土、绿色草地和条纹之间变化。这是几何深度冲突，不是用户显示器故障。

泥土顶面降到 -0.15，草地仍以 y=0 为顶面，因此碰撞高度不变。已看修复前后录像的连续抽样帧，转镜头和移动时草地颜色稳定。

重复静态网格按材质、几何和 24 单位空间区域实例化；阶梯也合批。土壤、地面和远景山不再做无用阴影投射，保留角色和互动物的阴影。关闭正常运行时 preserveDrawingBuffer；DPR 上限由 1.6 调到 1.5，申请高性能 GPU；HUD 文字未变时不重复写 DOM。

## 同条件测量

Edge 154.0.4258.37 headless，实际 GPU 为 NVIDIA GeForce RTX 4060 Ti / ANGLE D3D11，DPR=1。性能测量与录像分开。运行 QA 脚本注入只读统计入口，不在发布代码加入全局调试变量。

| 场景 | 修复前最大绘制次数 | 修复后最大绘制次数 |
| --- | ---: | ---: |
| 1280×720 移动 | 100 | 68 |
| 1280×720 转镜头 | 560 | 275 |
| 1600×1317 移动 | 84 | 63 |
| 1600×1317 转镜头 | 568 | 288 |

两版均约 170 FPS，P95 约 6ms，采样中无 >50ms 帧。批次包围盒会使部分不可见三角形一起提交，转镜头三角形峰值约 6.5 万变为 8 万；这是降低提交次数的取舍。不能把绘制次数减半说成 FPS 翻倍，也不能把本机结果当用户浏览器或手机的保证。

**尚未复现用户的严重卡顿。** 本版降低已识别的渲染开销，但用户设备/浏览器当前 GPU、硬件加速、DPR 和长时表现仍未知，性能问题保留待用户环境复测状态。
