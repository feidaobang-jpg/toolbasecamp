# v2.1.0：正视与第一人称

## 起因

v2.0.0 上线后用户问：“有横视、斜视，怎么没有正视？就是看向主角关卡前进的方向。”第三个视角“纵深”本该是身后上方，但上午为了避开镜头贴台阶的黑块，把它转到了玛丽左后方斜着看，看不到正前方。随后用户又要求：正视还可以切换到第一人称，代入感最强；并把这条写进 game-maker 规则。

## 做了什么

- “纵深”改成“正视”：镜头在玛丽身后肩上，看向关卡前进方向。W 前进、A/D 左右、Q/E 转。
- 正视后再按 C 是“第一人称”：镜头在玛丽眼睛高度（下蹲会变矮），不画玛丽自己；Q/E 转头，W 朝看的方向走；站着不动按 J，火球朝视线飞。死亡动画时暂时回到身后视角，看得清发生了什么；标题画面不会用第一人称。C 的循环变成：侧视 → 斜视 → 正视 → 第一人称。

## 过程中的取舍

1. 第一版正视用较高的追尾镜头（脚下约 5 格），走到砖块层、终点大台阶旁时，镜头经常落进方块里或被方块挡住，满屏都是半透明方块。
2. 加了“镜头避让”：镜头落进方块就往上抬，抬不了（天花板下）就沿视线往玛丽身后拉近。终点台阶后改善了，但从砖块层下面走过时视线仍被挡。
3. 最后把正视改成低机位：镜头约在脚下 2.6 格高。原作 1-1、1-2 的砖块层在 3～4 格和 7～8 格，这个高度刚好从砖块层下面看过去，还能看到头顶要顶的砖。镜头高度跟玛丽站的地面走、不跟跳跃。
4. 低机位带来新问题：跳高时玛丽跳出画面上方。改成镜头位置不动、看点随玛丽抬高（抬头看）。
5. 地下关左墙、奖励房间左墙在镜头外时会挡住整个画面：和天花板一样做剖面，把墙切掉；避让判定也忽略已经切掉的墙。

## 结果

- 回归 25 项通过；新视角测试全部通过；四种视角下电脑最慢帧 6.1～6.5ms。
- 实时录像：正视跳过水管、站上第二层砖，再切第一人称继续跑。
