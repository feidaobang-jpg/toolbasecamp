## 做了什么

- `levels.js`：新增 `build14()`。160 列城堡：台阶、4 处岩浆、7 根火棒、问号砖、6 块隐藏金币砖、13 格库巴桥、斧头、蘑菇人、桥上方往返浮台；地形逐格对照原作地图，见 [restoration.md](restoration.md)。
- `world.js`：火棒（转动与判定）、岩浆（沉下去就输）、库巴（来回挪、起跳、吸气喷火、被火球打 5 下现原形）、火焰（横飞并移到玛丽所在高度）、斧头之后的整段演出（断链 → 塌桥 → 库巴落下 → 城堡通关曲 → 走到蘑菇人 → 两行字 → 结算）。
- `scene.js` / `models.js` / `textures.js`：城堡主题。灰色哑光城堡石、背景石墙、跑道前方低一格的石地；会流动的岩浆，顶面亮斑、侧面一道浅色浪尖，坑上方有红光；火棒火球（加色光晕，沿纵深 6 份）；红褐色吊桥带护栏、铁链、斧头；库巴、火焰、蘑菇人的低模。俯视 / 斜视时按玛丽头顶那段天花板做剖面；Q/E 转到背面时藏起背景墙。
- `audio.js`：原版城堡曲 `sounds/castle.mp3`；接上已随包但没用过的库巴喷火、库巴落下、城堡通关原版音效。
- `main.js` / `index.html` / `style.css`：起始关卡多一项「1-4 城堡」、开场提示、斧头后的两行字（原作英文 + 中文）、城堡版结算文案、标题与说明改为“1-1 至 1-4”；传送区结算文案里的“只复刻到 1-2”顺手改成“1-4”。
- 网站游戏卡片副标题（`zh-CN.js`）改为「包含 1-1 至 1-4」，`games.html` 的语言包版本号相应递增；卡片封面沿用（主画面仍是 1-1，不是“点进去不是这款”）。
- `tools/build-toy.mjs`：允许 `TOY_VERSION` 指定版本号先给候选版打包；去掉一处过时检查——2026-10-10 主线去掉“返回游戏列表”后，main.js 里已没有那段列表地址，脚本原来会直接报错打不了包。

## 过程中遇到的真实问题

- **改库巴跳跃时把一个右括号注释掉了**：行尾加的说明吞掉了 `}`，整页 `SyntaxError` 打不开，截图脚本等 `__marioReady` 超时才发现；把说明挪到上一行。
- **城堡石在暖光下发棕**，不像原作的灰石；把顶光、主灯和玛丽身边的灯都改成中性偏暖，石头配色去掉黄味。
- **库巴跳起来头穿过上方浮台**：跳高从约 2 格降到约 1.6 格。
- **Q/E 转到正后方几乎全黑**：镜头在背景石墙外面，只剩玛丽周围一个淡化小孔；改为镜头转到墙后时隐藏背景墙，看到城堡剖面。
- **正视经过火棒时近处火球糊成一大片橙色**：火球也加入网点淡化。
- **玛丽身边的暖灯在近墙处打出一个白亮光斑**：调暗。
- **全程搜索一开始卡在第 95 列**：不是关卡过不去，是搜索在火棒前反复原地等，把关卡时间耗到只剩 20；给搜索加“同一状态（含火棒相位）只展开一次”后 322 个节点就找到路线。
- **正视版录像一开始没走到斧头**：正视下操作随镜头，D 是向右平移、W 才是向前；是游戏本来的相机相对操作，录像脚本按视角换键后正常。
- **旧回归测试有三处过时**：两份测试假设“1-3 是最后一关”（本次改动导致，改成过完 1-3 进 1-4、碰斧头后结算）；两份测试还在找火球键的“需火焰花”字样，那是主线 30147c57 早已去掉的提示（与本次无关），期望改为现行的“火球 + aria-disabled”。
