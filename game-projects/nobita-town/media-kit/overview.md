# 哆啦A梦小镇漫游 3D（nobita-town）· overview

- **入口**：`public/html/game/nobita-town/index.html`（Three.js 0.170.0 vendored，纯程序化美术与音效，零外部素材）
- **版本**：0.1.0（2026-10-01）
- **一句话玩法**：第三人称漫步一座同人风格的机器猫小镇，逛 7 处经典地点、点亮路牌、集齐 7 枚「记忆铃铛」，比比谁逛得又全又快。

## 背景

傍晚暖色光下的低多边形小镇：中央广场有蓝色圆头机器猫雕像（抽象圆滑的原创造型，不复刻具体角色形象），周围 7 处地点向经典日常场景致敬。无限命漫游玩法，无失败条件；完整短循环为 标题面板 → 开始 → 漫游收集 → 结算 → 页内重玩（不刷新页面）。

## 操作

### 电脑（全程键盘可玩，不用鼠标、不用 Pointer Lock）
- `W A S D` 移动（相对镜头水平轴），`Shift` 加速跑
- `K` 跳，`J` 互动（点亮路牌 / 看地点介绍）
- `Q` / `E` 单次按下切换镜头预设（跟随 / 广角 / 高视角），`C` 回默认
- `Enter` 开始 / 确认 / 重玩，`Esc` 暂停

### 手机
- 左下虚拟摇杆（推满约 92% 自动加速跑），右下 `J 互动` / `K 跳` 动作按钮 + 右侧 `Q / E / C` 镜头按钮（全部 ≥44px，只放实际存在的键）
- 竖屏开始后游戏容器整体旋转 90° 成横屏布局，触控坐标逆变换，无阻断性提示
- 「全屏」按钮对包含触控层的整个容器请求全屏；失败给可玩回退提示，不阻断

## 目标与规则

- 每处地点有一块路牌，走近（<3m）出现「按 J 互动」提示；按 J 点亮路牌（+横幅显示地点名与一句介绍），7 块路牌各藏 1 枚悬浮发光的「记忆铃铛」，走近（<1.9m）自动收集：+100 分 + 音效 + HUD 进度 x/7。
- 集齐 7 枚 → 通关结算面板：总用时、里程、步数、铃铛 7×100、点亮路牌数、时间奖励（`max(0, 3000 − 秒×10)`，10 分向下取整）；`Enter` 页内重玩。
- 最高纪录存 `localStorage`（命名空间 `tb-game-nobita-town-best`，try/catch 包裹，不可用时静默降级）。

## 结算与重玩

结算面板列出全部统计与「最高纪录」，破纪录时 kicker 追加「新纪录！」；`Enter · 再逛一次` 或点按钮页内重开，不刷新页面。

## 特色

- 全程序化：几何体 + canvas 纹理（草地/道路/石板/墙窗/水面/路牌字/光晕），WebAudio 程序化合成音效（开始/跳/路牌/铃铛/暂停/通关）
- 傍晚暖色光照 + 雾，路牌、路灯窗光自发光；角色走路摆臂摆腿动画与跳跃
- 性能：像素比上限 2、阴影贴图按需更新（`shadowMap.autoUpdate=false`，仅在玩家移动/跳跃/镜头变化时标记重绘）、共享几何体与材质缓存、逐帧零分配（复用 Vector3 与最近点结构）
- i18n：页面内嵌 `window.GAME_I18N` 兜底字典（56 key 中英），启动时合并进 `TB_LOCALES`，站点 locale 未更新时页面完全正常；「中文 / EN」即时切换（含路牌纹理重绘）

## 已知局限

- 镜头不做建筑遮挡处理：贴近大建筑时镜头可能被墙面/屋顶短暂挡住（表现为画面边缘出现建筑色块）
- 神社平台为整体碰撞体，玩家不能真的登上石阶（远景造型呈现）；河道不可进入（z 向钳制）
- 摇杆为 4 向优势轴 + 死区，非全模拟量；跑动由推杆幅度或 Shift 触发
- 阴影贴图 2048 覆盖全图，特写处阴影偏软
- 音效无背景音乐（仅事件音效）；暂停时铃铛浮动动画仍在播（不影响玩法）

## 真实遇到的问题与修复

1. **河边堤坝漏挂收集点**：首版 scene.js 第 7 处地点漏调 `place(6,…)`，场上只有 6 枚铃铛无法通关（浏览器实测 `view.bells.length === 6` 发现）→ 补上河边铃铛/路牌。
2. **结算面板不显示**：`finishRun` 忘记 `$('panel').hidden = false`，通关后画面停在场景（Playwright 断言 panel display:none 发现）→ 修复并顺带隐藏大字/提示。
3. **雕像五官埋进头球**：口鼻/眼/鼻/胡须/铃铛初始 z 坐标在蓝色头球内部，正视只有蓝球（截图发现）→ 调整 z 使五官前凸。
4. **英文模式下结算行保持中文**：切语言后 tally 未重渲染 → 抽出 `renderResults()` 并在 `tb:locale` 时重绘；同修 HUD 左上地点名不随语言切换的问题。
5. **商店街铃铛落在碰撞体内**（首版放在拱廊深处，玩家够不到）→ 移到拱廊前空地；神社路牌/铃铛按平台碰撞半径外移。
6. **合成 PointerEvent 触发 setPointerCapture 抛错**（测试环境伪指针）→ 给摇杆与动作键的 `setPointerCapture` 包 try/catch。
