备注：
- 带 `{n}` 占位符的 key（nextLevel / retryLevel / levelBanner / waveTag / winTitle）在运行时用 `tr(key, {n})` 填充。
- `newRecord`、`toastSunGot`、`cameraOblique`、`cameraTop`、`cameraReset` 为当前版本保留词（HUD/结算未直接引用，属预留文案）。
- 站点级 `data-i18n="pvz3d.*"` 元素由站点 `i18n.js` 渲染；动态字符串走 `main.js` 里的 `tr()`（先 `window.t`，再查 `GAME_I18N`，最后回退 key 本身）。
