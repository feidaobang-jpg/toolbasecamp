# 植物守卫战 3D（pvz-3d）· Media Kit

## 一句话玩法

在 5 车道 × 9 列的 3D 草坪上排兵布阵：种向日葵攒阳光、豌豆射手阻击、坚果墙挡路、樱桃炸弹清场，守住 3 大波僵尸进攻；过关后进入更快更多的下一关，无限递增。

## 背景 / 同人声明

本作是「植物大战僵尸」(Plants vs. Zombies) 玩法的**同人致敬 3D 重演绎**，仅复刻玩法机制，不搬运任何原作美术、贴图、音频或文本素材；全部模型为 Three.js 程序化几何体，音效为 WebAudio 合成。与 PopCap/EA 官方无关。页面脚注已注明「同人致敬演示 · 程序化美术与音效 · 与原作官方无关」。

## 操作

### 电脑（全程键盘可玩，不依赖鼠标 / 无 Pointer Lock）

| 按键 | 功能 |
|---|---|
| 方向键 / WASD | 移动草坪格子光标（5×9） |
| 1–5 | 选择植物卡（向日葵 / 豌豆射手 / 寒冰射手 / 坚果墙 / 樱桃炸弹） |
| J | 在光标格种植当前选中植物；光标压着阳光时改为收取 |
| K | 铲除光标格植物 |
| Q / E | 切换镜头预设（斜俯视 ↔ 俯视） |
| C | 回默认视角 |
| Enter | 开始 / 确认 / 下一关 / 重玩 |
| Esc | 暂停 / 继续 |

### 手机 / 触屏

- 直接点草坪格种植（选中卡片后）、点阳光收取、点植物卡选择。
- 底部卡片栏含「铲子」按钮，点按进入铲除模式再点植物铲除。
- 右下 Q ◀ / E ▶ / C ◎ 镜头按钮；顶栏暂停 / 全屏。
- 无摇杆（塔防不需要）；Pointer Events 按 pointerId 处理，pointercancel / 失焦 / 暂停即清输入。

### 横竖屏

- 初始化即填满视口、隐藏站点外围；开始游戏**不自动全屏**，提供独立「全屏」按钮（含触屏层）。
- 竖屏手机开始后容器 CSS 旋转 90° 成横屏，触控坐标在 `scene.pick()` 内做逆变换（已实测竖屏点格种植位置正确）。

## 规则

- 每关 3 大波：第 1、2 波为普通波，第 3 波红字「一大波僵尸正在接近！」且配巨僵小 Boss；波内僵尸分批生成。
- 僵尸突破到最左列时该车道小推车自动出击一次清行，**用过即无**；小推车已用再被突破 → 失败，结算标题「僵尸吃掉了你的脑子！」（同人措辞）。
- 清空 3 波全部僵尸 → 胜利结算（+1000 关卡奖励）→ Enter 进入下一关。关卡递增：僵尸血量 +13%/关、速度 +5%/关（封顶 1.5×）、数量与种类递增，无限关。
- 无玩家生命值，核心失败判定 = 车道被突破。
- 最高纪录（最高关卡 / 最高总分）存 `localStorage`，命名空间 `tb-game-pvz3d-*`（try/catch 包裹，隐私模式安全）。

## 胜 / 负 / 重玩

- 胜利面板：本局得分、消灭僵尸、收取阳光、最高纪录，按钮「Enter · 下一关（第 n 关）」。
- 失败面板：得分、到达关卡、最高纪录，按钮「Enter · 再战第 n 关」（重试本关，总分重开）。
- 页内结算重玩，不刷新页面；Esc 随时暂停。

## 特色

- 纯程序化 3D 美术：拟人化植物（圆头+茎）、方脸伸臂前倾僵尸、白天光照 + 阴影、云朵飘动、房子 / 马路 / 墓地布景。
- 3D 反馈：种植弹跳出土、豌豆飞行命中、僵尸受击闪烁 / 死亡倒地、樱桃火球爆炸 + 镜头震动、冰弹减速变蓝、阳光旋转发光。
- WebAudio 合成音效：种植 / 射击 / 命中 / 啃食 / 僵尸呻吟（随机音高）/ 小推车 / 爆炸 / 波次号角 / 胜负 jingle；静音开关。
- 站点范式接入：`data-i18n` + 页内 `GAME_I18N` 兜底字典（66 个 key，中英全量，见 `i18n-keys.md`）、t() 三级回退、触屏开关、中/EN 切换即时生效。

## 已知局限

- 程序化音效与几何美术为演示规格，无关卡编辑器、无存档续关（仅最高纪录）。
- 僵尸出生车道纯随机，不做行间避让；多个僵尸会堆叠啃同一格。
- 樱桃炸弹不会秒杀满血巨僵（2800 血 > 1800 伤害），需两颗或配合输出。
- 波次推进条件为「上一波清到 ≤2 只或超时」，超时 40s（第 3 波 55s），极端拖延会提前放行下一波。
- 音效在部分浏览器需首次交互后解锁（已按站点惯例处理）。

## 真实问题与修复（开发实测记录）

1. **`world.cards` 被空对象覆盖**：`freshWorld()` 重构时旧 `cards: {}` 残留在对象字面量后方，把新初始化覆盖掉，导致种植报 `Cannot read properties of undefined (reading 'cool')` 且整局无法种植。→ 删除残留字段后复测通过。
2. **scene.js `tmpObj` 重复声明（TDZ）**：重构时顶部新增声明未删旧位置声明，`node --check` 直接报语法错误。→ 去重后通过。
3. **触屏取格容差**：首版测试网格步长 14px + 容差 0.12 格在 844×390 下采样过疏，误判「点格无效」；复测（步长 6px / 容差 0.25）确认 pick 映射本身正确，游戏侧未改。
4. 复测结论：键盘光标移动 / 数字选卡 / J 种植 / K 铲除 / 收阳光 / Esc 暂停、触屏点卡 / 点地 / 收阳光 / 铲子 / 镜头按钮、竖屏旋转坐标、EN 切换、3 波→胜利→下一关→失败→重玩全链路 0 控制台错误。
