## 接下来的工作顺序

1. **虫潮基地防守开局 10–15 分钟**：先用新档实际跑普通难度前几波，记录目标理解、第一次建造/升级/雇佣、首波到下一波节奏、失败原因、失败后重开与进度恢复。优先修阻断和操作反馈，再调整引导/资源节奏；保留 Claude 刚验收的修复。以玩家能自己找到下一步、至少出现一次有结果差异的防线/小队选择为验收点，而不是仅看画面升级。
2. **亮剑章节由现有任务逐章完成**：Claude 当前做共用引擎＋苍云岭；每章先形成开场—目标—战斗—结算/失败—重玩完整流程，并复验平安县城，再接下一章。本任务不重复开发，也不预先把未完成新章放进正式入口。
3. **战地只打磨一张地图**：先验完整一局电脑对战、据点规则、胜负与重开，再验证既有联机/掉线；通过后才提升推荐位置。
4. **虫潮副模式只挑一个做深**：银行/房车/虫族/酸液先各做完整一局盘点，结合明确玩家反馈和成本选择；未选中的保留折叠测试入口，不同时翻新。酸液流程短，可先用作完整盘点起点；不因此直接承诺它成为第二主模式。
5. **新模式暂缓**：大灾变、大逃杀、躲猫猫先留构想，不占玩家菜单，也不同时启动。

准入标准：可完整开局、胜利/失败、重开/退出；存档与恢复可靠；电脑和手机布局/输入可用；有明确目标、反馈和一局节奏。推荐展示不等于保证无缺陷；未通关验收的内容保留测试/早期标记。发现核心流程阻断再单独关闭对应入口并写明原因，不删除历史玩家进度。
