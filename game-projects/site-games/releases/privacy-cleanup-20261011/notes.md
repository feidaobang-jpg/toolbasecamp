# 游戏站外账号与网站跳转清理

范围：已映射 Toy 的虫潮围城、坦克大战 3D、超级玛丽 3D、赤色要塞 3D、恐龙快打 3D。用户要求彻底删除游戏内网站账号收集及所有跳往本人网站的代码，并允许点击进入本人 B站主页。

- 虫潮删除网站登录表单、手机号/邮箱/密码字段、SiteSaveProvider 和账号/token 路径，重新构建兼容包。网站只保留本地存档及文件导入/导出；Toy 保留官方 SDK 云存档。不迁移、不上传历史凭据。
- 删除加载异常的返回网站游戏列表入口、联机大厅网站链接；联机邀请改为对应 B站 Toy 入口。联机 WebSocket 传输仍保留，不属于跳转或网站账号登录。
- 五款主菜单增加「作者B站主页」。普通网页使用原生链接；Toy 支持时在用户点击/键盘确认的手势中调用官方 navigate(space, 16214353)。不读取玩家资料、不自动跳转。
- 所有实际 Toy 包静态扫描通过：无网站登录/注册/密码上传/游戏列表代码；本人网站地址仅剩联机 WebSocket。
- 隔离 Edge 浏览器验收 16 项：五款 × 电脑/手机横屏/手机竖屏，以及虫潮网站旧档继续、导出、导入和前次进度保全。Toy SDK 使用隔离 mock；另通过官方云档自动检查点、清空本地后恢复、坏文件拒绝、存储失败等三视口浏览器验收及 26 项存档单测。手机为桌面模拟，未宣称真机验收。
- Toy doctor 五包无 ERROR；均提示固定 JS/CSS 文件名没有 contenthash，更新需重新下载资源，仅缓存建议，不阻挡提审。

网站部署、Toy 预览/提审与公开状态另见 release-status.json。Toy 提审不等于上线；虫潮先前公开入口显示已下架且更新返回 307008，需要记录真实平台状态。TapTap 本次未操作。
