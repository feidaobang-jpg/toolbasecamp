# TapTap 实机封面替换（2026-10-08）

按用户要求，六款已发布作品均准备横版1920×1080与竖版720×1080真实实机截图。仅作等比裁切、缩放、压缩和名称文字排版；没有使用AI概念图、重新摆模型或注入游戏状态。图标、截图组、视频、现有游戏ID与包体保留。

原始截图、裁切输出与完整CLI回执保存在handoff.json所列仓库外路径；记录包含来源、裁切框、哈希、旧/新URL与asset ID。恐龙采用首次上线时正常试玩的第一关战斗截图，虫潮采用正常试玩的荒漠第三人称截图；其余四款本次从当前TapTap H5包正常试玩截取。旧截图未标成新版本功能演示。

四款资料草稿回填后读回确认仅两处封面字段改变，正式送审。预检blockers为空，截图排版建议和既有经典IP内容预审提示均保留；没有伪造授权材料、跳过正式审核或签新协议。审核状态与公开生效分别记录。虫潮与恐龙已有玩法版本正在审核，其封面素材已上传，等待现有审核结束后从最新线上版本继续，仅替换封面。

游戏发布技能已记住本要求，并在技能仓库主线提交。共享台账与各游戏taptap-sync.json的cover_update字段用于去重和恢复；后续普通发包必须保留/续办本次实机封面，不能被旧宣传图覆盖。
