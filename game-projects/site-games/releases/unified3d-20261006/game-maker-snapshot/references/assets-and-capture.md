# AI 资源与真实开发素材

## 资源链

默认 AI 生成与原创程序化资源，保留“输入→原始生成→处理→游戏使用”关系。所有新游戏默认赤色要塞式低模哑光自然色美术，复刻/重制不必照原版画风；声音优先下载可用原版，找不到再合成，见主文件「复刻经典作品」。不把一切画成方块，也不给极简玩法强加精细 3D。先统一角色比例、轮廓、颜色与动作，再批量制作。

- 图片/贴图：当前图像生成工具按用途生成，明确透明背景、视角、尺寸与序列一致性。保留提示词、参考来源、已知工具/模型、原图与运行版，检查透明边缘与贴图接缝。
- 3D：用已有且授权的生成服务、Blender 程序化或 AI 辅助建模；不要求用户先提供模型。处理运行网格、材质、尺度、朝向、碰撞，活动角色接骨骼/动作状态，浏览器优先 GLB。生成模型不等于可玩角色。
- 遵守已授权服务与预算，不自动充值、订阅或调用新付费供应商。能力缺失时继续玩法/程序化部分，明确正式资产缺口，不把占位当精细成品。
- 声音实际绑定事件，音量/静音/暂停一致；原创题材按需要使用原创程序化或 AI BGM，不从参考视频截取音乐音效；复刻作品先搜索并下载原版音乐音效，记录来源和压缩/循环处理；确认找不到或不可用再 AI/程序化合成，不把回退称为原版。无默认麦克风录音或真人克隆。
- 关键资产记 ID、文件、生成方式/工具、提示词或参数、处理说明、实际使用位置、已知使用条件与占位状态。服务预览和实机分开；未知字段如实留空。

## 开发中采集

不用全程录桌面，利用验证时机留存后续无法复现的阶段：
1. 原型首次可玩、关键模型导入、主要视觉改变，留有版本的短片/截图。
2. 真实 Bug 若可安全复现，先录触发、异常和结果；没录到就存复现步骤并注明无原片，不为补镜头在交付版本重引故障。
3. 修复后同局面复验，关联 Bug ID，写真实根因/假设、修复及结果；偶然正常不等于修复。
4. 最后录当前构建的干净实机，覆盖核心动作、因果反馈与结局，镜头前后留余量。

## 捕获与证据

按 [交接协议](../../game-video/references/development-handoff.md) 存档。首选本游戏窗口/标签的实时采集，具体工具按会话能力，不假定浏览器工具一定能录音录像。

- 自动化录屏可能无音轨，Canvas capture 可能缺 DOM UI。验证真实文件，必要时另录游戏音轨与同步偏移；缺声音注明 `audio: none` 与补拍需求。
- 自动输入、内部回放、离线逐帧、真人输入分开记录；测试传送、时间压缩、固定种子和镜头修改注明。重演不能称首次发现。
- 保留完整玩法/HUD，隐藏无关调试。横屏母版以 1080p 为可选目标，按运行能力选帧率/分辨率，不把放大插帧当原生质量。
- 探测片长、分辨率、帧率与音轨，查看代表帧和动作连续过程。没听审不声称听过；登记哈希与源时间段。
- 不录凭据、聊天、无关桌面/应用音频。混入私人内容时制作可公开副本，保留受控原片并标不可直接发布。
- 原片在非公开媒体目录，不自动上传；转码记录母子关系，不把多个编码版本当多个场次。
