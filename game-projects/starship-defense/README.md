# 虫潮围城 v0.26.0 · 虫潮对战（1 对 1）

2026-10-08：新增「虫潮对战」模式（设计见 `design/versus-mode.md`）。主菜单「⚔ 虫潮对战 · 1 对 1」进入：对战电脑（简单/普通/困难）或好友联机 1 对 1（联机大厅建对战房间，人数固定 2 人，房主蓝方计算整局）。

- 双堡峡谷：场地放在主战场北面 900 米外（雾外），点对称；中央岩丘，东西两条行军路线，建造只能在本方半场离中线 25 米外。
- 经济：开局 600 金，每 10 秒按银行等级进账（60/85/115/150/190），升级 500/900/1400/2000；银行被打掉停产 30 秒后自动重建（不掉级）。打死对方单位得造价 25%，击倒英雄 150。
- 兵种 9 种：小虫群、机枪小队、突击小队（0:20）；甲壳战虫、迅猛飞虫、炎爆虫、医疗小队、突击战车（3:00）；虫王（6:00，3000 金）。单位边走边打敌方单位，遇到英雄和建筑才停下来打。
- 建筑 5 种（围墙、机枪塔、防空塔、自动炮台、特斯拉塔），对战中耐久 ×1.6、火力 ×1.3；核心 6000 血带机枪。
- 后期：6:00 起收入 +50%、每 30 秒双方各刷一波免费虫群、新单位 +25%、建筑受到伤害 +50%；9:00 起新单位 +50%、建筑受到伤害翻倍。15:00 比核心剩余血量，相差不到 5% 进入 2 分钟加时，先掉核心血者输。
- 操作：R 出兵面板（1-9 派兵、0 升级银行）、Z 路线、L 建造、O 买枪；手机「出兵」「建造」「商店」按钮打开同一面板。面板不暂停战斗。
- 对战不读写单机存档和排行榜；退出时恢复战役状态。本地战绩（对电脑各难度胜负）存 `chongchao-versus-record-v1`。

代码：玩法在 `public/html/game/starship-defense/versus.js`，接入在 `game.js`「虫潮对战」段；服务器 `server/coop_lobby.py` 为虫潮房间保留 `mode`，对战房间上限 2 人。

验证：
- `verify-versus.cjs`：真实按键/点击完整流程、规则（无友伤、英雄受伤 ×0.8、英雄打建筑 ×0.6、赏金）、炮塔开火、结算与再来一局、暂停菜单、退出恢复（单机自动存档不变）、电脑满负载帧时间、手机横竖屏视口（30 项）。

- `verify-versus-balance.cjs`：无界面加速时钟，电脑对电脑批量打完整局，输出胜率、时长、首波时间、阵亡来源。

# 虫潮前哨：堡垒与自由测试 v0.6.0

当前主工程为 Three.js 网页游戏，沿用用户认可的精致 Q 版。定位是 B 站 Toy / 视频驱动的小 Demo；Steam 仅为可能的后续去向，没有确定上架计划，不维护第二套 Godot 实现。

## 本版

- 修复激光高速弹丸越过目标：脉冲激光炮按住连续发射即时光束；狙击和轨道炮也采用连续路径命中检测，轨道炮按距离贯穿最多三敌。
- 岩石具备实体碰撞并阻挡弹丸；飞行单位按高度通过。怪物在障碍旁绕行，出生位置避开实心障碍。
- 基地两侧与后方山体围合、正面开口；两侧金色台阶可步行登上门楼。保留原城门与城墙规则。
- 防空激光塔专门攻击飞虫；左前短洞穴两端可穿行，右前野外地堡可进内回血，镜头遇洞壁/屋顶缩近。
- 暴露自由测试入口 T，游戏内 H / 测试台。玩家、小队、建筑、基地、城门、载具无敌；全武器、无限金币弹药与重复取用道具，四类载具直接驾驶。
- 测试台可选择十章虫种、六种精英词缀、小首领、大首领和召唤数量；全类型混战、清场、重置与返回普通模式。上限 48 虫 / 4 队友 / 32 建筑，控制负载。普通关卡保留。
- 普通 sst_save_ 与 sandbox_ 子空间隔离；Toy 又使用 toy-chongchao-v1-sst_save_ 独立前缀。普通存档不会被自由测试覆盖。

## 启动与验证

入口 public/html/game/starship-defense/index.html。旧 starship_defense.html 重定向仍可用。

使用 HTTP 服务：Python -m http.server 8765 --bind 127.0.0.1 --directory public。
GAME_URL 指向测试入口，GAME_VERSION=web-fortress-v0.6.0 后运行 verify-web.cjs；verify-fortress.cjs 验证本版激光/碰撞/无敌/存档与混合虫潮移动压力。?qa=1 才暴露自动化钩子。脚本使用本机已安装 Playwright 和 Edge。

WASD 移动，J 射击，K 跳跃，U 手雷（直升机下降），I 互动/上下载具，O 商店，L 建造，V 换枪，C 四种视角，R 开战，Enter 开始/重试，Esc/P 暂停，M 声音，F 全屏。自由模式 T 进入、H 测试台，Tab/回车操作菜单。手机使用对应触控按钮，竖屏自动旋转舞台。
