# 虫潮前哨：守卫基地

选择兵种，使用枪械和手雷、购买装备、建造防御，保护基地并击退虫潮。现有游戏支持准备与战斗阶段、兵种、装备商店、建造、载具、队友、关卡推进、暂停和浏览器本地存档。失败后可重试本关。

本次Toy版本增加独立打包、清晰首屏目标、静音和手动全屏、键盘快速开始/开战/重试，隐藏测试模式按钮。核心玩法沿用原版。WASD移动，J射击，K跳跃，U手雷，I医疗包/载具/城门，O商店，L建造，P暂停；新增Enter开始、R开战/重试、M静音、F全屏。手机保留摇杆与动作键。

面向视频的首轮切入点：玩家能否守住虫潮来袭的基地。标题以实际挑战为中心，不声称一键开发成功，不承诺Steam。已有截图见本版captures，完整玩法录像待补录。Toy审核状态以管理端或官方CLI为准。
