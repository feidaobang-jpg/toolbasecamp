# 虫潮围城直播准备版 live-v0.1.0

基线：web-touch-layout-v0.19.1。分类：独立直播入口新功能；普通单机玩法不变；正式B站直播待本人权限/项目审核及平台对AI独播的许可确认。

共用现有地图、角色、战斗、队友、载具与复活。通过窄接口插入直播规则，不复制维护第二份完整游戏。直播存档使用sst_live_save_命名空间，普通试玩/旧存档保持sst_save_；Toy普通入口不运行直播控制器，也不包含本机密钥或服务。

已实现：AI独播、人工接管AI辅助、本人主持AI操作；免费弹幕兵种组与20秒投票；维修/护盾/坦克/轰炸支援及真实执行回执；五分钟守城与自动重开；本地模型解说、中文语音、麦克风音量避让；官方B站项目鉴权/长连/心跳/关闭；事件查重和故障停止；独立控制台与OBS场景准备。

真实问题及修复：
- 整备倒计时归零后，进入战斗的remaining仍是0，导致立刻判胜。保留初次测试输出，改为切换阶段时重设剩余时长，复测实际战斗及胜负重开。
- 初次误把相机预设的字符串传给数字索引接口，检查现有相机接口后改为数字高位跟随；第一人称使用独立setCamMode。
- Ollama下载遇到代理fake-IP重定向限制。改从官方registry下载manifest及blob，逐个校验SHA256，没有关闭应用保护或接受未知来源文件。
- Ollama首次GPU推理加载约31秒且请求超时；CPU模式实测中文回答+本机语音约3.27秒，默认numGpu=0，保留GPU给游戏和OBS。
- 直播附加HUD与普通HUD叠在一起；实机检查后仅直播入口收起普通信息面板，将基地与主角耐久放入直播信息栏。普通入口不改变。
- 初次WebSocket依赖版本的npm audit发现已公开修复的漏洞，升级固定ws8.22.0；最终audit零漏洞。
- 持续运行的GPU几何计数增长，确认金币/医疗掉落被移出场景后未释放专属几何与材质。补齐拾取、超时、清场、关间回收四条释放路径，并用100次真实渲染/拾取压力验收；不释放角色共享几何。

限制：观众归入四名AI队友的兵种组，不是每人独立角色；未做真实手机验收。官方B站连接缺少本人开发者凭据，真实礼物与推流尚未验证；模拟效果不能当作真实礼物或收益。语言模型提示与过滤不保证生成内容永远无误。
