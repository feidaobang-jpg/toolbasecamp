# 酸液围场 v0.38.0

目标：把“狭小区域躲酸液、虫子耐打、双方成长”做成可选短局，让躲避和喷射后的反击窗口都有意义。

本版不改基地防守的成长。三轮各3/4/5只固定位置且不转向的酸液虫，扇形弹道按轮次增加、第三轮双连喷；金线预警1.35秒，喷后蓝色弱点伤害1.8倍，平时护甲只受30%伤害。人物3点生命、受伤1.35秒无敌，K闪避、I使用已获得护盾。清场后暂停三选一升级，无血量自动补满。挑战纪录只写独立本机键，原战役存档/备份和Toy官方云档规则保留。

真实迭代：首次可玩录像保存在本机 artifacts/acid-arena-20261013/prototype（开发构建未留完整指纹，因此不冒充最终版）。初版跟随视角看不全虫子，改为固定中心战术俯视；随后三视口图像复查清除了存档胶囊和准备按钮残留。第一次平衡探针连续酸液过密，普通绕圈10秒死亡；改为较慢稀疏单喷，第三轮才双喷。第二次发现每组射线四分之一步偏移让正中心变成安全死角，改为整步/半步交替。当前固定步长探针：站桩20.75秒失败，绕圈27.52秒到第二轮后失败，预知弹道的避弹脚本97.53秒通关；这些不是玩家测试或通关率。

最终回归覆盖桌面、横屏与旋转竖屏：实际移动、触屏摇杆/闪避、实时子弹命中、四视角、暂停/重开；夹具验证固定朝向、弱点倍率、受伤保护、失败、两次升级、护盾、边界、胜利和原存档继续。另有射击偏好/切换、存档26项以及最终Toy包禁止网站跳转和账号上传的检查。手机仍只是浏览器模拟。
