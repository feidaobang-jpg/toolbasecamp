# v0.9.3 去掉地上的装饰小光锥

base_version：web-keyboard-v0.9.2（网站与 Toy 均已上线）。

用户问“地上的锥形小光柱是干嘛用的，没用就去掉”。它们是 deco() 里散布的 260 个小锥体（深色画风是发光青色、Q 版是绿色），沿用首发版的“荧光植物”装饰，没有碰撞、不能拾取、没有任何玩法作用，所以删除；同时删掉 theme.js 里只给它们用的 plant / plantGlow 配色。无碰撞的小碎石保留。

验证：两种画风载入并开局，场景中小锥体数量 260 → 0，实例化网格各少 1 个，无页面错误。前后对比截图在本地 captures/（before-field-*.jpg、after-field-*.jpg，按仓库规则不入库）。玩法与数值无改动，未重跑整套验收。
