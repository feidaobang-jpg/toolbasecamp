# 战地模式改造记录

用户要求把原对战全面改成战地风格，并去掉经验和升级。将旧对战规则入口替换为独立的据点战模块，守城与房车保持原逻辑与资源配置。

地图新增沙漠旧镇、通信站、仓库与军事营地。模型用代码生成并按材质合并静态零件，使新增玩法不需要下载大模型或贴图。保留原驾驶和三种输入模式，用固定五兵种、八武器、四载具替代购买和成长。双方均由据点、伤亡和兵力票决定胜负。

实测发现并修正：旧触屏医疗键被隐藏、换弹和医疗坐标重叠、旗点条被旧样式隐藏；瞄具原来为实心面，改为可透视的框架；多人切兵种时旧上下文覆盖新武器列表，已把装备更新纳入当前控制上下文；旧买兵/升级类网络命令整段隔离，避免进入战役处理器。

验证包含真实键鼠射击换弹、五兵种八武器、四载具上下车与直升机升降、占领/争夺/票数/复活/装甲、1v1和4v4完整AI对局、三端真实WebSocket及第四人中途加入、掉线接管、横竖屏与小视口、操作模式双向切换、退出后原资源配置恢复。测试使用QA接口隔离规则，完整对局则模拟连续游戏步进；截图与录像的测试捷径在handoff单独注明。

限制：现有AI无复杂战术协作，未做真人平衡验收；建筑是不可进入的掩体，未实现破坏或固定翼飞机；没有真机性能测试。本次不制作或发布新视频。其他渠道登记22点批次，不把本地包测试称为平台上线。
