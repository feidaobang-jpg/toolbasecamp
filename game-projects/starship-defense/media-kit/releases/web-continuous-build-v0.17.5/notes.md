# 连续建造 v0.17.5

来源：用户截图中“不争气的空白”反馈放完一座需要退出再放；用户授权实现连续摆放并回复截图内四条评论。

- 原先成功放置后直接结束建造。现在保留同种建筑虚影，移动到空位可继续确认放置；每座单独检查金币、碰撞与64座上限。
- L/手机建造换建筑，Esc/取消结束；取消只撤下未放置的虚影，已有建筑保留。
- 调整提示，避免放过建筑后仍说“没有扣钱”。
- 桌面、手机横屏及竖屏模拟：一次选择放3座、原位重复确认不收费、金币不足、64座上限、换建筑、取消、商店切换均通过。手机App真机未测。
- 不修改模型与场景，沿用封面。媒体为QA输入及测试位置跳转，录像无音轨，只作操作证据，不冒充普通玩家录像。
