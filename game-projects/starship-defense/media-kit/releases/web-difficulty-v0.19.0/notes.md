# 虫潮围城三档战役难度 v0.19.0

玩家反馈：有人觉得现有虫潮偏简单。新增休闲/普通/困难，默认普通，不统一提高所有玩家的门槛。

- 休闲：敌人血量85%、伤害70%，基地最大耐久135%；出怪间隔125%、精英概率减半，双词缀尝试概率15%。虫潮数量与普通相同。
- 普通：旧血量、伤害、金币、基地耐久、数量与间隔保持一致；副本沿用独立难度。
- 困难：敌人血量112%、伤害130%；新增虫潮规模125%、出怪间隔65%且最低0.35秒；精英概率额外10个百分点（上限38%），双词缀尝试概率60%。小兵金币按55%取整（至少1），固定首领、通关与母皇补给不提高。测试覆盖800组章节/关卡/周目/母皇状态；考虑词缀去重和金币取整，新增波次小兵金币期望最大约普通的1.133倍，未出现怪多导致经济成倍膨胀。
- 母皇击杀后减少后续虫潮35%的策略收益继续有效；同屏虫群48上限保持。难度固定在新局，手动存档、自动存档、开新局备份及云档保留字段；缺字段旧档按普通。
- 三档共用已有休闲积分总榜，页面明确说明，不宣传跨难度公平竞技。

真实问题：自由测试的暂停返回按钮被35层工具栏拦截。保存修复前截图后提高菜单到36层，电脑/模拟触屏复验通过。

三视口自动化覆盖：选择/键盘确认/触控、刷新保留、新局/继续/读档、旧档兼容、无效云档拒绝、副本不叠加战役倍率、自由测试独立、切输入模式保留进度、母皇减弱与普通曲线一致。密集虫群帧时间来自RTX4060Ti电脑，手机仅模拟；不声称真机验收或真人难度平衡已完成。

封面沿用。录像是真实自动化WebGL，包含受控测试定位，不是真人试玩；没有音轨，媒体交接为partial。正式版本部署核验后同步Toy及两条已确认虫潮视频简介。网站/Toy/B站各自以实际核验状态推进基线。
