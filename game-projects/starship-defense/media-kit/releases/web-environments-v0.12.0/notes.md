# 虫潮围城 v0.12.0：章节环境

第 1–3 章使用暮色荒漠（暖色沙地、层叠砂岩），第 4–6 章使用极光冰原（雪地、冰晶、极光），第 7–10 章使用虫巢边境（菌毯纹路、巢拱、菌伞与孢子）。共用深色战场的角色和界面，只替换地表颜色、天空、灯光与边界装饰。地形高度、碰撞、基地布局和主线数值不变。

在主菜单选择“自由测试”，进入后打开“测试台”，选择“战场环境”并点“前往此环境”，可立即预览三种场景。普通模式根据章节自动选择环境，读档和副本返回同样恢复正确环境，不新增画风设置或存档字段。

只保留当前环境的装饰资源，切换时释放旧几何、材质和实例缓冲。同一环境内换关不重建。大型地标位于可行走边界外，中央射界保持清楚。气氛粒子只占一次绘制，流畅画质隐藏；没有新增图片或模型下载。gzip 游戏脚本比 v0.11.0 增加 2,743 字节，详见 `size.json`。

验证结果见 `checks.json`：真实章节推进、读档、副本往返、测试台选择、普通存档隔离、反复切换的资源数量、手机触控和布局均通过；浏览器没有脚本错误。电脑操作回归 12 项通过。

`performance.json` 使用桌面 D3D11 GPU、960×540 手机视口、4 倍 CPU 限速，48 只混合敌人交战采样。该环境下约 20–21 FPS，不能据此承诺真机帧率，也不是改动前后的等条件帧率对比。单独开关装饰测得当前视角增加 4–6 次绘制、约 2,700–11,200 个三角形；后续应以实际手机体验为准。默认保留原有“精致/流畅”画质选项。

本次只更新网站；B 站审核包保持既有 v0.11.0。
