# 虫潮围城 web-feedback-v0.22.1（普通补丁）

来源：2026-10-07 B站消息中心三条玩家反馈（见 feedback-ledger.json 与下方 rpid）。

## 改动

1. 重型迫击炮平衡（rpid 316323444209，BV1WbHq6eEBt）
   - 射程 48→64 米（超过狙击炮台 55），伤害 140→180，价格 1600→1400，爆炸半径 6→7 米。
   - 弹速 32→85 米/秒，飞行时间按距离预结算（0.3–0.8 秒，原来约 1.4–1.5 秒）；按虫子速度预判落点。
   - 实测：静止与 8/16 米每秒移动目标均命中并造成 180 伤害（修复前移动目标 2 秒内 0 伤害）。
2. 虫子卡死与出生点异常（rpid 316324806465，BV1Ujad6DEuf）
   - 卡住检测不再限定"无路线且 z<182"：凡 5 秒无实际位移（含隧道路线中、母巢口、基地建筑后）即丢弃失效路线并绕行/钻地朝目标推进。
   - 出生点撞墙/陡坡时自动向外搜索安全落点（含精英词缀放大碰撞体后的二次校验）；钻地绕行检查头顶净高，防止钻仰在建筑下。
3. 联机大厅手机端无法输入（rpid 316322217985，BV1WbHq6eEBt）
   - 根因：全局键盘导航循环在弹窗打开时仍接管焦点，手机点昵称/房间号/密码输入框后焦点被抢，软键盘弹出即收回。
   - 修复：大厅弹窗（.coop-panel）打开时导航循环让位，输入框保持焦点；视口因软键盘缩放后焦点仍在。
