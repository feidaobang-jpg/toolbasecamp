# 虫潮围城 v0.37.3

- 电脑手机共用自动、按住、点击开关连射；独立瞄准设置与既有偏好保留
- 触屏按钮显示连射开关状态；暂停/失焦/取消触摸/操作模式切换清除连射
- 联机发送真实按键/开关意图，目标检测由房主完成；菜单与建造阶段不发射
- 设置页深色对比度修复，游戏内帮助与版本说明同步

房车追击判定、主动技能和FPS特殊规则保留；不改变存档标识或Toy映射。验证与发布证据见 handoff.json。

开发记录：原来触屏绕开电脑射击偏好，联机客户端还把“存在目标”固定传true，导致无目标也产生开火意图。现在由同一输入状态处理，房主只在找到目标时自动开火。菜单设置页的黑色文字也改为深底浅字。集成时主线加入母巢浅坡，因此本版顺延为0.37.3并复测三条洞道。

素材：保存实际Toy预览三视口操作录像与设置截图；仅功能验收，敌人由测试夹具固定位置和血量，未录修改前原片或完整介绍。过程故事可据此讲输入差异及联机修复，不能把QA录像当真人完整通关。音轨静音，无新声音改动。本版没有生成新视频，简介未满7天记待合并。
