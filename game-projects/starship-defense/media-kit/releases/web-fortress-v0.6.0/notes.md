# v0.6.0 真实记录

用户先认可 Q 版，明确要求先更新 Toy，再修复网友激光反馈并扩展堡垒与自由测试。已批准 Q 版 v0.5.0 先提交并在实际 Toy 公共地址验证；本次 v0.6.0 另外上传预览，尚未提交审核。

激光旧代码仅做帧末碰撞，44 个距离在 60/30/20 FPS 下分别漏 5/24/33 次；修复后全部命中，连续按住一秒实测伤害 130。原始数值证据保存在 laser-before.json，没有伪造旧录像。不能确定网友所谓“激光炮”一定指向当前 laser 键，但修复涵盖高速命中问题，购买后即时装备亦验证。

山体和掩体选用合批程序几何；新增洞穴顶石时实际发现索引/非索引几何不能直接合并，已统一为非索引，浏览器重新验收。洞穴第三人称镜头增加遮挡缩近。保留四人小队与四类既有载具，没有照搬百人 NPC 和原生完整洞网。

普通模式按原关卡走，自由测试采用真实无敌与独立存档，不使用 Infinity 参与数值序列化，不额外放大武器伤害。资源/次数无限，活跃对象有上限以保持帧时间。

移动混合虫潮测试 30 秒有两次超过 50ms 的长帧，P95 约 6.2ms；不能宣传绝对无卡顿。两档静态压力无超过 50ms 长帧。均为桌面 GPU 自动化，不是真机手机。

媒体为真实浏览器自动化。截图/录像中的测试摆位、无敌和高血量有标注。新增游戏音轨只从游戏 Web Audio 录制，音频已解码确认有游戏声音，但尚未听审。原片留本地，不推送仓库；轻量图像和交接索引入库。

Steam 仅保留未来可能性，当前方向以 Toy、视频反馈和小游戏 Demo 为主。web-game-maker 已更新并通过技能校验。

复查中发现普通过关的 1.5 秒延迟回调可串入新开的自由测试，旧混战帧率样本已作废并替换。以场次代号和模式条件隔离后，强制复现与 30 秒末尾 48 虫计数均通过。城门近景补充柱体/地形遮挡检测。静态双画质压力保留 b05871cb 基线；最后构建的混合移动压力见 fortress-verification.json。

网站自动部署未及时生效，按仓库规则 SSH 补同步本游戏五个文件；公网逐文件一致且实际普通/自由模式浏览器验证通过。源码提交 bdfce710。新功能 Toy 最终仅预览，等待用户确认，旧 Q 版已公开发布。
