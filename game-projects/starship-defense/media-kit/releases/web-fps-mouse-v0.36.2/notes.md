# 电脑第一人称鼠标瞄准 v0.36.2

用户要求电脑第一人称由鼠标接管瞄准。原代码读取了锁定鼠标的相对位移，却没有请求 Pointer Lock，所以实际只能按住画面拖动。

本版在键鼠第一人称开局、进入该视角和继续游戏时请求接管；直接移动鼠标转向，左键射击，枪战规则下右键举枪。未接管时点击画面只用于接管，不误开火。第三人称、触屏、纯键盘、暂停与面板会释放鼠标，拒绝接管时保留拖动和 Q/E。主战役默认自动寻敌与射击设置不变。

Edge 实测发现并修复两处边界：切触屏时主动解锁不能被当作 Esc 而误暂停；先请求锁定再 setPointerCapture 会在浏览器立即接管时抛 InvalidStateError，已调整顺序。连续 C 切换测试保留每次按键之间的游戏帧，避免把多个按键合成同一帧。

验证：真实键鼠接管、自由转头、左右键、移动、Esc、继续、商店、视角、输入模式、失焦；拒绝接管回退；手机竖屏触控模拟；枪战 26 项回归；包体与网站存档隐私 4 场景。手机结果为浏览器模拟，未做物理手机验证。截图与静音录像为自动化实机采集，QA 设置了无敌、清场和位置，仅作为操作证据。

封面沿用：本版只改电脑操作，画风与核心场景不变。普通操作补丁未达到视频简介累计 7 天门槛，新增待合并项，保留其他任务已有待办，不逐版本写视频简介。TapTap 按默认规则不发布。
