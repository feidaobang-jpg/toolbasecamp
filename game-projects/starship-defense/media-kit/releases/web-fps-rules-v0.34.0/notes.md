# 战地与抗战改为第一人称手动瞄准 v0.34.0

用户试玩战地和抗战后确认：这两个人打人的枪战模式只适合第一人称、手动瞄准、有限子弹，其他视角和自动射击没有必要。本版只改这两个模式；主战役、房车、虫族仍是多视角加默认自动瞄准，也不增加有限弹药模式。

## 规则

- 步行固定第一人称，C 不再切视角。战地上载具、抗战骑马时切到第三人称跟随，C 只在两档跟随距离之间切换；下车、下马回第一人称。
- 所有视角都手动瞄准：子弹从枪口汇聚到准星指向的第一个落点（敌人、掩体、地面或最大射程）。战地载具的镜头改为朝准星方向看，车身留在画面下方，屏幕中心就是炮口要打的地方。
- 只在按住时开火，不再因为附近有目标自动射击。弹匣与换弹沿用原有设定（战地弹匣打空自动换弹、备用弹药无限；抗战弹匣有限、军需箱补给）。
- 键鼠完全手动：按住左键或 J 射击；右键拖动只转视角，原地点一下才举枪；右键拖动时补按左键同样开火。没有使用鼠标锁定。
- 触屏和纯键盘保留准星约 7° 内的轻度吸附；纯键盘没有俯仰键，吸附不看高低差。触屏按住射击键的手指可以继续拖动瞄准。
- 这两个模式不读取也不改写玩家保存的「瞄准方式」「射击方式」和战役视角偏好；设置面板里这两项在模式内锁住并说明原因。
- 联机战地：客人把朝向、俯仰和镜头距离发给房主，房主据此还原准星出弹。只用了服务端已放行的输入字段，服务端没有改动；旧版客户端进新版房间仍按原方式处理。

## 实测中发现并修复

- 手动瞄准常把炮弹打在目标脚边。我方炮弹会陷进地面约 0.3 米才爆，爆炸点被判为“被遮挡”，整发没有溅射伤害；改为从地面以上判断遮挡。原来自动瞄准总是打在目标身上，所以没有暴露。
- 退出战地后恢复视角偏好时，原代码先复位再读偏好，会把保存的“第一人称”覆盖成第三人称；改为先读后复位。主战役里偏好第一人称的玩家开新局时同样受益。
- 电脑端转视角原来只能按住左键拖动，而左键同时是开火键。手动开火后这等于转视角必须浪费子弹，因此加了右键拖动。

## 验证

- `verify-fps-rules.cjs` 26 项：两个模式的视角锁定、默认设置下不自动开火、对准命中与偏开不命中、吸附范围、真实鼠标右键拖动与举枪、坦克按准星落点开炮、设置锁定、退出后恢复、手机横屏视口真实触摸，以及主战役回归。
- `verify-fps-rules-online.cjs` 5 项：本地联机大厅，房主加一名客人，验证客人不被代为开火、对准命中、偏开与抬头不命中。
- 原有套件：战地 `verify-conquest.cjs`（含 1 对 1、4 对 4 电脑完整对局）、`verify-conquest-online.cjs`、抗战 `verify-resistance.cjs` 17 项、`verify-resistance-aim.cjs` 11 项、`verify-pc-controls.cjs`、`verify-camera-response.cjs` 103 项、`verify-touch-layout.cjs`、`verify-feedback-input-flight.cjs`、`verify-zerg-corpse-spin.cjs` 通过。`verify-conquest.cjs` 的触屏布局检查按新规则更新：步行时切换视角键收起，上载具后出现。
- `verify-zerg-mode.cjs` 在本版跑了 11 次，10 次通过；失败的一次紧跟在另一套中途报错的测试之后，之后连续 9 次未复现，基线 3 次通过。原因没有查实，记为偶发。
- `verify-rv-breakout.cjs` 和 `verify-town-versus.cjs` 的后半段在未改动的基线上同样失败（引用了已被重做掉的旧房车路线和旧对战接口），与本版无关；`verify-town-versus.cjs` 的房车城镇部分通过。

## 限制

- 手机为 Edge 的触屏视口模拟（真实触摸事件），没有做实体手机多指和性能验收。
- 没有做真人平衡验收：手动瞄准后电脑步兵相对更强，难度体感可能上升。
- 电脑端没有鼠标锁定，转视角需要按住右键或左键拖动，与常见射击游戏移动鼠标即转视角不同。这是沿用“不设计鼠标锁定操作”的既有约定，是否在这两个模式放开由用户决定。
- 联机客人为纯键盘时，吸附按普通锥形处理，打不到明显高于自己的目标。
