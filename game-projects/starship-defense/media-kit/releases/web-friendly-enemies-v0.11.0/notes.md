# 虫潮围城 v0.11.0 敌人美术更新

玩家反馈：敌人都像蜘蛛，丑且恐怖，普通怪/大怪/精英/大小 Boss 应有区别。

保留深色星际战场与装甲兵；重做敌人几何、配色、脸部与动作。用短脚、两只平静的大眼、软壳与圆钝部件消除蜘蛛特征。普通虫有 10 套不同轮廓；精英加宽肩甲和背旗，小 Boss 为直立拳甲，大 Boss 有巨龟、飞翼、堡垒巨卫三套，母皇为六瓣核心。不同章首领沿用章节配色。玩法数值不变。

使用共享合并网格，每个模型 3 个动态部件，带翅膀为 5 个；不加载新贴图和外部模型。实测报告含完整原始帧时间；不是手机性能承诺。HP 条与词缀徽记依新模型高度定位。测试包括 50 套组合、伤害/死亡/分裂、旋转、桌面和手机视口。

captures/before.png 为改动前本机实时截图，采集于 v0.10.4 深色模型，不能当成新版本素材。enemy-lineup 为运行模型的 QA 陈列且专门标注，不是战斗截图。battle-rotation 是真实运行录像，但采用 QA 排布、提高敌人血量；无音轨。查看 6 fps 顺序帧，未做声音听审。封面为游戏原生场景的隐藏 HUD 截图。
