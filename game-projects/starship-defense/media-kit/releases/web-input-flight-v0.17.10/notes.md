# 虫潮围城 v0.17.10 玩家反馈修复

基线：web-camera-mobile-v0.17.9。来源：2026-10-04 20:45、20:46、20:50 的 B站回复通知；报告者为我不是abbie、188的史蒂夫。

- 飞虫出洞后无翅膀：原先创建模型使用当前是否飞行，而虫洞路径上的飞虫先步行，出洞只改 AI 状态，没有补模型。现在按飞虫种类生成翅膀，洞内步行也保留翅膀。
- 部分迅猛飞虫在地上走：原先用 z<182 决定出生时是否飞行，地表的部分野生飞虫也被判成步行。现在根据真实洞顶判断是否能飞，地表恢复飞行，低矮虫洞内步行，母皇仍留地面。
- 移动/面板切换后触屏建造按钮不响应：输入 reset 释放捕获但没有立即清空闭包里的旧 pointer；若 WebView 延迟 lostpointercapture，后续按下被忽略。现在统一使用按钮上的指针归属并在 reset 时同步清空，旧手指抬起不影响新手指。

测试：旧版两个飞虫状态错误及模拟延迟捕获释放时的按钮失效已留数据；修复后电脑/手机视口针对性测试通过，连续建造（含手机竖屏）、余额/重叠/64座上限、切换建筑/商店、拆除后返回建造通过。触屏延迟释放采用确定性事件模拟，尚无报告者真机复测；不把此模拟称为真机复现。

本次沿用封面：局部输入与飞虫缺陷修复，没有改变整体画风或主要场景。网站、Toy及回复状态记录在本目录各 json；发布前不宣称已上线。
