# v0.17.0 虫族与操作修复

恢复 af5668d6 的项目程序化虫族几何：六足节肢、分节甲壳、獠牙和骨刺，保留飞虫与巨腹母皇，降低色彩饱和度。不是写实电影资产，士兵、地图、昼夜和洞内手电继续沿用。
