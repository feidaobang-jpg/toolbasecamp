# 虫潮围城 0.38.1：Y / H 抬头低头，医疗改到 N（2026-10-14）

## 用户要求

2026-10-13 用户把“上下转视角用 Y / H”定为所有 3D 游戏的统一键位；当时虫潮围城的 H 是医疗 / 直升机降低、Y 是直升机升高，和它冲突。10-14 先在《枪火集结》里迁了，用户随后明确说：「虫潮围城也要改h/y按键啊」。

## 改了什么

- 键盘 **Y 抬头 / H 低头**：按住生效、松开即停、同按抵消，和拖动画面上下看用的是同一个俯仰量和同一个范围（±1 弧度）。走主镜头的模式都生效，实测的是基地防守；房车、虫族、酸液围场没有逐一实测。
- **医疗包 / 兵种支援 / 虫族模式的“号令” / 直升机降低**：默认键从 H 改为 **N**（这几样本来就是同一个动作）。
- **直升机升高**只用 K（空格），Y 不再升高。
- 玩家在「操作设置」里自己改过的键保持不变；新默认键和玩家自定义的键撞了，只给新默认键另找空键，不动玩家的设置。
- 提示文字改为跟随当前键位：上直升机的提示、互动提示、低血量提示、商店里医疗包和直升机的说明、右上道具栏“医疗包×n(N)”、底部操作提示。底部操作提示把“Q 左转视角 · E 右转视角”压成“Q/E 转视角 · Y/H 抬头低头”，否则加两项会超出屏幕两侧。
- `key-bindings.js` 与枪火集结用同一份文件。

## 经过

1. 照搬枪火集结的改法后先写了专门的验证脚本，第一轮就发现底部操作提示是按键位表动态生成的，自动显示了“N 医疗”，但没有抬头低头——加进去之后整条提示在 1280 宽下左右各溢出 84 像素，于是改成合并写法。
2. 截图时又看到右上道具栏还写着“医疗包×2(H)”：上一轮在枪火集结搜旧文案时用的规则排除了括号后面的情况，这种“(H)”写法漏掉了。这次按括号、斜杠、“H键”“按H”等写法又搜了一遍两款游戏，虫潮里只有这一处；枪火集结里同一行也在，但那个道具栏只在基地防守里显示，枪火集结里看不到，没有为它单独发版。

## 验证

- `verify-look-keys.cjs` 17/17（本地构建；线上与 Toy 的结果见 handoff）：默认键位、四种自定义键冲突情形、Y/H 抬头低头与限位、N 用医疗包而 H 不再用、直升机 K 升 N 降而 Y 不升、操作提示不超出画面、道具栏写当前键、无脚本报错。
- `verify-combat-controls.mjs` 通过。
- `verify-dash.cjs`、`verify-zerg-mode.cjs`、`verify-keyboard.cjs`、`verify-camera-response.cjs` 都有失败项，但在线上 0.38.0 上跑出来是完全相同的失败项（脚本本身过期），与这次改动无关。其中用到旧默认键的几处按键和断言已经改成新键位。这些脚本还会往旧 release 目录里写文件，跑完已还原 / 删除。
- 没做：手机真机；真人试玩；各模式逐一实机走查（只在基地防守的准备阶段和直升机上验证了按键；虫族“号令”用的是同一个动作，显示的键跟随键位表，没有单独实测）。
