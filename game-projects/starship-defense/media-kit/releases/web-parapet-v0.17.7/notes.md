# 城墙胸口矮墙 v0.17.7

- 真实问题：旧存档保留了早期正面8段合金围墙，厚城墙升级后仍重新加载到墙顶；只测试新开局未覆盖此迁移问题。
- 加载没有rampartRevision标记的旧存档时，仅清理旧默认8个坐标的围墙；金币、关卡、其他建筑不变。新存档记录迁移标记，之后玩家自行造墙正常保存。
- 城墙外缘增加连续1.35米高、0.6米厚的实体矮墙，约角色胸口高；城门与上坡通道保持畅通。能阻止误走跌落，主动跳跃可翻出；无墙内缘仍能跳下。
- 矮墙阻挡敌方直射弹；高于掩体的暴露部位仍会受伤，不是无敌保护。高速弹先比较遮挡再结算人物伤害。
- 允许我方在矮墙处向下射击，近身墙脚敌人可被正常自动瞄准和开火击中。

验证：旧存档迁移与再次存读、前侧后矮墙挡人、跳越、坡道与无墙边缘、墙脚命中、低弹被挡/高弹命中、键盘与模拟触屏、原跳跃/洞穴/载具回归。
手机为桌面视口模拟，未做真机B站App验证。自动化录像为真实WebGL运行，含测试定位，无游戏音轨。
封面沿用：基地局部结构修复，不改变游戏主题与视觉身份。

发布：网站资源及双端测试通过；相同哈希Toy包已发布，正式入口复测通过。两个视频简介v0.17.7已公开逐字核验。
