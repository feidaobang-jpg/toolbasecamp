# 抗战瞄准与拖炮操作 v0.33.1

战役默认第一人称，仍保留C切换。Z/右键/举枪按钮缩小视野和散布，瞄准时隐藏切枪栏；射击方向从枪口收敛到相机中央的实际交点，避免旧平行射线与准星错位。四把枪模型保留二战外形，轻机枪使用偏置准星避开顶置弹匣。

弹头铜色，曳光为深色边缘与橙金芯；补充短枪口闪光、烟、命中反馈。枪弹240m/s、重力9.8m/s²，炮弹60m/s，均为适合小地图的简化玩法参数，不宣称真实武器弹道或全物理模拟。镜头没有随机位移；后坐动作仅在枪模型上。

炮旁K拉炮，WASD/摇杆慢速移动，I放下后再次I操炮；Q/E或A/D左右，W/S或±高低，空白处拖动也可瞄准。预计落点标记与仰角、射程提示随炮口更新，对上城门后J开炮；保留原搬弹、装填和三次命中开门流程。轮子随拖行转动，炮管/炮架安全范围及转向时人物轨迹不能穿墙；放炮时保存姿态，继续检查点恢复位置。

实测发现手机拖视角区域遮住了战役按钮，统一提高战役交互控件层级，保持低于菜单。横竖屏模拟可点瞄准、切枪、小队与炮口按钮。电脑真实按键和鼠标、手机按钮模拟及原模式回归通过；真机/多指/完整正常难度连续三章未验收。

网站完成测试即发布；平台包和已有视频说明登记22点b-2，不操作新片。沿用游戏列表虫潮封面：本次为同一游戏内模式操作和效果调整，原守城默认主模式画风与入口没有改变。采集原片仅供开发QA、无音轨、使用阶段直达及无敌，不能当作已审成片。
