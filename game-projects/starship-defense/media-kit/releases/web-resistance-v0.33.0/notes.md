# 抗战战役开发记录

用户选择“剧情战役＋每关可重玩的小型战场”，继续确认是否独立游戏。实施为虫潮内新模式，复用输入、音效、渲染和菜单，场景、人物、任务状态及检查点独立；原现代战地模式仍可进入。

三个章节分别围绕交通壕与手榴弹、骑兵冲锋与掩护撤离、搬弹操炮与城门突破。李云龙、张大彪、孙德胜以角色名及原创短指令出现；没有导入电视剧视频或配音，骑兵章节改编为可玩的撤离任务。

实测发现并修复：重复几何合并丢掉枪械顶点色；屋顶坡度和招牌朝向错误；城门楼底部挡住破门通路；骑兵冲过封锁后运输车留得过远；炮弹用尽后缺少明确补充路径；切换视角提示在独立主循环里不消失；一处检查点和三处敌兵出生与掩体重叠。出生和队友救回位置现在搜索附近空位。

验证包含真实键盘移动、跳跃、上马、冲刺、手雷和三发炮击，三章阶段/结算/重玩，检查点死后复活与刷新继续，手机横竖屏模拟及回到原战地/房车。任务阶段隔离测试使用QA定位、清敌或无敌，不冒充完整正常难度通关；录像同样标注了后续阶段直达和无敌。连续动态画面另行检查，录像无音轨，不能作为已审核成片。

本机封装用于确认自包含与体积，未直接上传平台；完成网站发布后进入现有22点批次，保留先前渠道限制。新视频未请求、未发布。

最终画面复查发现城门两侧有空隙，补齐石砌门框与对应碰撞；封闭城门不能从侧缝绕过，炸开后只开放中间通道。
