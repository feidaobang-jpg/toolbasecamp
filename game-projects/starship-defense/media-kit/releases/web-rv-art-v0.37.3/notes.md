# 房车实机美术样板

目标：回应用户「游戏能否像封面一样好看」，先改善虫潮房车模式的可玩画面。以程序化模型和灯光完善低模风格，没有把封面图片贴到游戏里。新增装饰复用合批/实例化，未改变碰撞与路线。第一轮天空偏橙、地面有规则方格，已调整为更淡的天空和连续细噪声；未拍到这些早期失败画面，不补造过程。

旧版同站位截图为保存旧构建后的重演；录像经过QA起点重定位，之后是真实RAF与键盘事件驱动，不是离线动画，没有音轨。合并了其它任务已发布的菜单、最近目标瞄准和浅虫洞，保持双方改动。

故事素材：before-street → final-street/房车侧前 → final-realtime 的僵尸、车灯和驾驶。此批适合展示房车画面更新，不包含整款游戏完整通关。电脑高/流畅画质约170FPS受本机刷新上限约束；不推断手机真机帧率。
