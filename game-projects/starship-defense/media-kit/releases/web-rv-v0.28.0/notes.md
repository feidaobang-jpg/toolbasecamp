# 房车突围首版

用户决定将房车打僵尸思路收进《虫潮围城》，担心短期增加太多模式，因此本版控制为单车、单人、单路线；敌人沿用虫群。复用已有角色、载具射击、音效、视角和操作，新增移动基地、三个补给点、燃料/零件、维修和两级机枪/装甲升级。

路线约2480米。每站停车通行35秒，搜索18秒，维修8秒，升级/补油6秒。停车时房车自动射击且仍受虫群和酸液伤害；人员阵亡复活，车毁失败。整备选择面板暂停，实际作业恢复战斗；离车、上车或死亡取消作业并返还零件。缺油仍可缓慢驾驶，避免无解卡死。

存档使用独立本地键 chongchao-rv-breakout-v1，含位置、车损、燃料、零件、升级、补给和通行进度。房车不上传基地云存档。回到主菜单恢复原战场；基地与对战进度保留。首版不含房车联机、路线生成、多车或独立僵尸游戏。

QA边界测试部分使用传送和计时推进；驾驶、8秒维修、6秒升级和触控按钮是实际浏览器操作。完整路线为固定0.05秒模拟，自动导航、关闭音效，无无敌或额外资源，311.1秒完成并搜索三站。此结果证明规则可通关，不代表真人难度评价。

Edge无界面、RTX4060Ti、1280×720、高画质：初始36虫负载下驾驶与转视角连续7秒，平均134FPS、中位5.9ms、P95 15.8ms、超过50ms为0；采样中虫子会被正常击杀，并非全程维持36只。手机仅390×844/844×390视口和触控模拟，未做真机性能验收。原对战30项和战役重开音频5项通过。

开发中发现路线天空固定在中点时，远处天空球形成灰色断层；已改为随房车平移，退出时恢复。旧错误记录不伪造媒体。当前主游戏封面继续沿用：原有基地防守与虫群仍为主内容，房车是菜单里的追加短线，整体美术和主色调未替换。
