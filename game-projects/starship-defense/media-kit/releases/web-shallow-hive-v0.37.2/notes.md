# 母巢浅坡与回程优化 v0.37.2

目标：玩家反馈母巢地下往回走慢、吃力。实测旧母巢22米深，沿既有98米高差过渡的最大坡度18.61°，上坡速度最低为平地73.06%。

仅把共享HIVE.depth从22改为4米；地面、洞顶碰撞、母巢摆设及角色落地继续从同一高度函数派生。保留三条路线、洞内10米通道净高和15米大厅中心净高，保障母皇、机甲与队友活动空间；浅层洞壳会随地板整体上移，外部可见拱顶不是新增可走山坡。最陡处3.50°、上坡速度95.10%。按相同正常步行输入，中央完整回程由14.83秒到12.80秒，侧道17.65秒到15.70秒；不改全局速度或射击规则。

验证：三视口走完三洞进出；真实键盘、虚拟摇杆回程；三路虫群（中央含Boss）；四兵种及吉普/坦克/机甲进出、直升机洞口待命；旧存档继续/导出/导入，旧地下高度落地；六处低山坡及最近目标瞄准回归。手机是Edge视口模拟，不是真机。联机整局未重跑。

旧版采集保留desktop原图、步行时长及录像；旧采集在手机步骤遇到过时的摇杆选择器停止，baseline仅包含桌面，不把缺失手机旧画面补造为基线。修正选择器后新版三视口完成。历史rescue全量脚本随后遇到已移除的recallUnits QA接口；新增HIVE_ONLY范围，实际执行13项洞内队友/载具回归，不声称旧经济/救援全套通过。

四视角母巢转向/跳跃动态已留存并查看16张顺序帧，地面、洞壳、母皇与出入口正常。独立10秒移动转镜头性能测量，无录屏，RTX4060Ti/Edge D3D11；数据见performance.json，不能外推手机性能。录屏静音，仅供后续合并选题证据。
