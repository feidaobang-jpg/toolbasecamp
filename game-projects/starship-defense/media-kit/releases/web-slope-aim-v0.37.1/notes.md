# 虫潮：一人高山坡与最近目标瞄准

用户要求把山坡降到一人高，自动瞄准最近的怪。实际六处野外山坡原高3.2～8米，改为2米，接近装甲兵主体高度；基地高台、虫巢、外围不可行走山体保留。地形、山顶堡垒和行走碰撞共用高度。

旧瞄准按朝向、首领、精英与aimBias加权，且触屏/联机有不同扇形范围。现在按当前受控玩家或载具的水平距离，在射程内选择最近的存活、已出土目标；四视角、触屏、联机输入、载具和手雷一致。手动瞄准和独立枪战规则保留。

开发先留存旧包同站位画面和选敌结果，再改高度与选择逻辑。基线近处小怪未被选中，改后所有视角选中，实测近怪受90伤害、远首领未受伤。山顶堡垒进入、矮墙射击、保存/备份和新版菜单复验通过。旧第一人称测试仍按六视角循环且点击已迁出的枪战模式，已调整为当前四视角及虫潮现有范围。
