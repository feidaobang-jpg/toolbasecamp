# 队友职业与驾驶

用户要求队友能够驾驶载具，并增加队友种类。保留四人上限，通过明确的职业分工及商店驾驶分配增加配队选择；不增加常驻操作按钮。

新功能验证包括自动步行接近载具、四种车辆出入基地、载具火力、隐藏驾驶员不被重复命中、玩家接管、损毁后安全下车、下关修复、副本前下车和职业/分配存档。转职按原生命比例换算，不能靠反复转职回满血。治疗/维修每名支援兵每次只作用于一个附近目标，驾驶时停用。

测试中手机商店第一次快速点标签被既有250毫秒防误触保护拦截；测试增加打开面板后的正常操作间隔，未移除防误购保护。没有可用的故障原片，不把该测试节奏问题包装成游戏事故。

实机录制使用明确的 QA 摆位与无敌测试模式，之后是真实时间自动键盘输入；Playwright 录像无音轨。只采集游戏网页。功能验证使用普通模式，性能另开页面测试，不把录制开销算入测量。封面沿用：敌人、场景、角色及载具美术风格不变，新增角色名牌不足以导致图文不符。
