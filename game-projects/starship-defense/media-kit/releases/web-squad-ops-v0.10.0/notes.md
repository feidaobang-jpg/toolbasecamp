# 虫潮 v0.10.0 开发记录

本轮依据用户的 S9 截图与四项功能反馈。原版已有 replaceChildren/Object.hasOwn 补丁，移除两者的模拟未复现原故障；因此不把它们写作已确认根因。新版以普通脚本包消除 ESM 入口依赖，同时让加载失败时保留可读布局、重试和浏览器版本。S9 仍需真机回测。

三个副本复用现有战场区域，有独立清敌、守点和双小首领目标；不宣称新增三张独立美术地图。装备对每个队员槽位独立保存。设施上限含城墙和炮台，共 64 座。

QA 初次脚本试图在手机点击桌面工具栏的副本入口，该工具栏按原设计在触屏模式隐藏；改为真实玩家入口：暂停→副本，测试通过。

截图与录像存放 captures，本机保留不入 Git；测试布置明确使用 QA 钩子，不冒充自然随机游玩。封面沿用：主画风、主场景和默认视角未改变。
