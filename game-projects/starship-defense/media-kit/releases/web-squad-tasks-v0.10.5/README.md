# 虫潮围城：队友自动协作 v0.10.5

- 移除常驻“队令”触控按钮、G 快捷键和“出击”模式。暂停菜单保留“队友任务：跟随我 / 守基地”，新游戏默认跟随。
- 跟随队形只索敌玩家附近 24 米范围；离队超过 18 米优先归队，近身后退，不追远处残血敌人。队友分散索敌、就近拾补给。
- 虫潮接近基地 30 米或城门 24 米时自动回防，威胁清除 3 秒后恢复跟随。主动留守则保持基地防线；突破城内的虫群会引导队友收缩防线。
- 留守岗位避开门口通行区域，双向过门仍自动开门、无人后关闭。
- 副本自动跟随，不覆盖长期任务选择；旧“出击”存档迁移为跟随，旧“守城”保留。修复移除手雷后新存档被云存档校验误拒绝。

验证：`verify-squad-tasks.cjs` 通过，覆盖真实键盘/手机菜单输入、索敌分配、回防与恢复、追击约束、存档迁移、双向过门和副本任务恢复。`verify-mobile-classes.cjs`、`verify-squad-ops.cjs` 回归通过。均为 Edge 浏览器及手机视口模拟，不宣称手机真机性能验证。

该发布使用已提交的深色战场素材独立构建，不包含另一个任务尚在调整的敌人新模型。网站和 Toy 的实际发布结果见同目录 `handoff.json`。
