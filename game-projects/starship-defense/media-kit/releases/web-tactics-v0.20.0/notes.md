# 虫潮围城：小队战术升级 v0.20.0

本轮是在既有游戏上增加玩法与体验，基础版为 web-restart-audio-v0.19.4。用户确认的范围：逐人留守/出击、虫潮预告、第一章前五关节奏，保持现有战役、武器、无限手雷与画风。

## 实现

- 战术部署可逐人指定跟随或留守，全队快捷指令会统一分工。手动任务优先；自动回防可关闭，开启时只影响未单独下令的队友。驾驶员使用自己的任务，副本内暂时跟随，返回恢复。分工、自动回防选项和上一关战报随本地/云存档保存；旧档继承全队任务。
- 预告和实际出兵共用计划：显示虫种、数量、洞口和布防提示；现有野怪另列。首周目第一章前五关依次为城门入门、双路地面、酸液掩护、空地夹击、三路混合；后续章节保留本章虫种及首领。自由测试和副本明确不使用战役预告。
- 前五关额外通关新兵补给为180/220/240/260/300金币，只在胜利时一次结算。普通难度第二关结束的保守固定收入足够雇佣机枪兵与医疗兵；可选野怪、精英、母皇与副本不计入这项最低预算。
- 工程兵留守时走近基地范围内受损设施维修；头顶标签标明守家/跟随。战报记录维修前的基地/城门耐久、设施/队友/载具损失，以及从本关整备到结算的收入和支出。

## 实测与真实问题

- 四种视口（1280×720、844×390、390×844、568×320）按钮和键盘导航、暂停恢复、存档验证、15种难度/关卡组合的预告与出兵一致性通过。
- 首轮发现新面板刚打开时导航会覆盖主动选中的键盘焦点，窄屏缩放后按钮不足44 CSS px；修复并复测通过。首轮记录见qa/first-run.json。
- 留守工程兵前往墙顶炮塔时，被城门两侧的路点判断反复拉回入口；改为从内侧墙顶接近受损设施，实测炮塔耐久50→250。没有问题发生前的视频，只有测试记录，不重演历史故障。
- 全队守家与分队前出均用正常生命、实际赚取的金币、实际战斗/寻路函数完成前五关。控制测试将玩家放在固定战术站位，排除可选野怪和母皇收益；属于加速平衡夹具，不是真人试玩或虫洞突袭通关。
- 小队职业/载具、自动回防/城门穿行、跟随与枪口开火、云档适配回归通过。首次通关夹具未走下一关整备阶段而沿用了已领奖标记，已修正测试流程，没有为测试修改游戏奖励。
- 48混合虫＋4队友的移动/转镜头负载独立测量；数据见qa/performance.json。本机Edge、RTX4060Ti，手机只是视口/触控模拟。
- 已留有效实时浏览器录像及DOM截图。WebGL captureStream/MediaRecorder在本机只产生空媒体，替换为Playwright浏览器录像；该录像无游戏音轨，后续制作视频需补录带音母版。不将其标为完整成片素材就绪。

## 内容与发布交接

可以围绕“留人守家，带队前出”的实际变化制作下一期。当前夹具只支持分工、混合虫潮和工程兵维修；带队钻洞反攻母皇的完整挑战仍需普通模式实录，不能用测试定位录像宣称完成。

本轮没有改变画风、场景或默认视角，网站和Toy封面沿用。网站部署、Toy包哈希/审核状态、两条已确认视频简介公开核验及活动检查结果以handoff.json与对应渠道记录为准。新视频尚未制作或发布。
