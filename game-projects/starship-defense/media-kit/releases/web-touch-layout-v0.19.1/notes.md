# 手机按键位置自定义 v0.19.1

来源：虫潮Toy动态下 bili_59253225804（评论316226527777）的自由摆放按键建议。理解为触屏布局自定义，保留现有默认样式。

新增暂停中的拖动布局编辑，可从主菜单或暂停设置进入，保存当前设备布局、取消或恢复默认。所有触屏功能键和摇杆独立移动；未调整项沿用原预设，窗口变化保持画面内。设置与战役存档、电脑改键分离。

7组针对性实际浏览器检查和现有电脑操作12项通过，截图与原始录像在 qa/captures；手机为视口模拟，无实体手机验收。测试不代表实体手机性能。沿用游戏卡片封面，本版无需更换。网站、Toy与B站简介/原评论分别核验并记入 handoff.json；不制作新视频。
