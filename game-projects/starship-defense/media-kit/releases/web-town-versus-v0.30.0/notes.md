# v0.30.0 本地试玩：房车城镇与对战成长

状态：本地验证完成，等待本人试玩审核；未合并部署主线，未上传 Toy/TapTap，未更新视频简介或回复反馈。此版不可进入 22 点自动发布批次。

试玩入口：http://127.0.0.1:8809/html/game/starship-defense/index.html

1. 主菜单 → 房车生存 · 废弃城镇 → 开始城镇探索。WASD 驾驶，I 上下车/搜索，O 地图与设施，J 射击，H 医疗，C 切视角。手机用同名按钮。
2. 先沿街自由开往南街修理厂或西街加油站，确认无需守站、无需按次序通过。停车后在车内按 O 即可办理对应服务。
3. 驶入旧住宅区看僵尸发现与追击，退远或绕建筑看它们回到原地。下车靠近黄色物资箱搜集零件，再到修理厂升级、超市兑换罐头/医疗包。
4. 随时前往北端营地，打开设施面板手动撤离；也可尝试搜齐六区。暂停退出后可继续独立城镇存档。
5. 主菜单 → 虫潮对战 → 选人数/电脑难度。20 秒开始双方自动出兵，此后每 25 秒补一波；靠近兵线作战观察金币、经验、等级和生命上限。死亡保留等级，新一局重新 Lv1。

## 本次取舍与修复

旧房车路线用加油站关卡锁通行，和自由驾驶的预期冲突。本次重建为互通街区，资源设施决定去哪里，感染区决定是否冒险。只在房车模式改用僵尸，保留基地与对战原有虫潮身份。废弃超市用仍有备用电源的应急售货机解释交易；没有凭空新增有人经营的商店。

维修与升级改为场地服务，车内同样能办理；没有把每次服务都变成强制下车。搜索仍需要下车，空车会自行防御已追击目标。无油保留挪车能力，避免把资源短缺变成无法继续的死局。

对战把被动银行经济与主动兵线收益并存，等级是每局成长。没有照搬整套 MOBA 英雄技能或装备系统；原有职业、枪械、派兵和建造继续发挥作用。

实机复查发现房车提示计时没有走原战役更新，提示会永久停留，已在房车更新中正常计时隐藏。修理厂/加油站的完整屋顶会遮挡第三人称，已改为破损开放屋顶，招牌移到车位侧面。对战新增等级信息后顶部核心 HUD 与右上操作存在重叠，已收窄并重新排布。

## 验证与素材限制

- `qa/results.json`：18 项城镇/成长/存档/操作测试。道路可达性使用实际车辆碰撞半径的网格遍历；驾驶、按钮与暂停用真实浏览器输入，边界规则有明确 QA 定位/加速。
- `qa/teams/verify-versus-teams.json`：24 项 1–4 对团队回归。
- `qa/online/verify-versus-teams-online.json`：15 项四浏览器真实 WebSocket 联机，包括主机升级、客机等级和生命同步、加入、掉线接管。仅本地服务，不代表公网网络条件。
- `qa/balance-1v1.json` 和 `qa/balance-4v4.json`：八局完整电脑加速对局，全部结束；样本少，不据此宣称难度完全平衡。
- 截图和 `captures/town-versus-realtime.webm` 为真实 Edge WebGL 运行，脚本操控，含声明的测试定位/推进时钟。录像无游戏音轨，不是已审成片。动态视觉已抽查，手机为视口/触屏模拟，未做真机验收。
- 基地玩法与平台封面沿用既有资产，本次只交本地玩法预览。公开网站、Toy、TapTap、已有视频说明的成功基线保持不变。

源版本和产物哈希见 `release-status.json`、`handoff.json`。试玩通过后还须记录批准渠道，整合最新主线并复验后才能发布。
