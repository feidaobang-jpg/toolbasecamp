# v0.7：坡顶也能成为射击据点

用户反馈：希望Q/E转镜头、手机操作、上下坡速度、山坡可进入堡垒，询问I键满血提示，并要求检查Toy SDK/CLI/Skill。

沿用圆润低模风格。扩展两座缓坡，平顶放有后方入口和四周射击窗的堡垒；约束地形最大坡度，测试实际步行入内，不用传送代替可达性验证。射击窗口真实放行激光，下沿掩体阻挡低弹。

I并非一个空功能：本来是医疗包/上下车/城门共键，满血不消耗是正确行为，但描述含混，且发现提示优先城门、执行优先载具。统一目标函数后修复，附高度筛选与最近载具选择。

SDK文档页在未登录IAB跳到介绍页。通过官方页面公开静态脚本内的类型声明核实API，另读官方GitHub Skill及本机CLI --help-json。未读取或复制登录凭据。作者与BV号由CLI只读查询确认，当前没有视频绑定，本次只添加游戏内视频入口，不自动绑定。

实测发现Toy在www.bilibilitoy.com隔离iframe运行，修正最初只识别www.bilibili.com的判断。预览不提供Toy ID，不能把isSupport=true当实际业务成功。显示中文提示；云档和榜单写入通过mock验证，未覆盖真实账号数据。官方公开API没有执行一键三连，入口明确为支持作者/查看视频。

前版v0.6遵从用户确认提交，平台先返回auditing，后mylist published，实际公开页出现测试模式/防空/洞穴等，运行目录v21159。v0.7独立预览待用户确认；不能将两者状态混同。

网站自动部署未及时落地，按项目规则仅SSH同步本款六个改动运行文件，七个文件公网校验通过。
