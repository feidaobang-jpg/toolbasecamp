# 真实开发记录

用户认为旧迁移版同时丢失了简单模型的可爱感和精细模型的整体质感，要求先试改 Q 版，认可后再更新技能。本次没有改技能。

改用原创程序化圆头装甲兵、胖甲虫与玩具基地，共享合并网格，以左右腿组和身体做动作。废弃写实岩石贴图的运行引用，保留原文件供回退。角色前脸初稿的护目镜与脸壳交叠、虫眼被头部遮住，在静态检查后前移修正；没有留下修正前原片，不能当录制到的事故。

截图原有悬空护栏源于城门组内使用了世界坐标，父节点又叠加一次高度与Z偏移；已改成局部坐标。血条仅受伤显示，并参与深度遮挡。手机准备提示缩短并移开动作区，隐藏桌面键盘条。

48活虫+4队友，两档各30秒射击压力，以及独立30秒移动/射击/四镜头压力均有原始帧时间。设备为 headless Edge ANGLE D3D11 / RTX4060Ti，不能外推到所有设备或真机手机。自动录像与帧率采样分开。

before-base.png 是本次动手前实际捕获的 v0.4.0，不属于新构建。其余截图以最终重新采集为准。normal-play.png 使用普通游戏开局；toy-variants 和压力录像有测试摆位/高血量，属于开发验收证据。无音轨，不声称完成声音听审。
