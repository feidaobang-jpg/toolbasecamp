# 地下虫巢与城墙攻防 v0.15.0

基于 v0.14.0 队友职业/驾驶版本，按用户草图修改地形与行军路线。

- 白点为发光菌装饰，已删除。三个入口逐渐下降到地下 22 米；连续联合洞顶覆盖三条通道和中央母巢大厅，无旧交叉切口。
- 波次敌人从母巢沿指定通道走到入口，再进攻基地；飞虫在出洞后起飞。母皇与护卫留在地下。
- 前墙厚 12 米，两侧与后墙顶宽 8 米，两条宽 8 米的院内缓坡登墙。墙顶可建炮台，守基地的四名队友自动登墙。保留现有四人队伍上限，不宣传百人防线。
- 按住 Shift 或手机跑步键为 1.65 倍步速，没有冷却、体力槽或无敌。K 闪避保留 2.5 秒冷却/火枪兵 1.8 秒。旧自定义 Shift 按键保留，自动给新增跑步选择空闲键。
- 原环境、敌人模型、兵种、载具和九种副本继续保留。毒区伤害仍关闭。

实际发现并修复：远景补地大平面穿过地下通道（改为仅填地图四周）；后山挡住后墙步道；墙顶与地表共面产生条纹；队友在坡顶被半径碰撞挡住；队友选择大厅巡逻点时错误更换入口、绕到洞外；入口目标切换过早导致往返。均有脚本复测，未留首次故障录像，不重演成事故素材。

验收：三洞玩家实际移动往返、三路虫群含大首领出洞、两条登墙坡与后墙通路、墙顶放置、四名守军登墙、四名队友跟入地下、跑步倍率与无无敌、闪避冷却。副本 34 项与队友职业/驾驶回归通过；三难度采样无毒伤。

实机素材为后台 Edge、QA 场景定位后真实键盘输入；录像无音轨。性能为 RTX 4060 Ti、48 虫 + 4 队友持续移动转镜头，不代表手机真机。原片与截图只留本机。

默认玩家视角与虫群造型不变，旧列表封面仍准确展示保留的兵种；本版另留城墙与地下实机场景，暂沿用现有封面。
