## 改动

1. **载具卡地形修复（严重）**：
   - 驾驶被挡时按单轴滑动贴墙走，不再整帧卡死（game.js 载具驾驶分支 canGo/单轴回退）。
   - 有移动输入却持续走不动约 1.5 秒时，用 rescueSpot+vehicleCanStand 自动挪到最近安全空地（与「载具救援」同一落点标准），并提示「载具已从卡住的位置脱困」。
   - 联机为房主权威模拟，修复在宿主模拟层生效并经快照同步；客户端输入过期/延迟导致的停顿观感随输入频率不变，但卡死后无需再靠救援按钮。
2. **RPG火箭筒**：商店 1300 金币。dmg 135、射程 46、爆速直飞、5 米大范围爆炸；打虫群、巢穴墙、厚甲。
3. **四连导弹架**：商店 2100 金币。扣一次扳机错开 90ms 连发 4 枚小型导弹（dmg 42、2.4 米爆炸、0.6 追踪系数），跑动中边移动边轰。换枪会取消未完成的连发。
   - 两把武器自动进入商店与武器栏；weaponDps 按 (burst) 修正商店秒伤显示；存档迁移无需处理（新增 id，旧档不受影响）。
