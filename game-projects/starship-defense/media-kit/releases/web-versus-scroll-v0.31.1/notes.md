# 对战建造与买枪面板滚动修复

用户手机截图显示建造面板只露出第一排，底部建筑及商店枪械无法查看购买。原触屏面板仅允许占逻辑屏幕高度的46%，卡片子元素又继承全局touch-action:none；竖屏旋转后只允许pan-y也不能覆盖实际滑动轴。

面板改为随可用屏幕高度伸缩，固定分类、路线、金币和关闭按钮，物品区独立滚动。卡片及子元素允许两个物理轴的触摸滚动，增加始终可见的上下翻阅按钮；极矮横屏扩大面板顶部空间。实时金币刷新保留物品DOM与滚动位置，切换分类返回顶部。

回归覆盖电脑、844×390、844×346、390×844、346×844、320×568与844×260，使用Chromium实际触摸手势、翻阅、选择底排特斯拉塔并放置、购买四连导弹架/等离子炮、扣费与关闭。测试金币通过qa入口注入，非普通玩家默认状态；手机为视口模拟，没有真机验收。

本版仅修界面交互，游戏场景、画风及核心玩法未变，沿用游戏列表与平台实机封面。网站验证后立即发布，Toy依用户本次紧急指令同步；TapTap与既有视频说明/公告按已有22点任务b-2登记，未制作新视频。
