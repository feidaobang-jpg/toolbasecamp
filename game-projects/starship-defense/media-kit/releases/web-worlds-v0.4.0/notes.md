# 本版真实改动与取舍

选择合并到现有网页虫潮，复用成熟双端玩法；原生Godot项目保留。网页采用重点精细的轻量3D：导入甲刃虫与士兵骨骼及动作，迁入岩石纹理，调整天空、雾、灯光、跟随镜头与前哨菜单。嵌入图片缩到1024并编码JPEG，虫子/士兵从15,357,716字节降到1,878,660字节；网格与动画未删减。

静态装饰实例化、减少不必要点光、远处动画降频；实时交战同屏限制48虫、粒子160、短暂尸体8。密集画面曾出现虫子模型重叠，加入有界局部避让；没有保存修复前动态原片，不能将重演称首次异常。自动化读取键盘打开建造面板过早曾导致检查失败，改为等待实际面板可见后断言；并非玩家游戏崩溃。

为避免误称全量移植，不移入Godot原生物理、50人编制或整个洞网，保留网页自身玩法。死亡无限复活但基地仍可失败。所有性能结果基于实际后台Edge/RTX4060Ti；录制和测量分开，不能把25fps录像编码当实时FPS。手机为桌面模拟、不是物理真机。

随后迁入重甲精英、虫后和机甲，五个GLB由34,777,672字节压至5,543,152字节；新增模型已单独做旧入口导航、机甲驾驶/射击/下车检查。机甲改为统一橄榄色，虫后无贴图部件降低饱和度，敌方血条保持固定世界宽度，避免随Boss尺寸遮住视野。
