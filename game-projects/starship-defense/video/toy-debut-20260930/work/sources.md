# 制作来源

- 游戏：本仓库`game-projects/starship-defense`生成的Toy v0.1.0发布包，公开链接 https://www.bilibili.com/toy/chongchao-qianshao/index.html 。发布记录见同游戏media-kit。游戏与录制均未使用未知第三方录像。
- 代码依赖Three.js r152，MIT许可，发布包已包含THREE-LICENSE.txt。几何角色、地形与WebAudio声音来自项目游戏。视频使用生成画面与现场合成声音，不另行分发Three.js源代码。
- 解说：edge-tts在线调用微软zh-CN-YunxiNeural，rate +5%；不是离线TTS，不是克隆作者本人声音。服务使用条件未在本期独立做法律评估。
- 字幕与动效字体：本机Windows Microsoft YaHei，用于渲染后的画面；不分发字体文件。
- 封面：imagegen基于`qa/cover-ref.png`（defense源35.5秒）重新布局，实际提示词与生成文件位置见`edit/bilibili-zh/covers/prompts.md`。不是未经处理的游戏截图。
- 成片未加入库存音乐、影视片段或他人视频。游戏原始音轨是音乐与音效的合轨，独立人声与最终混音另存audio目录。
- 本任务仅生成文件，平台AI内容标识等投稿设置需在实际上传时依入口填写，没有替用户确认账号声明。
