# 坦克大战 3D：经典 35 关 + 魔改无限周目（Tank Battle 3D）

## 一句话玩法
一款游戏两种玩法：**经典复刻**按 FC《坦克大战》原版 35 关、原版敌军名单与数值逐格还原，只把画面变成 3D；**魔改**是 100 关一周目的自创战场，加入 2D 版的船、手枪、装甲、精英怪、敌军抢道具和小 Boss / 大 Boss，打通进入更难的下一周目，周目无限。

## 背景
- 之前网站上有两款坦克大战：2D 版（`tank_battle.html`，有 Boss、章节、船、联机合作）和 3D 版（只有第 1 关是经典结构，第 2～50 关程序化生成）。B 站评论问「怎么只还原第一关」。2026-10-04 用户决定合并：画面用 3D，开局选「完美复刻经典」或「魔改无限周目」。
- 用户以为原版是 50 关；FC 原版《坦克大战》（Battle City，Namco 1985）实际是 35 关，打完进入第 36～70 关（同样地图、敌军按第 35 关），之后回到第 1 关。经典模式按这个原版结构做。
- 2D 版页面保留（主菜单「多人联机合作（2D 版）」可进入，联机只在 2D 版），游戏中心只留合并后的 3D 一张卡片。

## 操作
- 电脑：WASD 行驶（随视角吸附四方向），J 开炮（经典每按一下一发；魔改可按住连发），Q/E 按住无极转视角，C 切换视角（斜俯视 / 正俯视 / 近景 / 正视 / 第一人称），Esc 或 Enter 暂停；菜单 ↑↓ 选择、←→ 调整、Enter 确认。
- 手机：左侧浮动摇杆（四方向，主轴带滞回），右侧 J 开炮大按钮，上方 Q / C / E 小按钮；竖屏开始后自动把游戏旋转成横屏布局并逆变换触控。开始不自动全屏，独立全屏按钮。
- 第一人称：镜头跟着车头转，按下方向键那一刻锁定方向（W 前进、A/D 左右转向、S 掉头），按住不会原地打转；站着不动用 Q/E 看向侧面超过 45° 时车头跟着视线转。

## 经典复刻（35 关 · FC 原版）
- 地图：原版 35 关逐格还原（13×13 个 16px 方块，砖块按 4px 一块削除、坦克按 8px 格阻挡），河、树林、冰面、钢墙照原版。
- 敌军：每关 20 辆按原版出场名单与顺序，中 → 右 → 左三处轮流出生；出生间隔 190−4×关号 帧，同屏最多 4 辆；第 4、11、18 辆闪红色，第一次被打中掉道具。
- 数值：玩家 0.75 px/帧，普通敌军 0.5、快速 1；弹速 2 / 4 px/帧；子弹上限、三星打钢、子弹互撞只在有玩家子弹时抵消、头盔 / 定时器 / 铁锹按 64 帧粒度计时、敌军 AI（格点 1/16 决策，按时间从乱走 → 追玩家 → 攻老鹰）、开火 1/32、冰面滑行都按 ROM 调研数值。
- 道具：头盔、定时器、铁锹、星星、手雷、坦克 6 种，原版 16 个固定掉落点和掉落概率表；道具不过期，下一辆红色坦克出场时收走。
- 计分与流程：100/200/300/400 分，道具 500；满 2 万分整局奖一次命；灰色幕布 STAGE、原版黑底计分页（逐个计数）、GAME OVER 字样从底部升起；第 35 关之后进入 36～70 关，再回到第 1 关。
- 起始关卡 1～35 可选（原版也能在开局选关），标题背景实时换成所选关的原版地图。
- 默认原版 3 命、一发就坏；选项可改成无限命 / 标准 3 格耐久（标准耐久时第 7、14 辆敌军掉修理包）。

## 魔改无限周目（100 关一周目）
- 10 个章节（锈湾、青苔沼、熔岩脊、霜原、紫雾林、砂海、深渊礁、雷暴原、夜鸦城、终焉虚空，沿用 2D 版章节名），每章换天空、地面、水 / 岩浆、树叶配色和地形偏好。
- 每章第 5 关小 Boss、第 10 关大 Boss、第 100 关终焉 Boss；其余关混入精英怪（精英重炮 2 血双发快弹、火焰车 4 血烧墙烧树）。
- 小 Boss 五种（按章节轮换）：火焰战车（2 格宽火焰弹）、双管突击车（并排双发 + 冲锋）、布雷车（埋雷，炮弹可提前引爆）、指挥车（呼叫护卫，护卫活着时有护盾）、狙击炮车（同行同列时红色激光瞄准再射穿甲弹）。
- 大 Boss 32px 体型、1～4 根炮管，按档位解锁招式：宽穿甲弹、三向齐射、连射、召唤护卫、迫击炮（地上红圈预警）、宽火焰弹；血量过半暴怒加速；背后装甲最薄，从后面打伤害 ×2。Boss 能碾碎挡路的砖墙，但重型炮弹打不穿老鹰围墙（只能被普通炮弹慢慢削）。
- 2D 版玩法迁入：船（能过河，每层替你挡一发，最多 3 层，船沉在水上会被推上岸）、手枪（直升三星并加装甲，四星能烧掉树林）、星星到三星送一层装甲、敌军抢道具（道具放 4 秒后敌军碰到就抢走，效果反过来对付你）、道具 20 秒后消失。
- 难度：关号 + 周目组成的进度位置决定敌军数量（16～34）、同屏上限（4～6）、移速、弹速、开火频率、重甲血量、Boss 血量；曲线渐近收敛，高周目不会变成秒杀。分数倍率每周目 +0.5。
- 默认无限命、标准 3 格耐久，修理包固定在每关第 7、14 辆敌军被击毁处（经典一发耐久时换成 500 分奖章）。过关自动存进度，主菜单「继续第 N 关 / 从第 1 关开始」；旧版 50 关存档自动迁入。

## 失败 / 成功 / 重玩
- 失败：老鹰被毁，或命用完 → GAME OVER 字样升起 → 原版计分页 → 结算（倒在第几关、击毁、Boss、阵亡、用时、命数与耐久模式）→「从第 N 关再来 / 重打第 N 关」、主菜单、游戏列表。
- 成功：敌军全部消灭 → 计分页 → 下一关；魔改第 100 关之后进入下一周目。
- 暂停菜单：继续、从本关开头重来、演示模式、视角、画质、音量、帧率、全屏、主菜单、游戏列表。

## 标准选项
模式、起始关卡 / 进度、命数（按模式分别保存）、耐久（按模式分别保存）、演示模式（无敌含老鹰，默认关、不保存、开过不计最高分）、视角（按模式分别保存）、画质（自动 / 高 / 流畅）、音量 0～100%、触屏按键（自动 / 显示 / 隐藏）、帧率显示、全屏、返回游戏列表。最高分按模式分开（经典初始 20000，与原版一致）。

## 主要功能（implemented）
- F-classic-35：原版 35 关地图、名单、数值、道具、流程与 36～70 关循环
- F-remix-100：100 关自创地图（10 套布局 × 10 章节主题 + 河道 / 水塘 / 树林 / 冰面点缀 + 连通性校验 + 中路护卫）与无限周目
- F-bosses：5 种小 Boss、10 档大 Boss + 终焉 Boss 的招式、预警、暴怒与弱点
- F-2d-gameplay：船、手枪、装甲、精英怪、敌军抢道具、修理包
- F-views：5 个视角预设（含正视剖面、第一人称驾驶舱）与 Q/E 无极旋转
- F-options：标准游戏选项与按模式保存
- F-audio：原版 FC 音效（开炮、打砖、打钢、爆炸、道具、开场曲、计分、GAME OVER、暂停、冰面）+ 程序合成的引擎声和魔改音效
- F-controls：键盘全程、手机摇杆与按键、竖屏自动横置

## 限制与计划（planned）
- 联机合作只在 2D 版（菜单入口跳转），3D 版暂无多人。
- 原版 2P 双人模式未做。
