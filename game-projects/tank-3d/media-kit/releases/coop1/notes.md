# 坦克大战 3D · coop1 双人联机

分类：正式版本。用户确认先验证 Toy 联机链路，再在现有坦克大战 3D 加入房间码邀请与两人合作守基地。

- 主菜单新增双人联机，六位房间码、昵称、准备、房主开始；经典 35 关与魔改模式沿用现有战场。
- 房主运行唯一玩法模拟，服务端转发客机输入与房主快照；两辆坦克、炮弹、敌军、可破坏地形、基地、过关与结算同步。
- 每人独立命数、耐久与装备，金色 1P / 蓝色 2P，共用团队得分；联机不覆盖单机进度或最高分。
- 暂停与继续同步全队。任意玩家离线结束房间，明确提示重新邀请；本版不做中途加入、房主迁移或随机匹配。
- 网络失败可返回单机；旧 2D 联机协议保持独立。

验收：逻辑双玩家与快照往返、独立受伤与耗尽命数、分数奖命与装备跨关；服务端两席限制、准备门槛、权限、输入转发、离线清理与旧协议隔离；桌面与手机视口模拟的两浏览器建房、移动、客机开火、暂停、操作模式切换、横竖屏、过关、离线、返回单机。

单机旧 browser-check 中“行驶带着第一人称镜头转向”与“手机 Q 按钮”断言已不符合当前主线（独立转头和空白拖动）。本次将断言更新到已有行为，不改变游戏的单机视角规则。

本地网络调试使用 127.0.0.1:8792；正式版及 Toy 使用本站 wss 联机服务。联机为房主权威的休闲合作，不提供服务器反作弊或持久房间。手机视口模拟与浏览器双端验证不等于 B站 App / 多指触控真机验收。

截图和录像见本版本 captures 与 qa/out；真实开局截图与隔离敌军后的输入测试截图分别标记，不将测试操作当正常实战。封面沿用：地图、主体画风和坦克题材未变化，联机入口通过菜单说明。

网站、Toy 和 B站简介的发布状态以 handoff.json 与 bilibili-sync.json 的实际核验记录为准。

收尾真实ASGI日志检查发现客户端断线后再次close会抛WebSocketDisconnect；补充关闭防护及对应回归测试（服务端3项通过）。仅服务端修正，已验证Toy前端包未变，不重复送审。
