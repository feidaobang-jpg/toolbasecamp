# 道具卡死修复 · 2026-10-01

基于 single-view1 的当前 50 关版本。用户反馈第一关出现道具提示后画面卡住。

在真实 Edge 浏览器中移除 Canvas roundRect 能力复现：首次道具出现触发 TypeError，游戏时间连续两次读取保持不变。该 API 在部分旧嵌入内核不可用；用户具体浏览器尚未知。改成通用 Canvas 路径绘制圆角，不改变道具外观及规则。

额外修复：爆炸/护盾光环复用几何资源，重开/换关释放计分贴图；Toy 包共享控制模块语言文件改为包内路径，补全语言切换接口并提取坦克双语字典，避免模块 404、原始 key 文案及切换异常。

验证：19 项逻辑检查通过；网站版与 Toy 自包含包桌面/手机竖屏模拟均通过六种道具出现、拾取、过期、保护/冻结/铲子计时、连续五次复活、基地失败、暂停/继续、中英切换、第 50 关进入第 2 周目。旧 Canvas 能力条件下帧循环持续运行。100 次重复光环后几何资源数 21→21。

实测 Edge + RTX 4060 Ti，1280×720，DPR 1，约八秒连续移动/射击/切镜头：平均 168.4 FPS，帧时间中位数 5.9ms、P95 6ms，1 帧超过 50ms；测量时未录像。另存实时自动化短片并检查连续抽帧，画面正常。移动测试仅视口/触控能力模拟，未测真实手机性能。短片无声音，本次未评审声音。

本版 captures/ 的短片与图片仅留本机，JSON 验证与轻量交接记录入库。旧版本媒体不改归属。
