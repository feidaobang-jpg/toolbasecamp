# v0.2.0
沿用已有第一关 3D 同人原型，保留程序化模型、砖墙、老鹰、20 辆敌军与六种道具。本版补齐手机竖屏横置、触控逆变换、独立全屏和固定镜头输入。

真实问题：原手机竖屏会阻止游玩；现改为自动横置并通过触控方向测试。浏览器 resize 事件在虚拟帧 QA 中异步到达，测试等待事件后再推进帧。

验收：桌面开始/暂停/基地失败/重玩/清关（结局用明确 QA 捷径），横屏双触控、竖屏触控方向、五次连续死亡与复活、护盾结束、演示开关。真实 Edge 硬件渲染帧时间独立测量见 captures/perf-*.json。

媒体：浏览器全页录像出现画面冻结，检查后改用 Canvas captureStream 实时采集。录像不含 DOM HUD 与声音；截图包含 HUD。不得称为完整有声游戏母版。真机手机与完整有声通关录像待补拍。原 v0.1.0 媒体保留原构建归属。
