# 公路打僵尸 3D（Zombie Road 3D）· overview

- 入口：`public/html/game/zombie-road/index.html`（站点路径 `/html/game/zombie-road/`）
- 引擎：Three.js 0.170.0（站内 vendored），全部美术为程序化几何体 + canvas 纹理，音效为 WebAudio 程序化合成，零外部素材
- 版本：0.1.0（2026-10-01）

## 一句话玩法

雪夜公路上，僵尸潮顺着车道涌向你身后的沙袋防线；六波一波比一波凶，击杀捡零件、按 U 建自动机枪塔，活到第 6 波「巨骸领主」倒下即胜。

## 背景与原创声明

灵感来自同作者的单机 Godot 游戏《哆啦A梦小镇·北境感染公路》（雪夜公路六波守防线打僵尸、零件建塔）。网页版只取其核心玩法方向（雪夜公路 + 六波尸潮 + 沙袋防线 + 零件建塔），**世界观、命名、题材、美术、音效、数值与代码全部为本次原创**（原创丧尸题材，未使用哆啦A梦 IP，也未搬运原作任何素材、贴图或音频）。

## 操作

电脑（全程键盘可玩，不依赖鼠标，不使用 Pointer Lock）：

| 按键 | 功能 |
| --- | --- |
| W A S D | 移动（相对镜头水平轴） |
| ← / →（按住） | 连续旋转视角 |
| ↑ / ↓（按住） | 有限俯仰（0.12–1.25 rad） |
| J（按住） | 射击（喷火器为持续喷射） |
| L | 翻滚闪避（翻滚期间无敌） |
| 1 / 2 / 3 | 切换武器：步枪（速射）/ 喷火器（短距锥形持续群伤 + 点燃 DoT）/ 狙击枪（高伤慢速） |
| U | 在准星地面落点建造自动机枪塔（100 零件，场上 ≤6 座，有 HP 会被僵尸攻击） |
| I | 花费 40 零件，维修附近损坏的机枪塔（9m 内） |
| Q / E | 单次按下切换镜头预设：Q=越肩，E=高位战术 |
| C | 回默认视角 |
| Enter | 开始 / 波间继续 / 结算后重玩（页内重玩，不刷新页面） |
| Esc | 暂停（不 preventDefault，不会拦截浏览器退出全屏） |

辅助瞄准：准星锥形范围内自动软锁定最近敌人（金色圆环标记 + 准星高亮），hitscan 自动吸附目标中心，键盘瞄准负担低。

手机：左下虚拟摇杆（模拟量）；右下动作按钮 J 射击 / L 翻滚 / U 建塔 / I 维修 / 1-3 武器（字母 + 功能标签，56–82px）；右侧镜头区 ↺/↻ 按住连续旋转 + Q/E/C 预设。Pointer Events 按 pointerId 跟踪，pointercancel / 失焦 / 暂停即清空全部输入。竖屏开始后整个容器旋转 90° 成横屏（触控坐标逆变换）；开始不自动全屏，「全屏」按钮对整个容器（含触控层）请求全屏，失败给 toast 回退提示。

## 目标与规则

- 沙袋防线完整度 = 防线 HP（1200）。漏过玩家走到沙墙的僵尸会啃防线，防线归零即失败（核心失败条件）。
- 击杀掉落零件（14m 内自动吸附飞向玩家）与概率医疗包（10%，+30 HP）：普通感染者 6 / 疾行者 6 / 装甲怪 14 / 酸液投手 10 / 精英督军 24 / 巨骸领主 80。得分与零件分开计：普通 10 / 疾行 12 / 装甲 30 / 投手 18 / 督军 60 / Boss 400。
- 敌人 6 类（同屏 ≤30，首关 6 波共 176 只）：普通感染者（慢）、疾行者（快）、装甲怪（高血慢）、酸液投手（远程抛酸，落点红圈预警可躲）、精英督军（第 3/5 波头目）、第 6 波 Boss「巨骸领主」（高血、周期召唤感染者、低于 40% 血进入狂暴加速）。全部头顶简化血条。
- 玩家 HP 归零 → 防线后复活点无限复活（3 秒无敌）；「演示无敌」开关在面板内，默认关。
- 波与波之间 Enter（或点击战场）继续；6 波全清 → 胜利结算 → Enter 进入下一关（关数 +1：波数 +1、僵尸 +35% 血 / +10% 速 / +20% 伤，无限关）。
- 最高波次与最高得分存 `localStorage`，命名空间 `tb-game-zombie-road-*`（`tb-game-zombie-road-best`，读写均 try/catch）。

## 胜 / 负 / 重玩

- 胜：第 6 波（含 Boss）清空 → 结算面板（分类型击杀数 + 总得分 + 新纪录标记）→ Enter 进入第 2 关。
- 负：防线完整度归零 → 失败面板（坚守到第 N 波）→ Enter 从第 1 波重开（页内重玩，不刷新）。
- 暂停：Esc 或工具条「暂停」；工具条另有「全屏」；面板含操作说明、声音开关、触屏开关、中/EN 切换、演示无敌开关。

## 特色

- 雪夜公路全程序化：车道线柏油路 + 护栏、雪原与雪杉、撞毁车辆残骸、暖光路灯（光晕闪烁）、飘雪粒子（700 颗绕相机回收）、公路尽头出怪点的红色雾中光晕、随防线完整度变红发光的沙袋墙。
- 零件经济 + 自建机枪塔布防（落点在准星地面、限防线前方）+ I 键维修。

## 已知局限

- 车辆残骸、护栏、杉树只有视觉意义，未做角色-障碍物碰撞（玩家与僵尸可穿过）。
- 僵尸 AI 为直线追击 + 简单分离，不会绕后或利用掩体；平时直奔沙墙，玩家/炮塔靠近才被拉仇恨。
- 步枪/狙击为 hitscan 曳光表现，无弹道下坠；酸液为抛射投射物。
- 飘字等 UI 元素数量上限较低（≤14 条）；雪粒近相机时会显示为较大的方点。
- 手机竖屏旋转布局在极端长屏（如 21:9）下按钮可能与镜头区重叠。
- 页面 URL 带 `?qa=1` 时会挂载 `window.zombieQa` 自动化验证钩子（跳波次、清场、加零件、按键注入、读状态），与站内 QA 范式一致；普通游玩不暴露任何入口。
- 未做手柄/振动；未做存档续玩（每局从头开始）。

## 真实问题与修复（开发验证中发现）

1. `main.js` gatherInput 返回 `mz`，但 `game.js` stepPlayer 两处读取 `inp.my` → 移动分量为 NaN，玩家原地不动。统一为 `mz` 修复。
2. `main.js` 误写 `_dir.dz`（应为 `_dir.z`）→ 射击方向含 undefined，hitscan / 软锁定 / 喷火锥形全部失效（一枪都打不中）。已修正。
3. 修复 1 前用属性 setter 陷阱定位 NaN 写入点（stepPlayer 移动行），确认修复后全套通过。
4. 测试脚本自身的竞态（按键后未等一帧就读状态）与传送钳制错误造成的 3 例 FAIL，属测试问题非游戏 bug，已修测试复测通过。
