其他玩法 · 实验内容

设置与存档

地表白天 / 夜晚可在主菜单或暂停菜单切换并保存；进入虫洞自动开启手电，跟随视角照亮前路，无需按键、不耗电。
电脑默认：WASD / 方向键移动 · 自动寻敌并攻击 · 按住画面用鼠标拖动转视角 · 按住Shift跑步 · 空格跳跃 · 操作设置可选纯键盘、手动瞄准、按住/切换射击及改键
按住 Shift / 手机跑步键持续加速（无冷却）· K/空格 跳跃（落地后可再次起跳，无冷却）· I 互动（开关城门、上下载具）· H 医疗包 · U 无限手雷（无需补充，无投掷间隔）· 直升机 Y 升 / H 降 · 1-6 / X / 滚轮 换枪 · O 商店 · L 建造 · R 开战 · P/Esc 暂停
手机：左摇杆移动，右侧空白处拖动转视角；「切换视角」在各第三人称预设与第一/第三人称间循环，无需记键盘；商店、建造、换枪、医疗、手雷都有对应按钮
菜单和面板：方向键 / WASD / Tab 选择（黄色框），J / 回车确认，K / Esc 返回，全程不用鼠标
玩法：打怪攒钱 → 买枪强化、造炮塔、雇最多12名队友 → 开战守住基地。基地耐久归零即失败；玩家阵亡会复活，基地损伤保留。
母皇：早杀可减少本章后续虫潮 35%，每次通关额外领补给；晚杀保留更多虫群掉落。菜单可「队友集合 / 载具救援」，各冷却 20 秒，保留血量；在虫洞内救援时载具停在洞口。
城门：玩家和队友靠近自动开门，队友通过后自动关门，I 手动开关 · 走远了看小地图和基地方向提示找家 · 载具被打坏下关自动修好 · 进度自动保存
新功能：队友拾金币与血包、商店「队友」升级武器和护甲、最多 64 座设施、9 个副本随章节解锁，副本三档难度分别领奖（独立于战役难度）；右侧「菜单」或 P/Esc 暂停

游戏暂停

操作模式 · 切换立即生效，保留本局进度

全队指令会统一分工；战术部署可逐人安排跟随/留守。

救援保留血量，各冷却 20 秒。队友集合时驾驶员下车、分配保留；洞内救援载具会送到洞口。直升机跟随到洞口待命。

⚑ 战地模式 · 沙漠据点战

沙漠战场：争夺 A旧镇、B通信站、C补给仓库。控制多数据点消耗敌方兵力票，兵力归零或15分钟结束时决胜。选择固定兵种装备，上车作战；阵亡后8秒重新部署。

规模

装备：O / 部署：L / 战况：T / 换弹：R / 支援：H / 上下车：I。手机使用同名按钮。双方各有8名电脑步兵与越野车、坦克、装甲车、直升机；弹匣打空自动换弹，备用弹药无限。联机由房主计算战局，中途加入接手电脑座位。
